# SDD084：主机的多个 SSH 登录账户

## 目标与边界

主机资产、SSH 登录账户、登录凭据、Agent 运行权限和单次任务权限分别管理。一台主机保留稳定 ID、名称、SSH 地址和 Agent 身份，可登记多个登录账户；每个账户可绑定多个凭据。平台在安装前选择账户，不依赖尚未安装的 Agent。

## 需求

- 删除 managed_machines 的 username/default_credential_id 字段与主机级凭据绑定入口。账户是唯一用户名来源，凭据必须绑定明确 account_id；禁止旧字段兼容或双写。旧开发数据库明确拒绝启动并要求用户备份后使用新数据目录，不自动删除或迁移秘密。
- 主机登记仅保存资产和 SSH 连接地址；可在登记流程中另行创建第一个账户及凭据。账户 username 在同主机唯一且创建后不可修改，修改用户名通过新增账户完成；账户默认凭据和主机默认账户分别显式管理。
- 所有终端、预检、安装、更新、回退、卸载、权限切换、Docker安装及AI接口从选中 credential_id 唯一解析 account_id/username，不根据用户名猜权限。安装默认勾选自动选择合适账户：优先已登记root账户，再尝试具备权限及其他有效账户；连接、鉴权或权限不足的只读预检可自动换账户，记录每次尝试。取消自动选择后仅检查用户指定账户。已经修改远端或结果unknown时先核对，不跨账户重放。
- 凭据库复用现有加密存储，绑定按账户隔离；同一私钥可显式绑定不同账户。一次性秘密只能使用一次；默认6小时，不收集sudo密码，不把公钥当作登录秘密。
- 账户列表显示最近检查的 SSH 连接状态、实际root/免交互sudo/无权限/未知及有效期。推荐只使用同一主机未过期、目标与凭据仍匹配的检查；安装自动模式顺序只读检查已登记候选，其他操作不自动探测，不因账户名root而信任。无已验证候选时允许选择未检查账户重新检查，或添加账户。
- 权限不足明确说明当前账户可SSH登录但不能安装/维护，并提供已验证账户推荐、账户管理和添加入口。用户选择后重新检查、重新生成并审阅计划；保存、检查和选择不自动执行作业。
- 维护计划冻结主机、账户、用户名、凭据修订、Agent身份及原权限范围；更改默认值不影响原计划。不得通过新账户扩大既有批准。unknown核对可显式选同主机另一账户的有效凭据执行原固定只读检查，保留原批准身份与核对身份审计，不能重新派发。
- 在途终端/维护和未决结果阻止删除账户；旧凭据撤销/过期仍保留审计。Agent原有审计、签名和维护互斥保持。
- 中英文界面统一展示登录账户+凭据，用户可以在主机内管理账户、添加凭据、设默认、删除不再使用的账户；非管理员不能读取账户秘密或执行管理操作。

## 架构同步与验收

本次改变数据模型与凭据边界，须同步 docs/system-design.md 与Doca正文/原生图并最新版本回读。覆盖账户隔离、错误账户/主机引用、默认值变化不替换批准身份、权限不足推荐、过期拒绝、未知结果恢复、终端和维护全链路；真实SSH与模拟API证据分别记录。
