### 验收发现与修复约束

- Linux 真实根目录的祖先权限检查必须正确处理 `/`，拒绝可写祖先时仍保持失败关闭；临时目录 fixture 不能代替默认绝对路径验证。
- 空白主机必须先创建固定无登录账号及其同名主组，再运行真实权限预检，仍在停止已有服务之前；不得依赖系统的隐式用户组策略或预先存在的 `/usr/local/bin`。已有账号主组不匹配时直接报告，不修改其权限。
- SSH 安装检查与 `--fresh` 的占用判断必须同时覆盖 daemon 与 helper 的固定 unit、配置及状态路径。残留先在检查阶段说明，直接调用安装器也须在注册/写入之前拒绝，不能接管或清除原 helper 身份。
- root 完整管理模式升级的初始确认、等待、提交与成功回执统一要求普通 Agent 与 helper 同时健康。中心复用已有签名 helper 状态，核对冻结的 helper 身份、安装代次、目标构建、新 activation 与权限代次，不能只凭普通 Agent 心跳宣布两个组件升级成功。
- 上述为既有单包双组件一致性及权限边界的实现补漏，不增加新组件或控制通道；仓库与 Doca 的既有设计约束继续适用，发布验收状态另行记录。
