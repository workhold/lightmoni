# SDD087 Agent 统一普通账号与受控高权限能力

## 目标

一套 Agent 发行与生命周期，一个 `lightmoni-agent` 非登录普通系统账号。常驻采集、心跳、平台通信与普通用户脚本统一使用该账号；不再创建、保留或维护 `lightmoni-task` 账号。完整管理模式安装同包 root helper，普通脚本执行前降权到 `lightmoni-agent`，高权限脚本保留显式签名审批链。普通脚本作为受信任的运维代码，可访问该账号可读的 Agent 凭据与可写状态；不声称它们与常驻 Agent 之间存在身份隔离或完整沙箱。不安装 helper 的监控模式只采集和拨测，不执行自定义脚本。

## 范围

- 安装、更新、回退、卸载和权限模式切换通过已登记的 root 或免交互系统管理 sudo SSH 账号执行固定流程；SSH 账号不成为常驻或任务身份。
- 首次登记主机时 SSH 用户名默认 root，登记和新增账户界面推荐使用 root 完成安装维护，同时允许改用具备免交互系统管理 sudo 的账号。已有主机和已保存账号不改写；用户名只是输入建议，实际权限必须检查通过。推荐 root 不意味着开启服务器 root SSH 登录，也不意味着普通任务获得 root 权限。
- `runtime_mode=root` 表示完整管理/helper 已启用，不再表示网络 Agent 进程 UID0；`runtime_mode=user` 表示监控模式。在线证据中 Agent UID/GID 始终非零，helper 身份/能力单独签名证明。
- helper 是同一发行内的受管组件，只有完整模式安装其 systemd unit；统一维护、停止、恢复和删除，不能独立版本漂移。
- 所有自定义普通脚本由同包 helper 内复用的 TaskRunner 执行，并切换至 `lightmoni-agent` 的非零 UID/GID，清空附加组和 capabilities、启用 NoNewPrivileges；不注入 SSH 或 root helper 秘密。该普通账号无任意 sudo 和 Docker socket 权限。高权任务沿用独立签名任务授权，不提供任意 sudo 或本地命令 API。
- 自动选择安装账号默认开启：先核验已登记且有效的 root 账号，再检查其他可用账号的免交互系统管理 sudo 权限。允许只读检查阶段继续选择候选账号；派发安装后不得静默更换已批准账号或重复安装。手动选择只检查指定账号。
- 没有可用账号或全部账号无法满足安装维护时，返回可机器读取的原因及下一步，并在当前主机上下文提供“添加 SSH 账号”“管理账号”和“重新检查”。提示区分无凭据、凭据过期/撤销、连接/认证失败和缺少管理权限；保留用户输入，添加或更新后回到当前操作重新检查，不自动执行安装，也不教用户配置无限制 sudo。
- 页面以“检查账号 → 确认安装 → 查看进度”为主路径，展示实际选中的 SSH 账号、普通运行账号和高权限授权状态；安装、升级、回退、模式切换和卸载共用一套账号选择、审阅与逐主机进度，避免展示内部 task 账号或独立维护入口。
- 同一主机有未核对的 `unknown` 普通脚本结果时，中心拒绝新脚本派发且 helper 不领取后续脚本；用户明确重试并关联新运行记录或管理员记录人工核对后才解除主机级阻塞。
- 普通脚本的领取、续租、回执与核对只走 `/api/v1/privileged-executors/:id/task-runs/...` 签名 helper 通道；Agent bearer 不提供脚本领取或回执路由。
- 监控模式不发布脚本领取能力；切换模式须显示影响并独立批准。升级不改变已批准模式。派发后未知状态禁止重放。
- 平台管理员仍按当前范围管理全部主机，不增加平台 RBAC；普通及高权任务均持久审计。

## 验收边界

执行功能性身份/生命周期、类型与构建检查；不执行漏洞复现、可利用性验证或真实用户主机写操作。发布前记录实际检查与未完成的实机范围。
