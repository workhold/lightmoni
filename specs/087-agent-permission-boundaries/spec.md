# SDD087 Agent 服务、任务与维护身份分离

## 目标

一套 Agent 发行与生命周期；SSH 管理身份、常驻服务身份和任务身份独立。常驻 Agent 始终以 `lightmoni-agent` 非 root 运行；完整管理模式安装同包 root helper，普通脚本降权到 `lightmoni-task`，高权限脚本保留现有显式签名审批链。不安装 helper 的监控模式只采集和拨测，不执行自定义脚本。

## 范围

- 安装、更新、回退、卸载和权限模式切换通过已登记的 root 或免交互系统管理 sudo SSH 账号执行固定流程；SSH 账号不成为常驻或任务身份。
- 首次登记主机时 SSH 用户名默认 root，登记和新增账户界面推荐使用 root 完成安装维护，同时允许改用具备免交互系统管理 sudo 的账号。已有主机和已保存账号不改写；用户名只是输入建议，实际权限必须检查通过。推荐 root 不意味着开启服务器 root SSH 登录，也不意味着普通任务获得 root 权限。
- `runtime_mode=root` 表示完整管理/helper 已启用，不再表示网络 Agent 进程 UID0；`runtime_mode=user` 表示监控模式。在线证据中 Agent UID/GID 始终非零，helper 身份/能力单独签名证明。
- helper 是同一发行内的受管组件，只有完整模式安装其 systemd unit；统一维护、停止、恢复和删除，不能独立版本漂移。
- 所有自定义普通脚本由 helper 内的普通 TaskRunner 执行，并切换至独立非登录账号 `lightmoni-task`；不继承 SSH、服务秘密、附加组或 capabilities。高权任务沿用独立签名任务授权，不提供任意 sudo 或本地命令 API。
- 同一主机有未核对的 `unknown` 普通脚本结果时，中心拒绝新脚本派发且 helper 不领取后续脚本；用户明确重试并关联新运行记录或管理员记录人工核对后才解除主机级阻塞。
- 普通脚本的领取、续租、回执与核对只走 `/api/v1/privileged-executors/:id/task-runs/...` 签名 helper 通道；Agent bearer 不提供脚本领取或回执路由。
- 监控模式不发布脚本领取能力；切换模式须显示影响并独立批准。升级不改变已批准模式。派发后未知状态禁止重放。
- 平台管理员仍按当前范围管理全部主机，不增加平台 RBAC；普通及高权任务均持久审计。

## 验收边界

执行功能性身份/生命周期、类型与构建检查；不执行漏洞复现、可利用性验证或真实用户主机写操作。发布前记录实际检查与未完成的实机范围。
