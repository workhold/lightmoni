# SDD 168 实施计划

1. 在 `MachinesPage` 为部署和 Agent 管理入口增加可见文字及局部样式，保持其他紧凑图标操作不变。
2. 为 `AgentOperationProgress` 增加默认保持原行为的标题隐藏选项，卸载对话框复用现有状态 Alert，避免重复。
3. 重排卸载成功页：真实回执在前，原计划使用可展开的原生 `details` 折叠；提供“完成”按钮，待审批和异常流程不改。
4. 移除普通安装确认的危险样式，统一恢复卸载显示文案，保留 `recovery` API 契约和全部风险提示。
5. 更新隔离 UI 验收，运行类型检查、生产构建和相关主机回归，检查桌面/窄屏截图并记录验证证据。

## 契约与架构

- 契约见 [contracts.md](contracts.md)，仅涉及展示和既有交互。
- 架构影响不适用：无后端、数据、控制路径、权限或部署变化，不修改 `docs/system-design.md`。
