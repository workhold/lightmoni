# Data model
Protocol concrete enum: openai-chat-completions, openai-responses, anthropic-messages, google-generative-ai.
Config adds protocol string; omitted/blank legacy values normalize to Chat. Auto cannot be stored/run. ConfigView returns concrete protocol. Config may also carry `reasoning_effort`: `provider-default` (omitted/blank legacy value), `none`, `minimal`, `low`, `medium`, `high`, or `xhigh`. The value is a provider-neutral request preference; it is passed to the runtime only when explicitly set and is never inferred from a directory listing.
DiscoveryInput adds protocol (auto or concrete, omitted=auto). Temporary key overrides use_saved_key; saved key requires exact normalized base match; protocol-only change permitted at same base.
DiscoveryView extends previous fields with protocol_options:string[], protocol_source:manual|official-host|endpoint-path|catalog|default, requires_confirmation:boolean, capabilities_verified:false. protocol is a concrete recommendation (not generation proof). models:{id,label?}[], max500, truncated includes native page markers.
UI auto has effective recommended concrete protocol; if requires_confirmation or no evidence for unknown URL, select concrete protocol before saving. Manual model retained. Editing protocol participates in debounce/cancellation; successful normalized base adoption must not trigger duplicate query.
Worker config adds optional protocol, defaultChat for legacy. Protocol-specific native SDK translates neutral text/tool history; Mastra internal messages retain native per-step metadata; host durable text/tool facts retain ownership and existing compaction bounds. The worker config carries the normalized reasoning preference. `provider-default` omits a reasoning override and lets the selected model decide. Native providers map the shared levels to their own settings when possible; unsupported levels produce a runtime compatibility warning or provider error according to the SDK, never a fabricated capability claim. The setting does not expose hidden reasoning text.

Native durable metadata: optional ToolCall.provider_options and Message.provider_state allowlisted for signatures/encrypted reasoning, bounded, hidden from UI session responses. This prevents next-turn signature validation failure. Never preserve plaintext reasoning parts.
