# SDD 050：集中连接凭据与主机网络地址

## 目标与范围

用户在一个连接凭据库管理 SSH 私钥与密码；登记主机时选择已有凭据或直接新增，主机绑定默认凭据后 SSH 终端、安装检查和 Agent 安装/卸载不再反复要求选择。同一私钥按真实公钥 SHA256 指纹复用，不按私钥文本或密码散列识别。

主机列表的“主机”栏同时标明登记的 SSH 连接地址、Agent 发现的内网 IP 与其他网卡地址、平台观测到的出口/来源 IP。支持多网卡、IPv4 和 IPv6，以及只有内网的部署环境；没有观测时显示“待发现”。平台主机 ID 是唯一资产身份，IP 变化、共用 NAT 或同名网卡均不影响主机绑定。

## 用户流程

1. 运维工具增加“连接凭据”页，管理员可新增、命名、查看状态/期限/关联主机、编辑名称及撤销凭据。默认保存 6 小时，支持自定义期限与明确选择永久；不返回私钥或密码。
2. 登记或配置主机可选择有效的已有凭据，也可填写新的密码/私钥并保存到库。用户名、地址和端口属于主机，不属于共享秘密。
3. 主机绑定有确定的默认项；可切换默认、解绑。默认失效时提示更新，不自动改用另一条凭据。已有检查/计划继续绑定当时确定的凭据 ID。
4. 解绑只影响该主机；全局撤销前展示关联主机并明确确认，撤销影响所有绑定、终端及待审批计划。删除主机不能删除其他主机仍需使用的共享密钥。
5. 主机名称下展示 SSH 地址、内网 IP、其他主机 IP、出口/来源 IP；详情展示网卡、地址族、地址类别、最近观测时间与来源依据。安装 Agent 后自动发现，不通过公共第三方探测站查询出口。

## 生命周期与升级

- 中央凭据加密存储一次，主机凭据记录作为绑定保留稳定 ID。有效旧凭据迁移到库，保留旧主机的期限、撤销/消费语义和历史检查/计划；无效旧历史不重新激活。
- 同公钥私钥复用中央项，不因重复提交隐式延长保存期限。密码不生成可离线猜测的指纹。旧绑定期限不得因合并而增长；绑定有效期受中央项与绑定自身共同约束。
- 临时凭据在 Agent 激活后的清除仅解除相应绑定；共享项的过期/撤销清除中央秘密并使所有消费点失效。
- 新 Agent 上报网卡快照；旧 Agent 未上报时保持协议可用并明确未发现/上次观测。新 Agent 身份不能冒用旧 Agent 的地址快照。

## 来源与边界

出口/来源 IP 是平台对该连接的观测，不承诺为公网地址或可入站访问。默认忽略客户端转发头，只信任 socket 对端。部署者可显式设置可信代理 IP/CIDR；仅可信链路从右向左解析 X-Forwarded-For，缺失/非法来源不能伪装成主机 IP。网卡内容为经过认证 Agent 的自述，不作为主机授权或自动匹配依据。

本轮不改 SDK、不写主机环境变量，不执行生产主机变更，不发布镜像。架构有变化，需同步仓库系统设计及 Doca 并回读，创建 GitHub PR 供审核。

## 验收

覆盖同钥跨机复用/重复去重、默认自动选择/切换/失效不回退、解绑与全局撤销边界、加密/不泄露、旧库升级与期限、密码/终端/检查/安装卸载回归；网络覆盖多网卡、IPv4/IPv6 私网、CGNAT、链路本地、非法/超量输入、可信/不可信代理、纯内网观测与重装身份；浏览器验证中英文及窄屏凭据页、登记选择和主机栏信息。
