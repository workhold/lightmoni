# 实施计划

1. 在本规格中固定删除、密码验证与 Agent 计划审阅边界。
2. 复用已有主机 DELETE API，在详情界面增加确认删除入口，覆盖运行中资源拒绝和删除后刷新。
3. 使用隔离 fixture 验证密码凭据只能进行一次固定只读 SSH 预检，检查结束立即撤销且不能生成自动部署计划；使用 vchive 只做受控的实际密码/私钥路径验证。
4. 运行类型检查、主机后端测试、主机 UI 回归和生产 bundle 验证，记录未执行真实 Agent 安装的边界。
5. 通过 GitHub 功能分支 PR 交付，不直接合并或升级线上；因凭据认证边界变化，同一 PR 同步仓库 HLD/LLD 与 Doca 在线设计副本。
