# 交互契约

- **删除确认**：详情页显示“删除主机”，必须二次确认；后端返回占用/运行状态、有效凭据或未结束计划时保留主机并显示错误。
- **计划取消**：`POST /machines/:id/deployments/:deploymentId/cancel` 仅管理员可用；被占用的主机返回 409；`awaiting_approval` 变为 `cancelled`，已 `cancelled` 幂等返回；其他状态返回 409。过期但未执行的计划可以取消；取消不下发 SSH，不签发 enrollment。
- **删除范围**：成功删除主机及其级联凭据、SSH 检查、部署记录；页面列表重新加载，不能把失败当成成功。
- **密码边界**：密码凭据可选择一次固定只读 SSH 预检或一次管理员网页终端；检查结束或终端租约释放后立即自动撤销，不能通过部署计划确认自动安装。页面明确建议一次性使用并撤销。
- **部署边界**：只有 SSH 私钥、确认指纹和新鲜成功预检可以生成计划；计划必须在页面明确确认后才调用 apply。
- **测试边界**：真实 vchive 测试不保存长期密码、不执行 Agent 安装、不执行任意业务命令；密码凭据验证完成后自动撤销，私钥凭据在测试结束后显式撤销。
