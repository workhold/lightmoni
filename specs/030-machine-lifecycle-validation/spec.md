# 030 主机生命周期与凭据验证

## 目标

补齐主机管理的删除入口，并验证密码凭据的 SSH 登录边界与固定 Agent 部署审批流程。

## 需求与验收

1. 管理员可以从主机详情中删除主机；删除必须明确确认，执行前由后端阻止运行中的终端、检查、部署、有效凭据或未结束部署计划，删除成功后列表刷新并清理关联凭据、检查和部署记录。详情历史提供待审批计划取消入口；取消只作用于尚未执行的计划，允许过期计划取消，重复取消保持幂等。
2. 删除主机的按钮和确认提示提供中英文文案；成员不能看到或调用该能力。页面准确显示后端拒绝原因，不虚报成功。
3. 密码凭据可用于一次固定的只读 SSH 登录预检或一次管理员网页终端，不得用于自动 Agent 部署；密码不长期保存，检查结束或终端租约释放后立即自动撤销。
4. Agent 部署只能使用已确认指纹、成功且未过期的 SSH 私钥预检结果；先生成可审阅计划，再由管理员明确确认执行。测试默认停在计划审阅，不在未明确确认时安装或修改主机。
5. 使用 vchive 进行真实验证时，只执行固定只读 SSH 预检和有限的终端识别命令；不执行 Agent 安装，除非用户在审阅计划后另行明确确认。凭据在验证完成后撤销；测试记录不进入仓库。

## 范围边界

保留后端凭据加密、SSH 固定检查、Agent enrollment 和部署命令；扩展密码预检/终端和部署计划取消接口，补齐 DELETE 的使用边界。不新增资源类型，不上传新的镜像。

## 架构影响

适用但范围受限：新增“密码凭据 → 固定只读 SSH 预检/管理员网页终端”的认证路径，并明确密码凭据的自动撤销边界；Agent 部署仍只允许私钥，中心/Agent 拓扑和存储职责不变。已同步更新 `docs/system-design.md` 第 13 节；Doca 在线副本需在同一 PR 中回写并记录回读结果。
