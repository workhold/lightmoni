# SDD 194：左上角品牌版本标识

## 目标

在已登录界面左上角品牌区显示当前 LightMoni 前端包版本，位置紧邻“监控工作台”描述文字，帮助用户截图和反馈时直接说明运行界面版本。

## 行为

- 品牌区显示 `v<web package version>`。
- 版本来自 `web/package.json`，随统一版本脚本和镜像构建一起变化，不手工维护第二份版本文本。
- 展开导航时显示版本徽标；折叠导航时与品牌文字一起隐藏，只保留 L 标识。
- 徽标带 `LightMoni 版本` 可访问标题，不改变导航、鉴权或任何运行时协议。
- 登录页暂不新增该徽标；本需求针对已登录左上角工作台品牌区。

## 非目标

- 不显示 Agent、SDK 或主机版本。
- 不新增 API、存储、架构路径或权限。

## 验收

1. 已登录界面左上角显示 `监控工作台 v0.1.9`。
2. 徽标与 Web 包版本同源，构建后仍一致。
3. 折叠导航时徽标隐藏，展开后恢复。
4. Web typecheck/build 与隔离浏览器验收通过。
