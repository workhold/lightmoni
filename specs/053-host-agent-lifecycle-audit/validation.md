# 主机管理与 Agent 生命周期加固验收

## 范围与结论

基于 GitHub `main` 的 `334df478c97621efaeae60bb0d4cf72c1a22dde9`，审查登记与集中凭据、SSH 预检、首装、卸载、维护互斥和浏览器恢复。使用独立工作区与隔离数据，不操作生产、vchive 或原本地 8080 服务。

本轮存在架构影响：首装状态持久化、unknown 恢复、人工结束及冲突操作屏障。规格、计划和契约先于实现补入本 SDD；仓库总设计第 13 节安装段及 13.8 同步更新。

## 限制与保留的约束

- 没有执行真实 SSH/systemd、vchive 安装卸载、生产部署或镜像发布。本轮 HTTP/SQLite、浏览器协议和脚本隔离测试不能等同实机验收。
- 重启恢复测试通过重装 Router 复用持久数据库及延迟响应模拟；没有执行 OS 级进程崩溃测试。
- 创建未知响应的登记/凭据防重复限当前窗口；本轮没有新增服务端创建幂等协议，重新创建前仍需核查列表。
- 人工结束不会停止远端进程，管理员必须先确认远端流程已结束；它保留 unknown 历史，不代表安装成功或已经卸载。
- 正常卸载保留 identity/config；本轮没有放宽 fresh 覆盖保护或引入自动重装协议。
