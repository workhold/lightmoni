# Agent 安装完成后的就绪确认

日期：2026-11-11；来源：生产发版后仍有安装失败。

## 事实与范围

香港节点 2026-11-11 10:53:46（北京时间）激活，10:53:58/59 helper/Agent 启动，持续上报到 13:59。该次安装记录只有 bootstrap_dispatched 与通用 unknown，缺失具体失败原因，不能追溯断言原始异常类型。13:59:40 人工结束撤销了 control/data 身份。只读核对时服务仍运行。源码在 SSH 完成后只检查一次新鲜心跳/签名通道，存在正常异步启动被判未知的竞态。

## 要求

- FR-001：SSH 安装仅派发一次；成功返回后在有界时间内等待本次 enrollment 激活、新鲜合法运行身份及 root 模式的签名执行通道。
- FR-002：等待期间保持主机忙状态、安装隔离和取消语义；人工恢复、身份变化或请求取消不能由旧请求覆盖。
- FR-003：超时仍保持 unknown，保留固定、安全、可区分的原因和已完成阶段；不记录原始异常/SSH 日志或凭据，不自动重装。
- FR-004：人工结束提示明确会撤销已激活 Agent 的控制/数据授权并导致离线；优先只读核对。
- FR-005：兼容没有运行身份记录的历史安装，不改变现有健康判定标准和手工恢复授权。

## 验收

迟到的心跳/通道可在一次安装内成功；超时、取消、错误身份及旧记录被恢复时不误报成功、不重放安装。原 SSH 错误白名单保持；未白名单内容不进入响应或回执。

## 架构影响

不适用。仅在既有同步安装确认流程内增加有界只读等待并修正现有 error/stages 文本与确认文案；组件职责、数据和控制路径、存储字段、协议形状、凭据边界、部署拓扑不变。仓库 system-design 与 Doca 无需修改。
