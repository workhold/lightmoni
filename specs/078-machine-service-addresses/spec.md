# 主机内外网服务地址候选与人工修正

日期：2026-11-01。用户确认内网和公网地址都需要自动识别候选、支持手动修正。线上观察：目标主机有内网网卡、独立公网 SSH 字面地址，中心连接来源为代理内网；现有网卡采集无法直接发现云 NAT 公网入口。

## 要求

- 主机管理分别展示内网/公网服务地址、来源、候选和采样时间；网卡观测保留原样，服务地址配置单独保存，不将 SSH 连接目标、平台连接来源与网卡 IP 混成同一事实。
- 内外网都支持自动网卡选择与手动指定。自动识别候选来自当前身份的有效网卡、已登记的 SSH 数字 IP，以及当前 Agent 到平台的公网来源；SSH/平台来源仅为待确认候选，不自动提升为 DNS 或内部服务地址。不额外调用第三方出口服务，不解析 SSH 域名后暗中选址。
- 手动输入或点击候选均由管理员保存确认；内网只接受私有/共享地址，公网只接受普通公网范围字面 IP。拒绝 URL、端口、CIDR、回环、链路本地和特殊保留范围；错误显示在对应地址字段下。
- 有效服务地址统一供现有应用、集群内部端点和入口 DNS 使用：内部优先内网，入口 A/AAAA 使用公网。手动选择覆盖自动选择；观察候选仍可查看，后续心跳不得覆盖人工设置。恢复自动后重新使用当前网卡。
- 配置具有独立 revision 和操作者/时间记录；并发冲突保留输入，不自动重放。绑定稳定主机 ID，Agent 重装不丢失；SSH 目标代际变化时人工地址待重新确认，不能默默沿用到新目标。删除主机随之清理设置。
- 公网 IP 缺失时入口 DNS 必须明确提示主机未配置可用公网地址，不使用内网/代理地址，也不把空目标的 DNS 回读当作已发布入口。已发布内部端点不会为了显示公网而改写；具体端口绑定变更仍按原部署流程生效。

## 架构影响

有：新增中心管理态服务地址设置、机器管理接口和取址优先级。需在同一 SDD/PR 更新 `docs/system-design.md` 网络/SDD064章节，并局部同步 Doca《LightMoni 系统设计基线》，保留原生图块与无关内容，最新版本回读验证。Agent 原心跳/网卡协议、SSH 凭据、AI 审批与外部 DNS 归属不变。

## 验收边界

隔离 SQLite/HTTP 覆盖自动候选来源、NAT 公网待确认、两种手动覆盖、恢复自动、无效字段、revision/SSH代际冲突、身份更换、心跳更新、删除清理和权限。网站路由验证内网端点仍使用内网、入口 DNS 使用所选公网及缺失时可解释状态。浏览器验证保存/刷新、失败保留、候选采用、中文英文和窄屏。不会修改用户线上服务地址或发布公网服务。
