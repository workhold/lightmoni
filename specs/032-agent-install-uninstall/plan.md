# 设计

在现有主机管理、SSH pin、凭据租约及审核流程上增加保留数据卸载。全新安装和卸载是不同操作，拥有独立计划和回执；卸载需有远端身份核对，中心在确认移除后撤销对应 Agent 的两种凭据。SSH 凭据仍遵循 031 的临时/托管策略，秘密不返回前端或 AI。

卸载脚本作为平台内置、版本受控内容执行，使用 SSH stdin 或固定的安全封装传递，避免为卸载再签 enrollment 身份。默认保留节点配置和持久化目录；网页不开放 `--purge`。保留数据与撤销身份的结果分别展示。

安装引导修正鉴权下载，预检及执行双重阻止覆盖已有 Agent。已有运行节点以观察和核对为主，本期不实现跨平台认领或透明升级。

仓库系统设计与 Doca 第 13 节同步记录控制路径、凭据撤销与保留数据边界；原有原生流程图保留。
