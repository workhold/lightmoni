# 排查和决策

| 观察 | 决策 |
| --- | --- |
| arm64 Docker 创建固定 amd64 镜像实例时报告平台未指定 | 根配置声明 amd64，源码覆盖单独解析本机平台和本地镜像名 |
| 中心初始化读账号的 DDL 经过通用 ClickHouse 客户端写入 URL | 采用 ClickHouse HTTP POST 正文承载 SQL 和写入内容 |
| SSH 失败对象和维护错误附带远端原文。终端快速检查关闭过期会话时，绑定等待周期清理 | 返回固定错误码和退出码，在快速检查发现过期时清理该绑定 |
| 普通 HTTP 地址可用 Web Crypto 随机字节，`randomUUID()` 只在安全上下文存在 | 复用同一个 UUID v4 函数，保留服务端校验格式 |
| 助手返回原生审阅链接，路由固定跳转应用列表。原生页面仅手动读取 | 恢复带参数的管理员入口，以 URL 确定选择，仅轮询有活动的服务，以请求生命周期保护旧响应 |
| 助手按会话末尾恢复，可命中上一次完成事件。会话详情缺少派生状态 | 复用请求自身标识与持久事件，已受理标识在保留窗口内可识别，前端只回读 |
| 助手初次加载把数据目录作为必需步骤，目录异常会一起丢掉模型配置 | 单独加载数据目录，保留配置、历史与发送能力 |
