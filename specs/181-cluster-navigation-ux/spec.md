# SDD 181：集群导航与主机归属可见性

## 背景

集群已经是独立的部署资源，但左侧没有管理入口，主机页也只显示自由标签，用户难以发现集群及判断成员归属。

## 用户场景与验收

### US1：管理员找到集群管理

- 左侧“运维工具”在“私有镜像管理”之后、“应用管理”之前显示“集群管理”，链接 `/clusters`。
- 页面标题、活动分组和既有 `/clusters` 管理页复用，不新增重复路由。
- 成员角色不显示管理员专属入口，其他导航不变。

### US2：主机页区分集群和标签

- 主机列表显示所属集群名称；无成员关系时显示“未分配集群”。集群名称链接到对应集群详情。
- 支持按集群 ID 和 `unassigned` 筛选，保留现有 `cluster` 深链；标签筛选、搜索、批量选择互不影响。
- 后端安全投影只读附加现有 `cluster_id/cluster_name`，不暴露资源 spec、部署配置或凭据，无 ops 表时保持空值。
- 不提供通过标签或列表直接修改集群成员的捷径，原迁移、运行实例和删除约束不变。

## 非目标

不改变集群成员、调度、HA、数据复制或生产配置，不发布镜像。

## 架构影响

在既有 `docs/system-design.md` 42.1 补充只读主机投影和导航行为；无新组件、写入路径、存储、协议或凭据变化。
