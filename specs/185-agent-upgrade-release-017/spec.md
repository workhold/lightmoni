# SDD 185：Agent 升级排空修复的 0.1.7 发布

## 目标

从已合入 PR #256 的 GitHub `main` 发布含 SDD184 修复的中心镜像，在保持现有数据、配置和 ClickHouse 的前提下切换生产中心，再通过平台受控流程将 `zz-bj-1` 的旧 Agent 升级并核验。

## 验收

1. 用仓库版本脚本统一递增平台、Agent、SDK、MCP 和 Compose 固定镜像标签到 0.1.7；版本 PR 合入 `main` 后才从该合并提交构建 linux/amd64 中心镜像。
2. 本地构建、镜像内版本与 Agent 双架构发行包摘要、隔离中心健康/鉴权检查通过后，推送固定标签与 `latest`，回读摘要及 OCI revision。
3. 生产切换前记录实际运行镜像，备份 Compose、环境、主密钥及 SQLite 一致性快照；保留遥测卷、状态卷和 ClickHouse。切换后核对中心健康、版本和主机/应用现状。
4. 只对 `zz-bj-1` 发起平台一键升级。旧任务的 unknown 必须先按既有只读流程处理；运行中检查自然结束。最终确认 Agent 发行身份、心跳、服务和 Registry 容器状态。若维护结果未知，不重复派发。

## 架构影响

不适用。本发布仅将 SDD184 已审阅的控制路径投入运行，不新增组件、协议、凭据边界、存储或部署拓扑；架构说明已在 PR #256 的 `docs/system-design.md` §184。
