# 设计

以 GitHub 最新 origin/main 独立工作区实现，原工作区发行文件保留。

删除仍由 revision 乐观锁与事务保护。资源删除守卫检查真实实例终态、活动与未知执行、当前引用及启用发布快照；系统仓库仅在外部入口和集群缓存引用解除后允许注销；托管网站已发布修订的服务引用也必须检查。成功后退役已移除实例、清理端口预留及系统登记，执行与修订历史保留。沿用并验证已禁用网站快照不作为永久引用的现有规则；修复系统仓库无条件拒删和旧 active 聚合误阻塞。

存储路径集中在纯路径辅助模块，复用执行器当前布局，不变更数据位置。workload.inspect/apply/stop/remove 与 gateway.inspect/apply/stop/remove 返回有界非秘密 storage 元数据。中心从同实例观测读取清单，网站只筛选自身 website_id 对应的分组；旧Agent明确尚无回执，提供标准路径规则而不声称实际存在。管理员 GET /ops/resources/:id/storage 可读，详情内展示并可刷新，GET 不派发任务。

覆盖 HTTP/SQLite 的删除全生命周期及引用保护、旧状态、运行/未知阻塞；执行器真实临时目录渲染与 Docker inspect 夹具核对挂载和网站版本路径。运行相关测试、类型检查及页面实际渲染，记录证据。
