# 应用登记删除与宿主机存储目录

日期：2026-11-07。分支：codex/099-app-registration-storage。

用户要求：修复已卸载应用无法删除登记；确认并规范每个应用的宿主挂载和每个网站的配置存储目录。

验收：
1. 普通应用与系统仓库在全部实例已确认卸载、无活动/未核对作业、无网站或缓存引用后可删除登记；已停容器、离线或未知不等于卸载成功。保留修订、执行历史及远端持久数据，释放登记及端口预约。
2. 网站当前保存引用与仍启用的已发布引用阻止删除；成功停用后的历史发布引用不再永久阻塞已解除当前引用的应用。
3. 管理员在应用/网站详情看到逐机器、集群、实例的存储位置与挂载。Agent 回执提供实际宿主根目录、Docker 挂载来源/目标/只读及网站分组目录；未观测不能标为已验证。网站配置属于完整网关版本，不杜撰独立 conf 文件。
4. 标准受管根为 /var/lib/lightmoni-managed/operations/platform，workloads/<instance> 与 gateways/<instance> 隔离。配置按内容摘要、初始化首次写入、数据目录和命名卷保留现有布局；自定义 bind 和 Docker data-root 如实展示，不迁移或删除。

架构影响：适用。新增只读存储清单和 Agent 结果元数据，明确登记/历史/持久数据边界。同步 docs/system-design.md 与 Doca 基线，保留原生图并回读。未授权发行、生产部署或业务数据迁移。
