# SDD 195：Agent 安装入口的主机身份门控

## 背景

生产验收发现，已安装且在线的 Agent 主机即使 `deploy_agent` 连接能力可用，多选工具栏的“部署 Agent”仍可能被预判为可操作；单机菜单也存在同类风险。服务端最终会拒绝覆盖安装，但入口状态误导管理员。

## 行为

- 单机和批量安装预判都以持久 `machine.agent_id` 和 `agent_status` 为准。
- 只要主机仍绑定 active/uninstalled 之外的 Agent 状态，即使 SSH 与部署连接能力可用，也禁用对应“部署 Agent”入口，并显示已有 Agent 的原因。
- `removed` / `uninstalled` 主机仍可按现有能力进入安装流程。
- 服务端原有身份、远端残留、凭据、计划与锁复核不变。

## 非目标

- 不改变首装协议、覆盖安装拒绝规则或 Agent 生命周期状态机。
- 不新增架构路径；这是 SDD 192 主机状态投影的前端预判修正。

## 验收

1. 已绑定在线 Agent 且 `deploy_agent.available=true` 时，单机和批量“部署 Agent”均禁用并说明不能覆盖安装。
2. SSH 检查、卸载、移除节点等其他入口状态保持不变。
3. 隔离浏览器回归覆盖该生产反例。
