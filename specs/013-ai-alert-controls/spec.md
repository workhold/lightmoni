# 013 AI 告警规则与静默控制

日期：2026-10-19  
状态：已冻结需求，待实现

## 目标

让 AI 助手在当前登录用户权限内读取告警规则、告警组和静默窗口，并能提出有限的规则/静默变更。模型只生成变更提案；用户在助手界面明确确认后，中心重新校验权限、版本和有效期，再原子应用并返回回执。

## 场景与验收

1. 用户可以让助手查询规则、单项详情、告警组和静默；返回分页、稳定 ID、revision/version，结果有大小上限。
2. 用户可以请求启停/修改已有规则、设置或解除规则静默、创建/修改/结束静默；助手先返回原值、新值、影响、原因和有效期。
3. 提案生成不修改告警规则、静默状态、响应状态或通知队列；确认按钮只对当前用户、未过期且仍可读取的提案可用。
4. 应用前重新检查权限、目标版本和提案 TTL；并发修改或版本变化拒绝应用并要求重新预览；重复确认返回原回执，不重复执行。
5. 提案、应用回执和审计记录持久化；服务重启后状态可回读。告警页面上下文只作为提示，不作为目标 ID 或权限来源。

## 边界

本期不开放删除规则、接手事件、通知凭据、渠道管理、节点命令、任意 HTTP、任意 SQL 写入或自动修复。既有告警 HTTP API 和页面继续使用同一业务能力。默认提案有效期 15 分钟，单次提案只包含一个操作。
