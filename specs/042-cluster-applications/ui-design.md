# Final UI design (2026-10-30)

Applications and websites are global pages. Cluster selectors filter lists; they do not own the application identity. One serviceName has multiple deployment rows. The application selects manual/managed mode; each cluster row specifies machines or instance count plus CPU/memory per instance. OpenResty supports managed mode and fixed host ports 80/443.
Website domain bindings, HTTPS, certificates, paths and all Nginx options are shared. Only each location's upstream target is configured for each selected cluster. Selectable applications must have a deployment in that cluster. Independent dependency drawers preserve the parent form and refill the saved resource.
Reuse existing Ant Design theme and components. Capture desktop, 390px, 200% and action/entry/expand motion evidence; the root agent runs three final interaction passes and an isolated visual review. Media remains under ignored artifacts/screenshots; structured reports are committed.
