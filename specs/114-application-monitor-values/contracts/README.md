# 展示契约

不新增 API 或持久化字段。沿用应用 monitoring/telemetry GET 响应中的 load、web、sdk_metrics rows 及 range。

TelemetryPlot 接收既有 title/unit/rows/range/emptyText。每条 row 的 time 转为毫秒并排序；无效时间不参与绘图或统计。value 为有限数字或非空数字字符串时保留数值，其余为 null。series_label 优先，否则保留既有容器/网站名称与短 ID。

每条序列的最新值为最后有效值，平均值为有效采样点的算术平均值，最大值为有效点最大值；网络与磁盘沿用调用方计算后的速率，不汇总原始计数器。只对本次返回数据计算，现有截断/查询错误告警继续提示结果限制。图例和曲线共享相同规范化数据，三列均复用既有单位与两位小数。最新值的原生提示含有效样本时间。无数据不输出虚假统计。

兼容性：调用方参数、查询次数、15 秒刷新周期、筛选参数与空态文案不变。网站和 SDK 复用图表也显示同样数值图例。
