# 047 · 平台 MCP 首个可用实现

状态：已实现，待 PR 审核。继承 [SDD 046](../046-platform-mcp/spec.md)，本轮实现统一能力层与首批安全工具、Streamable HTTP MCP、专用 PAT、OAuth PKCE 及用户接入管理。用户已授权实现，不发布生产镜像、不操作用户主机。验收范围与限制见 [验证记录](validation.md)。

## 需求与范围

1. 外部客户端、HTTP 与内置 AI 的首批主机/任务工具复用能力层、当前身份授权、输入验证、安全输出与调用审计。
2. 首期工具覆盖主机元数据、任务/模板、真实执行状态、通用任务提案与目录读取；仅查询和提案，不开放凭据读取、任意 SSH、直接执行或 unknown 人工结束。
3. 独立个人访问令牌与 OAuth 授权均支持 scope、主机范围、期限和撤销；平台账户停用/降权实时生效。SDK/Agent/登录 Cookie 不能作为 MCP Bearer。
4. OAuth 使用预注册公共客户端、精确 redirect/resource、PKCE S256、授权码单次消费、刷新轮换与重放撤销。用户在平台页面明确授权。
5. 提案沿用现有任务中心审批、版本冲突与执行状态机，不伪造助手会话。撤销外部授权后阻止尚未提交的提案。业务幂等与协议请求 ID 分离。
6. 采用官方 SDK 的实际支持协议，按实现声明。协议/请求大小、Origin、并发、输出与调用频率受限，连接关闭不取消已批准领域执行。
7. 接入页面可管理自己的令牌、授权和客户端；秘密只在生成时展示，不写入浏览器持久存储或审计。

## 非目标

本轮不实现任意脚本自动批准、服务账户、持续授权、多租户或全部现有助手工具迁移。首期不承诺未实测的客户端/协议版本；2026 协议单独适配，不使用手写模拟协议冒充兼容。

## 验收

自动测试覆盖鉴权、PKCE/重放、scope与主机范围、schema拒绝、提案/审批/撤销、业务幂等、安全输出、MCP握手/发现/调用/断连以及现有任务回归。记录真实客户端可用程度，SDK集成测试不能冒充Codex/Claude端到端验收。仓库设计与Doca在同一PR同步并回读。
