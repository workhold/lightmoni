# SDD 213：助手分类重命名

## 背景

0.1.21 支持创建、选择和删除分类，但修改分类名仍需逐个打开会话并修改，无法批量维护。

## 目标

1. 分类管理中每个非“未分类”分类提供重命名入口。
2. 重命名会批量更新当前用户下该分类的会话；目标分类已存在时表示合并。
3. 正在运行响应的会话跳过并返回数量，避免并发写会话。
4. 固定建议分类改名为自定义名称后，旧固定建议不再自动出现，新名称作为浏览器本地的自定义建议保留。
5. 会话、消息、附件和运行状态保持不变，只更新会话分类字段。

## 非目标

- 不建立服务端全局分类表。
- 不做跨用户分类合并。
- 不自动迁移正在运行响应的会话分类。

## 验收

1. 分类管理行显示重命名入口，输入新名并确认后发起分类级更新。
2. 后端返回更新数量和运行中跳过数量。
3. 目标分类已存在时不报错，原分类会话并入目标分类。
4. 固定建议分类改名成功后刷新页面，新名称仍出现在建议中，旧固定建议不恢复。
5. 自定义分类改名后历史分组、候选列表和检查器分类一致。
