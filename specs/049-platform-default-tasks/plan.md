# 实施设计

- NodeStore 直接定义平台默认 Task 并事务初始化；新增一次性迁移标记，移除模板生成器。读取/保存删除 template_id 元数据，不改历史 TaskRun 快照。
- 创建和更新统一走 task/prepareTask：新建仅 script、来源固定 custom，更新保持来源及类型；平台来源删除返回冲突。AI 提案准备与批准复用该边界。
- 保留有效任务编译、原生配置下发、指标覆盖优先级与脚本队列。待配置原生任务不启用对应 Agent 处理器。
- Web 移除模板请求、页签、创建选项与无用样式；新建直接脚本，既有原生任务继续展示专用配置。来源展示“平台默认 / 用户任务”，默认行只编辑与启停。
- 本轮移除模板元数据可能改变旧定义 revision，旧预览和自动重试按现有版本检查安全拒绝；普通已排队或运行中的执行继续沿用已审阅快照，不自动重放，单次消费记录保留。不得为保持旧模板协议增加第二套目录。
- 同步 README、使用指南和 system-design 第27节及 Doca 对应章节，保留无关内容和原生图块。独立审查迁移、权限及原 SDD 048 回归。
