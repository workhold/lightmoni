# 主机管理网页 SSH 终端

管理员在主机管理点击“登录终端”，在弹出窗口内真实登录已登记主机，输入命令并实时查看输出。支持终端颜色、交互程序、Ctrl+C、窗口大小同步、全屏、主动断开及重新连接。一个有效私钥时自动连接，多个时明确选择。

只使用后端保存的直接 SSH 私钥和已确认的主机公钥指纹。浏览器和模型不接触私钥；终端属于管理员本人，AI 工具继续使用固定安装预检和人工审核的安装流程。本次扩展允许管理员通过终端手动执行命令，不为模型增加任意 shell 工具。

## 验收
- 管理员可打开小窗、登录、执行多条命令、查看 ANSI 输出，使用 Ctrl+C，调整窗口后 PTY 尺寸随之变化。
- 主机/凭据缺失或过期、主机指纹不匹配、认证失败均显示明确错误；不把原始异常或密钥返回浏览器。
- 普通成员、未登录、跨站 Origin、其他用户/其他登录会话、重复使用的连接入口不能连接；不能提交任意主机地址或秘密绕过已登记主机。
- 关闭窗口、离开页面、浏览器断开、凭据撤销/过期、注销/降权和平台退出都会释放 SSH/PTY。10 分钟无输入或最长 30 分钟后自动断开。
- 每台主机最多一个终端，和安装预检/部署互斥。连接期间不能改目标或删除主机；撤销所用凭据立即终止终端。
- 限制终端消息大小、连接数量和输出缓冲；命令和终端输出只在当前窗口中显示，不持久化、不写日志、不发送给 AI。审计仅记录操作者、主机、凭据 ID、时间、状态和结束原因。
- 界面中英文、窄屏和全屏可用；有真实 PTY/SSH 与浏览器验证证据。
