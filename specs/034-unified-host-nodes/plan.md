# 设计

前端统一导航和工作区，以主机记录与 Agent 独立身份的显式关联聚合展示。复用既有主机 SSH/安装/卸载控制器和任务编辑器，避免再造一套生命周期逻辑；节点独立接入不伪造 SSH 主机记录。旧路由作为兼容入口，保留深链参数和默认首页偏好。

新增节点生命周期元数据表，节点移除使用事务保存归档操作者/时间/原因并撤销独立 control/data 凭据。身份和凭据历史不物理删除。控制认证、数据认证、任务派发及节点展示遵守归档状态；显式检查未结束任务与卸载占用，操作幂等。共享 Key 节点不能通过全局撤销 Key 影响 SDK；无法证明独立凭据时拒绝完整移除并提示迁移。

主机关联通过固定只读 Agent 身份探测复用现有 SSH 互斥和指纹验证；目标或凭据变化后拒绝写入，不能抢占其他主机的绑定。MVP 沿用当前一条主机记录关联一个 Agent 的约束，不冒充已实现一主机多实例管理。

沿用宿主机独立 systemd 安装器。未来独立容器或 DaemonSet 可单独部署；sidecar 在业务部署配置中显式添加，不默认改写业务镜像，也不把容器权限当作宿主机权限。本轮统一页面和生命周期不引入新的容器部署器。

本地验收使用单独 SQLite/状态目录、loopback 端口与演示数据。移除演示节点使用真实平台 API；SSH 预检/安装卸载只验证现有隔离夹具，不对演示地址建立真实连接。
