# 验收记录

## 范围与实现

延续 PR14 的主机列表删除和导航改进，统一“主机与节点”入口，以三个页签复用既有主机生命周期、监控任务和任务标签编辑器。显式 `agent_id` 聚合已关联记录，独立 Agent 不要求登记 SSH。成员只读取节点与监控任务，不请求管理员主机或凭据接口；角色切换时立即隐藏旧管理窗口。

新增管理员固定只读 SSH 身份核验关联，拒绝身份不符、已占用绑定、未结束安装/卸载/节点任务、过期或撤销凭据。返回前在事务中重新核对状态；两个主机并发核验同一 Agent 仅允许一个关联成功。核验命令不接受用户参数或任意 shell；原始 SSH 错误不进入响应或日志。

节点移除在一个 SQLite 事务中保存身份墓碑、撤销 control/data 凭据并写审计，保留主机记录和历史。控制、数据、任务与旧共享 Key 降级路径均拒绝已移除身份；慢上传和并发 writer 均有回归。历史查询只返回禁用配置和空任务列表，不编译当前任务。移除不同于卸载远端 Agent；既有受审阅卸载流程继续使用。
