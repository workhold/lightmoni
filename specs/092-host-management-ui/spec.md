# SDD092 主机页操作与展示

## 目标

让用户快速识别主机、Agent 与管理权限，并完成常用操作。基于已合入的 SDD087，整理展示和入口，不改变安装、审批、凭据或执行协议。

## 交互要求

- 主机列保留用户名称、SSH 目标与有效服务地址三层概览；平台 ID、Agent ID、系统主机名、来源时间及原始网卡放主机详情。
- 管理状态使用真实 Agent 心跳、SSH 凭据配置和 Docker 环境观测；配置了 SSH 凭据不等于已建立连接，无可靠绑定时不推测 SDK 在线状态。
- Agent 版本、更新状态和操作进度合并展示；已移除/卸载的记录只能标作上次发行，不得暗示仍在安装运行。
- 常用操作直达，Agent 维护与主机设置分组；保留逐项能力门禁、账号修复入口及现有确认。待审批、运行中与结果未知的操作有可见继续/核对入口。
- 复选框选中后展示批处理工具栏；删除主机、移除身份保持批处理入口。筛选变化清除不可见选择，批处理仅作用于明确选中的当前主机。
- 支持名称/SSH 地址搜索、标签筛选、中英文和窄屏；完整信息仍可在详情访问。

## 验收

以隔离假主机验证布局、菜单目标、能力门禁、账号不足、未知结果、选择与筛选、长名称/IPv6、中文/英文及桌面/窄屏。无需再次向生产或真实 SSH 派发操作。

## 架构影响

不适用。仅前端视图、操作分组和文案调整，沿用现有 API、身份、审批和审计路径；不改写系统设计或 Doca。
