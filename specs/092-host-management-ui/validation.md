# SDD092 验收记录

日期：2026-11-04。基线为 `origin/main` 的 `ea75504`（已合入 #83）。

## 本轮范围

本轮仅优化主机页的展示、搜索、操作分组和详情导航，不修改服务端、SSH、Agent、凭据、审批或审计契约。系统设计与 Doca 同步不适用；线上未部署，也未再次操作 vchive。

此前的单主机现场回测见 [SDD087 现场验收](../087-agent-permission-boundaries/live-validation.md)。核心链路通过不代表全平台所有场景完成：真实跨版本升级/回退、多主机并发、跨时区调度和外部 MCP 端到端仍需后续专项验收。

## 界面验收

使用真实前端组件与本地隔离 API，包含完整管理、仅监控、缺凭据、首装未知、卸载未知、已移除发行、长名称及 IPv6 六类模拟主机。没有生产代理或 SSH；写请求一律拒绝。最终证据记录的写请求次数为 0。

已检查：

- 五列主列表，以及主机名称、SSH 目标、有效内外网服务地址的概览；没有把平台连接来源或容器地址推断为服务入口。
- Agent 运行模式、凭据配置和 Docker 环境分开展示；已移除的 Agent 只标记上次发行。
- 勾选显示批处理栏，筛选会剔除隐藏选择；搜索无结果有明确提示，标签筛选保留 URL。
- Agent 维护和更多菜单保留原入口、逐项禁用原因；缺少凭据时仍可打开部署表单并补充 SSH 账户。菜单点击关闭，Esc 收起并返回触发按钮焦点。
- 首装和卸载未知结果打开原记录，不重复派发；权限操作直达权限标签页，网络详情保留系统主机名、来源、时间和原始网卡，操作记录保留安装/卸载/更新历史。
- 只读角色不展示 SSH 管理与生命周期按钮，使用平台主机 ID；没有 SSH 地址字段时搜索正常。
- 中文、英文、深色主题与 390×844 窄屏。窄屏页面宽度/可滚动宽度均为 390px，表格自身为 336px/1144px；详情位于视口内，标签可达、内容可滚动。

最新源码上的 16 个定向断言通过，见 [机器可读报告](evidence/ui-report.json)。报告保留早先因热更新中断、不可操作的辅助功能选项、旧模块缓存及收起动画时序产生的失败尝试，并记录对应复测结果；没有将这些尝试从原始记录删除。最终使用最新模块，菜单按实际隐藏状态判定。
