# 界面说明与验收

存量运维管理页继续使用现有 Ant Design、lm-ops-panel、灰蓝色工作台和紧凑表格，不探索新风格。新增内容位于仓库部署和对外发布之间，主任务为选择部署与镜像、读取版本和引用应用；危险清理采用次级红色描边按钮并确认整个仓库范围。

状态覆盖：仓库无镜像、镜像无版本、查询加载、错误重试、分页、使用中/未使用/待核查、清理排队、完成、部分失败、unknown。切换请求以序号忽略旧结果，清理跨页面刷新通过持久 run 恢复。窄屏筛选改为单列，表格在自身内部横向滚动。100% 与 200% 截图保存于 evidence。

交互反馈复用 Button loading、Table Spin 的加载过渡、Modal 的打开关闭三处现有组件行为，没有新增自定义装饰动画。截图不能证明动效质量，本次没有额外制作录屏。删除重复解释，只在确认框保留清理范围、引用边界、不可恢复和磁盘回收说明。控件图标隐藏辅助标签，主按钮有稳定的可访问名称。

浏览器脚本验证部署选择、镜像筛选、分页、引用应用、空镜像、请求失败/重试、取消不删除、全仓库清理载荷、排队防重复、结果刷新与刷新后持久结果、中英文。连续三次通过记录见 ui-pass-1/2/3.json。服务与接口为隔离的前端契约 fixture；真实 Registry 协议和中心授权/围栏分别通过后端及本地独立 Registry 验证。
