# Feature Specification: 中心内外网地址同步与直报统一

**Feature Branch**: `codex/050-center-endpoint-discovery`
**Created**: 2026-10-31
**Status**: Implemented and validated
**Input**: 管理员登记中心内网IP和端口；SDK、Agent查询并同步中心内外网endpoint，内网优先、公网备用；移除SDK连接Agent。

## User Scenarios & Testing

### User Story 1 - 管理地址并更新客户端（Priority: P1）
管理员在既有上报地址页区分内网、公网，修改内网IP和端口后，运行中的客户端自动获得变更，无需重新部署。
**Independent Test**: 保存地址、启动客户端、替换内网地址；一分钟内后续上报进入新内网入口。
**Acceptance Scenarios**:
1. 管理员保存完整地址和用途后可刷新回读；普通成员不能写入。
2. 原内网入口失效，公网仍可访问时，客户端通过公网得到新地址并重新选择内网。

### User Story 2 - 内网优先及公网恢复（Priority: P1）
SDK和Agent各自从所在网络选择可达的中心入口。
**Independent Test**: 两个HTTP入口连接同一中心；内网关闭时后续请求走公网，恢复后重新使用内网。
**Acceptance Scenarios**:
1. 内网可达时，SDK遥测和Agent控制/数据请求使用内网。
2. 内网拒绝连接或超时后保留原请求身份，下次重试使用公网；已发出的写请求不在同次调用内改投。
3. 查询失败保留可用地址；没有新机制的旧中心仍接受显式地址直报。
4. 不同中心身份或跳转地址不接收客户端凭据。

### User Story 3 - 仅直报中心（Priority: P1）
接入配置、源码、示例和指南统一为SDK直连中心；Agent仅接收自身采集与任务产物。
**Independent Test**: Agent旧SDK遥测和配置代理路径返回404；四种发布SDK完成中心直报。
**Acceptance Scenarios**:
1. SDK不再隐式默认连接本机4318，不再提供agent/auto模式或local token配置。
2. 移除Agent公开SDK接收与配置代理，Agent内部采集、持久队列和诊断正常。
3. 同集群Nginx仅使用登记的内网地址，按集群内网互通约定处理，不加入公网备用。

### Edge Cases
地址为空/重复/非法端口、IPv6、旧记录缺少用途、无SDK密钥的豁免表、中心不可用、地址删除、超时取消、响应过大、中心身份不符、重定向、并发查询、未知上报结果均须有界处理。

## Requirements
### Functional Requirements
- **FR-001** 管理员登记完整中心URL（包含内网IP和端口），明确internal/public用途，沿用现有权限与最多20个地址限制。
- **FR-002** 客户端保留显式中心引导地址，查询中心发布的带版本地址清单；内网地址变更无需重新发布应用。
- **FR-003** 当前发布的Go、Node/浏览器、Python、Rust SDK与Agent使用相同发现契约，提供显式刷新操作；常态30秒刷新，首次上报前可发现。
- **FR-004** 内网优先，公网备用；缓存成功选择并有界冷却；失败的传输只影响下次请求，稳定批次ID及正文不变。
- **FR-005** 地址探测不携带秘密，核对同一中心身份后才发送凭据；不跟随重定向，不关闭TLS验证，不输出秘密。
- **FR-006** 同步读取兼容现有SDK密钥、Agent独立控制凭据与已启用豁免表；旧中心404时保留显式地址直报。
- **FR-007** 完整移除SDK→Agent入口、配置代理、示例和相关测试；Agent自身采集持久队列保持可用。
- **FR-008** 同集群Nginx后端固定内网，公网地址仅用于外部入口；不隐式复用SSH地址作为已配置内网的替代。
- **FR-009** 更新仓库和Doca系统设计并回读；验收明确隔离HTTP测试与真实公网网络的区别。

### Key Entities
- 中心地址：稳定ID、名称、完整URL、内网/公网用途；管理员维护。
- 地址清单：中心稳定身份、修订、最新地址与刷新间隔。
- 客户端选择：引导地址、当前入口、最近同步时间及失败状态，不包含凭据。

## Success Criteria
### Measurable Outcomes
- **SC-001** 四种发布SDK和Agent均验证内网首选、失效后公网恢复及更新地址后回切。
- **SC-002** 管理员更新地址后，在线客户端在一分钟内的后续请求采用最新可达内网入口。
- **SC-003** 中心身份不符与重定向测试中，候选入口收到的凭据数量为0。
- **SC-004** Agent旧SDK接收和配置代理接口全部拒绝，独立采集上报通过回归。

## Assumptions
公网引导地址长期可达；若全部已知入口同时失效，需要运维修复引导配置。所有候选指向同一中心与去重存储。普通生产连接使用有效HTTPS；显式登记HTTP适用于受信内网与本地验收。现有历史SDK语言不新增发布支持，但清理其Agent默认地址和指南。不改变Nginx同集群路由或用户公网DNS策略。
