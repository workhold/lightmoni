# 工作区紧凑页首

状态：实施中。2026-11-08。

用户要求删除每页内容上方占用较高的重复标题区域，将右侧按钮合并到下方内容区域。

验收：应用、网站、集群、域名、证书等运维页不再显示独立大标题，日志/刷新与现有筛选和创建动作同栏；主机、SDK、设置、镜像源、私有仓库、连接凭据、数据管理、服务部署、MCP和监控大盘列表同样压缩重复页首。对象详情保留对象名称和返回入口，以紧凑工具栏呈现；独立登录和授权确认页保留必要标题。保持动作、过滤条件、权限、加载与失败重试行为。桌面与390px窄屏可用，中英文和200%阅读不产生按钮重叠或页面横向溢出。

架构同步不适用：仅移动现有展示节点与样式，不改变组件职责、数据/控制路径、凭据、协议、存储或部署拓扑；不修改系统设计文档。
