# 前端加载契约

本 SDD 不改变 HTTP API、凭据、文件会话或容器任务契约。

| 用户阶段 | 允许载入的主机页模块 | 文件/API 行为 |
| --- | --- | --- |
| 打开 `/machines` | 主机页及其静态依赖；不含文件/容器/终端弹窗、Monaco 和 xterm | 沿用原 `/machines`、Agent、标签读取；不因模块加载执行 SSH |
| 打开文件管理 | 载入文件弹窗；编辑器继续延迟 | 按 SDD 131 创建文件会话并取得初始目录 |
| 浏览目录 | 不载入 Monaco | 沿用同一文件会话列目录 |
| 打开文本文件 | 载入 `CodeEditor`/Monaco | 沿用文件读取、草稿、版本与保存契约 |
| 打开容器面板 | 载入容器弹窗；不含 Compose 子弹窗和 Monaco | 沿用容器清单/操作契约 |
| 点击接管已有 Compose | 载入 Compose 子弹窗及编辑器 | 沿用 Compose 接管与配置校验契约 |
| 打开 SSH 终端 | 载入终端弹窗和 xterm | 现有详情读取、有效默认凭据的自动连接及关闭时清理会话的契约不变 |

构建文件名继续由 Vite 内容哈希决定。HTML 与资源缓存头按 SDD 131 保持，不新增客户端持久状态。
