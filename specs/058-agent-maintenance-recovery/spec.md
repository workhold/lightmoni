# Agent 维护、恢复卸载与离线交付

## 目标与场景

已安装 Agent 的凭据在平台缺失时，当前标准卸载报“不是本平台已登记的独立凭据节点”。需要保留标准核验，同时让管理员通过已登记主机的固定 SSH 目标恢复卸载。检查安装、升级、回退、卸载与重新接入闭环，修复实际缺口。先写规格，再实现。

## 要求

- 标准卸载仍要求已登记 Agent 身份；另提供明确选择的“SSH 恢复卸载（强制）”，记录原因、操作者、固定目标、远端身份与程序/数据证据，再审阅执行。恢复仅放宽平台登记完整性，不能忽略其他主机归属、任务与生命周期锁、SSH 主机指纹或路径安全。
- 恢复支持本平台没有凭据、没有绑定、远端身份文件缺失/损坏、程序部分残留。远端有效身份若已绑定其他主机，拒绝。远端证据变化必须重新计划，不能在 apply 静默接受。
- 默认仅移除固定服务与程序目录，保留配置/身份/缓存；可在生成计划前明确选择清除 Agent 配置和数据，审阅清除路径。此选择允许卸载后重新通过登记主机进行全新接入，不静默放宽 fresh 保护。任何模式均不删除业务数据、系统账户或任意请求路径。
- 仅撤销确属当前主机且已核验的实际 Agent 凭据；恢复时不因旧绑定、损坏身份或 SSH 目标相同而撤销其他身份。回执分别报告远端移除、数据策略、凭据撤销范围；强制卸载不等于删除平台主机/节点记录。
- 卸载待审批、执行中和 unknown 阻止新的有限任务提交、领取、调度、自动重试；主机 ID 和实际 Agent ID 双维互斥。已有任务和本地未完成标记阻止卸载。心跳和连续遥测保留用于观测。
- SSH 派发后断连或重启记 unknown，仅只读核对，不自动重放；核对可显式选当前有效 SSH 凭据。浏览器创建计划失联后先恢复持久记录，不能重复创建。
- 管理员可下载无秘密、带 SHA256 的固定手动卸载脚本，无需 enrollment token；新安装同时在主机固定位置保存脚本。脚本脱离平台可执行，默认保留数据，显式 --purge 才清除数据。相同任务、服务归属、固定路径与符号链接保护适用；幂等处理已移除与部分安装。
- 升级/回退保持受管身份、固定发行与校验、目标架构、审批、锁、unknown 核对和回退边界，不提供强制更新未知身份。

## 验收与范围

覆盖截图场景、缺失/损坏身份、部分程序、purge 后重新接入前提、异主机身份、审阅后证据变化、任务派发竞争、断连核对、下载鉴权、离线脚本与界面防重。隔离 shell/SQLite/HTTP/浏览器 fixture 不冒称真实 SSH/systemd 验收。本次不发布镜像、不操作生产和 vchive。
