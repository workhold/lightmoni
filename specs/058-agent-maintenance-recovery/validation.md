# SDD058 综合验收

## 问题与结果

截图中的错误复现为：远端已安装 Agent，但本平台缺少该 Agent 的凭据记录，标准身份核验拒绝卸载。新增独立的 SSH 恢复卸载，不放宽标准模式，也不将外部或损坏身份自动绑定。覆盖缺失/损坏身份、程序残留、固定目标快照变化、精确撤销、显式清除后重新 enrollment，以及派发后未知结果只读核对。

任务互斥补齐两条通路：TaskRun 的提交、领取、定时派发、自动重试按主机和实际 Agent 双维屏障；AgentJob 对恢复时实际身份为空/不同的主机增加绑定维度与事务内复验，防止原身份仍在派发任务。待审批、执行、unknown 均阻塞，取消后恢复；已有任务不被强杀。200 个被卸载屏障挡住的失败任务不会饿死另一主机的自动重试。

独立审查发现停服后断连的恢复卡死：原程序完整但 service_running 已变化，旧比较无法从 unknown 退出。修复为只允许此服务运行状态变化，其余审批程序/身份/数据证据保持严格一致；记录 failed、service_stopped，不重放、不撤凭据，可重新审阅。

## 验收限制

本轮未连接生产或 vchive、未修改线上服务、未发布镜像或构建完整双架构发行包。shell 测试重写固定路径并模拟 Linux root/stat/systemctl；HTTP/SQLite 与已有本机 loopback SSH fixture 验证协议和状态，不等同于新流程的真实 Linux/systemd 主机验收。live release、ClickHouse 等未配置环境的跳过保持明确。手动卸载只改变目标主机，不证明平台凭据已撤销。网页本地摘要校验需要 WebCrypto（HTTPS 或 localhost），下载文件也可用 sha256sum 核对。
