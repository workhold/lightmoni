# 设计与实现

- 后端在 machine_credentials 增加策略来源与清除元数据，使用幂等列迁移区分历史托管；新建不包含秘密的 machine_credential_events。统一清理入口原子清空密文、标记撤销/原因、取消引用已失效凭据的待执行计划。管理员身份与主机绑定保持不变。
- 临时私钥可检查/终端/部署，短期内支持检查→审阅→安装；密码结束即消耗；托管私钥只有明确确认后创建。每 30 秒及读取/使用前清理，Module.close 清除 timer 并接入 app 模块生命周期。
- 安装流程先核对 enrollment active + agent_id，成功事务记录结果并清理本机临时秘密；没有激活证据不清理未过期私钥。当前运行流程不被清理误标取消。
- 机器摘要新增有效 SSH/私钥数量、SSH 恢复通道以及 capabilities，原因码按 busy / 连接方式 / 主机指纹 / 凭据类型明确分类；部署能力不再按任意凭据计数。
- 前端添加独立策略与期限选择、托管确认、历史托管标签、清除状态和置灰说明。切换类型/策略清空秘密与期限避免跨模式复用；无秘密字段的脚本模式不显示密码/私钥框。
- 核验包含 fake clock 期限边界、重启迁移、启动/定时清理、活跃终端、部署成功/失败、托管保留、权限和脱敏，浏览器验证中英表单与按钮引导；全量 runtime 测试及 typecheck/build。
