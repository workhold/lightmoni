# 助手工作台设计

使用单一聊天栏组织对话与输入。桌面侧栏显示搜索及会话，宽屏需要时打开产物侧栏。窄屏和嵌入面板以抽屉承载侧栏。标题和分类编辑集中在会话页头入口。新对话显示输入框和四个可编辑的监控任务起点。

复用现有流式事件、请求 ID、掉线恢复、审批卡片、上下文收集和 MessageScroller。让生成状态和停止控制跟随输入栏，以单一状态提示区反映实际进度。常规步骤逐级展开，重要审阅结果与错误保留在对话内。

全页通过查询参数同步已选会话。只在用户选取、新建或删除当前会话时更改地址，并用选择版本隔离过时的详情回包。会话间切换时保留当前前端草稿和附件。键盘命令只触发界面现有操作。

大盘草稿在展示前通过大盘域的规范化函数。无效网格由现有默认布局规则补齐。Web 审阅入口也对已经存储的旧草稿清除无效网格，供现有保存接口补齐。

架构影响不适用。布局和交互使用现有视图状态。大盘草稿沿用既有大盘域和审批边界。中心 API、流式事件和存储保持既有契约。
