# 实现设计

从最新 origin/main 建立独立功能分支，隔离当前 SDK 工作区。将解析抽屉及单条编辑逻辑收拢到 `web/src/app/ops/DNSRecordsDrawer.tsx`，沿用 Ant Design 表格、复选框、表单和确认窗口。OperationsPage 只传入当前域名及统一刷新方法。

表格以厂商字符串记录 ID 为键（不转换为 number），跨页保存记录快照；请求序号屏蔽过期分页响应。搜索、同步和关闭域名清空选择。批量窗口固定域名 revision 和目标快照；创建按共用字段生成逐 value 记录，修改只覆盖显式选择的 type/value。预览始终展示本次准确输入。

独立批量模型负责生成输入、限制数量、判定 run 回执和串行执行，通过同步 ref 防止重复提交；执行期锁定输入及关闭动作，提供停止后续，终态窗口展示每条结果及汇总。响应丢失视为未知，授权/版本冲突停止剩余目标，不重发请求。整个批次完成后刷新 overview 与记录查询；保留失败项以供检查。

批量窗口固定标题与操作按钮，仅正文滚动，确保桌面与窄屏长表单的确认、关闭和停止后续始终可见；预览及结果表独立于禁用表单，保留结果颜色和可读性。

验证：模型测试覆盖多 value、保留字段、大整数 ID、部分失败、未知/待回读与停止；Playwright 隔离 HTTP 夹具覆盖跨页选择、取消、创建/修改/删除、业务失败、防重、搜索、末页回退、成员、中英文与窄屏；运行前端类型检查和构建、既有云 DNS 契约回归。夹具不写真实云 DNS，验收如实记录边界。

架构同步：不适用，理由见 spec.md；只组合既有接口，不改变系统职责及信任边界。
