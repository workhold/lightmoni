# 域名托管批量解析操作

**分支**：`codex/051-dns-bulk-record-actions`
**日期**：2026-10-31
**状态**：已实现并完成隔离验收，待 PR 评审

## 用户需求

域名托管的解析记录支持批量勾选、删除、修改解析类型和 value；支持同一个主机记录、类型、线路一次填写多个 value 批量创建。

## 行为与验收

1. 管理员在解析记录列表逐条勾选或全选当前页；选择可跨分页，显示选择数量及清空入口。切换域名、搜索或同步后清空选择，防止混入旧目标。单批最多 50 条。
2. 批量删除先展示固定目标（主机记录、类型、value、线路），确认后逐条删除。取消不发请求；执行时不能更换或关闭目标窗口，同步防重。
3. 批量修改可仅修改类型、仅修改 value 或同时修改，两者都不选不能执行。逐条展示原值和新值，保留各记录 ID、主机名、TTL、线路、优先级、权重和启用状态。
4. 批量创建共用主机记录、类型、线路、TTL、优先级与启用状态，value 每行一条。忽略空行、合并完全相同的 value，其他字符原样保留。预览生成数量及每条记录，最多 50 个不同 value；超过限制、缺少必填字段不能执行。
5. 三种操作均复用已有逐记录 API，串行执行；分别显示待处理、执行中、成功、失败、待回读和结果未知。单条业务失败不阻止后续，鉴权或版本冲突停止后续；不自动重试。停止后续不取消已发出的请求。
6. HTTP 202 中 failed/unknown 不能算成功；verifying 或 verified=false 显示待回读；通信中断显示未知并提示同步核对。只有已确认成功才显示成功，DNS 缓存传播仍需等待 TTL。
7. 执行完成统一刷新列表，成功修改/删除项移出选择，失败和未执行项保留以便核对。删除末页后回退到有效页，刷新失败明确显示错误。
8. 保持单条创建/编辑/删除/启停、搜索和分页，中英文与 390px 视口可用。关闭页面不保证剩余批次继续执行；历史回执沿用现有运维记录。

## 架构影响

不适用。浏览器内组合现有 DNS 单记录操作，服务器仍通过相同的管理员授权、revision、confirmed、作用域校验、云平台凭据及运维回执执行；没有新增 API、后台任务、存储、协议、凭据或部署路径。无需改写 `docs/system-design.md` 或 Doca 系统设计基线。若实现范围改变，重新判断并同步双端设计。
