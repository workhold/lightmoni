# SDD 025：左侧导航按用途分组

日期：2026-10-27。分支：`feat/grouped-sidebar-navigation`。

## 用户需求

将平台左侧平铺的工具入口按用途分类，主机管理、服务部署和节点助手集中到“运维工具”，方便用户查找相关能力。

## 验收要求

- FR-001 使用五组导航：工作台（概览、AI 助手）、监控分析（监控大盘、日志探索、告警中心）、运维工具（主机管理、节点助手、服务部署）、数据与接入（数据接入、数据管理）、系统设置（个人设置、管理后台）。保留已有页面名称与地址。
- FR-002 展开导航显示分组标题和链接；收起导航保留相同顺序的图标、组间分隔、链接名称提示及可访问名称。分组不增加页面跳转或第二次点击。
- FR-003 继续支持中英文切换、深浅色、已有导航展开偏好、窄屏与短屏滚动。当前路由的唯一入口高亮并带 `aria-current="page"`；子路由沿用父入口。
- FR-004 主机管理、服务部署、管理后台仅管理员可见；节点助手继续对成员开放只读能力。过滤后没有可见入口的分组不渲染。菜单可见性不能替代现有路由和后端权限检查。
- FR-005 导航定义集中维护分组、中文名、英文名、路径、图标与管理员标记，顶部页面标题和 AI 当前页上下文沿用同一份入口定义。

## 范围与架构影响

仅调整 Web 导航呈现及已有页面的入口可见性，不新增后端能力或自动部署方式，不更改路由、接口、数据/控制路径、认证或部署拓扑。因此系统架构文档与 Doca 同步不适用。

## 完成标准

完成前端生产构建、中文和英文导航、管理员和成员入口、当前页高亮、展开/收起及窄屏视觉验证，记录真实覆盖；仅向 GitHub 推送并创建待审 PR，不自动合入。
