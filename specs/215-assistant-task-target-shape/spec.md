# SDD 215：助手扁平任务目标形状

## 背景

0.1.25 只归一化了顶层 `host_ids` 到任务内目标，但实际模型在 `task` 外层同时携带扁平 `host_ids`，任务内省略目标。该形状仍被判定无效，诊断任务提案继续失败。

## 目标

1. 助手任务创建/更新接受任务外层 `host_ids` 与 `task` 并存的扁平形状。
2. 保存的任务与旧提案索引都保留同一扁平目标列表。
3. 拒绝同时出现扁平目标和详细目标的冲突形状。
4. 仍必须人工审批；不会创建任务或派发执行。

## 非目标

- 不改变任务存储表。
- 不放宽主机授权或审批要求。
- 不处理派发、取消和重试的既有契约。

## 验收

1. 扁平 `host_ids` + `task` 可生成待审批提案。
2. 提案内任务 `host_ids` 与扁平目标一致。
3. 旧提案索引可读取该任务目标。
4. 详细目标和扁平目标同时存在时拒绝。
5. 既有任务提案测试通过。
