# Validation Guide

1. Runtime/Web typecheck；运行 PNG 验证与平台 HTTP/SQLite 定向回归。
2. 使用真实 Router/SQLite 验证带图创建事务、GET 字节/权限/ETag、替换/删除版本冲突、中心重新打开后的持久化；配置版本、修订和任务数量不变。
3. 启动 cluster-ui-server 和 Vite，运行新增浏览器脚本：31 个品牌图片完整，实际创建、刷新读回、替换、取消、移除、失败输入保留；中英文、深浅色、390/1440px。
4. 主 Agent 实际查看代表截图；不把截图保存成功等同于视觉通过。
5. 仓库/Doca 新节保存并以最新版本回读目标文本和原生图；记录验证限制、PR 与用户授权发布结果。
