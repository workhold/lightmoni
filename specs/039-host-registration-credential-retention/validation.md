# 验收记录

日期：2026-10-29。用户要求登记时直接可见登录秘密及保存时长，统一默认 6 小时，并允许永久保存。本轮通过正式 GitHub PR16 更新，不自动合并。

## 最终行为

“登记主机”由两步改为同一表单，一打开即可看到主机名称、地址、SSH 端口/用户名、登录方式、密码或私钥输入、保存时长和独立主机公钥指纹。默认密码登录、保存 6 小时，可选 1 天、7 天、30 天、自定义或永久；同一保存时长作用于所选登录秘密。主机公钥指纹用于验证远端主机身份，不是登录凭据，不能代替密码或私钥；主机 ID、名称、指纹作为资产元数据保留。

有限凭据采用 managed，默认 21600 秒；表单的明确保存动作提交 confirm_managed=true。永久凭据要求选择 permanent 并主动勾选确认，API 校验 confirm_permanent=true，禁止同时传有限 expires_in_seconds。expires_at='' 表达没有固定期限，仅在 permanent 策略下有效；不伪造远期日期。有限托管和永久凭据不因 Agent 激活提前清除；永久仍可随时撤销，建议优先短期保存。

统一有效性判断已用于后端到期清理、能力统计、删除保护、终端、检查、安装/卸载与 AI 脱敏凭据选择，以及前端各选择器与批量操作。永久密码可复用，不会当作一次性密码清除。撤销清空密文并关闭关联终端、取消待执行计划；终端自身空闲/总时长、SSH 主机指纹、预检 TTL 及计划审阅限制仍生效。

保存凭据失败时保留已登记主机 ID、锁定资产连接字段并就地重试，不重复登记、不执行 SSH。可明确选择仅登记并稍后配置。同一登录方式更改时长保留已输入秘密，但重置自定义秒数/永久确认；切换登录方式或关闭窗口清理秘密。新增凭据复用相同表单。历史 temporary/one_time 凭据仍按其既定短期/单次使用规则清除，已有凭据期限不自动改写。
