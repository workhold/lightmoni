# SDD 036：主机入口与接入状态

状态：设计提案，待评审与实现。日期：2026-10-28。

本次交付需求、HLD/LLD、拟议接口、页面草图及实施任务，不改变运行代码、SDK 协议或线上数据。仓库/Doca 系统设计新增的内容明确标为“目标”，不得视为已有功能。继承 SDD 034 的可信 Agent 关联、权限和生命周期，以及 SDD 035 的批量操作。

## 目标

用户只需理解“主机”和它已接入的能力。左侧入口、页标题和首个页签统一称“主机”；Agent 是主机上的独立执行组件，SDK 是业务进程内的遥测库。主机可以只接入 SDK、只接入 Agent、仅登记 SSH，也可同时接入，三者互不作为前置依赖。

## 用户故事与验收条件

1. **一处查看主机。** `/machines`、旧 `/agents`、任务及计划深链继续可用，导航分类抽屉、默认首页偏好及批量复选框保留。首个列表的名称列为“主机”，原“管理通道”改为“接入状态”，并列显示 Agent、SDK、SSH；不以单一红绿点代替整机可用性。
2. **状态有依据。** Agent 显示未接入、在线、心跳超时、已移除或已验证卸载。没有关联只能说“未接入”，不能断言未安装；只有最近一次成功 SSH 检查确认 absent 时，附带“未发现受管安装”和检查时间。SSH 显示未配置、指纹待确认、凭据有效/失效及最近检查时间，不称长期在线。
3. **SDK 独立。** 没有 Agent 和 SSH 的主机也可明确关联 SDK 实例。列表显示未关联、尚无可用心跳、近期上报 N 个实例、心跳超时或状态未知；点击进入实例详情。Agent 离线、移除、卸载不改变 SDK 归属或撤销共享 SDK Key。
4. **多服务多实例。** 一台主机可关联多个服务、每服务多个进程实例。默认只显示近期上报数量和已关联数量，不以历史实例数计算健康比例；没有明确期望副本数时不显示“2/3 正常”。实例详情包含服务、环境、实例 ID、版本、语言、最近事件/接收时间、关联来源和状态原因。
5. **显式归属。** SDK `service`、`instance_id`、`host.id`、hostname、来源 IP、Key 都不单独证明物理主机归属。管理员选择平台实际观察到的实例，明确确认归属；平台部署服务时可生成预填的归属提案，同样由审批确认。SDK 不访问本机 Agent，不新增发现端口或自动签发凭据。
6. **不静默搬迁。** 同一已认证上报凭据、service、instance_id 选择器最多关联一个有效目标；重新关联、Key 轮换、主机合并或服务迁移有 revision 检查和审计，不能因后续自报 host.id 自动恢复已解除关系。实例 ID 默认随机，重启后变化的新实例不能静默继承旧主机。
7. **无数据不等于离线。** 心跳关闭、匿名上报、平台停报规则、断网、查询失败、旧数据补传和时间偏差分别给出明确或未知原因。只有确实观察到过合格心跳且超过期限才能显示心跳超时；不据此断言主机/业务进程已经停止。
8. **权限不扩大。** MVP 主机资产和新增 SDK 归属/摘要接口仅管理员使用；成员继续原有 Agent/任务只读视图，不因改名获取地址、SDK 服务分布、Key 元数据、SSH 凭据或批量写入。若将来允许成员查看主机摘要，另做后端投影与权限评审。
9. **操作有明确范围。** 部署 Agent、卸载 Agent、移除 Agent 接入、删除主机记录、解除 SDK 关联分别命名、说明影响并确认。删除主机预览显示 SDK 关联数量，写入与关联终止在同一事务处理；不删除遥测、不撤销共享 SDK Key、不远程卸载。批量动作仍逐台计划/确认/回执。
10. **不虚构资产。** Agent 独立接入不伪造 SSH 记录；未知部署范围显示“Agent 接入目标 · 主机范围待确认”。已知容器实例明确标记容器，不能根据 hostname 自动合并为宿主机。本 MVP 保留一条登记主机关联一个有效 Agent 的约束。

## 首批范围

- 统一主机命名、三行接入状态、独立的状态原因和时间。
- 管理员 SDK 实例候选、关联/解除/迁移、主机实例详情、有限范围心跳汇总。
- 无 Agent 的 SDK-only 主机通过“登记主机 → 仅登记资产”建立；SSH 为可选配置，不能为了看 SDK 要求虚构 SSH 地址或凭据。
- 平台服务部署输出可预填归属提案，现有部署成功不自动等于 SDK 上报成功。

不包含：CMDB 资源类型体系、自动网络扫描、按 IP/名称归并、全新 SDK 注册/凭据协议、跨主机发现、强进程存活证明、SDK 任意控制、K8s 多层拓扑、主机多 Agent 管理或容器自动注入。

## 架构影响

适用：后续实现需新增无 SSH 的资产登记、SDK 归属历史和状态聚合。设计阶段同步仓库系统设计 13.1 与 Doca，显式保留“目标/未实现”标记；实际架构和原 API 保持不变。实现完成后按验收证据更新“当前”状态。
