# 页面与交互

## 统一术语

左侧“运维工具 → 主机”；页面“主机”；页签“主机 / 监控任务 / 任务标签”。LightMoni Agent 名称保留，“节点”仅在身份/历史等必要技术说明中出现。旧路由与深链不因改名失效。

列表推荐三行接入状态，保持当前信息密度和批量动作，不铺三个独立的大状态卡：

| 选择 | 主机 | 接入状态 | 监控任务 | 最近更新 | 操作 |
| --- | --- | --- | --- | --- | --- |
| □ | prod-web-01 | Agent：在线；SDK：近期上报 2 个实例；SSH：已配置 | 3 个任务 | 15 秒前 | 详情 / 更多 |
| □ | prod-api-02 | Agent：未接入；SDK：近期上报 1 个实例；SSH：未配置 | — | 20 秒前 | 详情 / 部署 Agent |
| □ | worker-03 | Agent：心跳超时；SDK：未关联；SSH：凭据有效，最近检查失败 | 2 个任务 | 4 分钟前 | 详情 / SSH 检查 |

示例为拟议效果，不是当前平台资产或测试成功记录。SDK 状态可点击展开，不能让 Agent 的颜色覆盖 SDK 状态；同一行可以同时出现 Agent 超时、SDK 近期上报。

## 主机详情

复用当前详情容器，按“概览 / Agent / SDK 实例 / SSH 与凭据 / 操作历史”组织；若空间不足实现为右侧宽抽屉，手机改整页。首批不增加新的资源类型菜单。

- 概览：名称、可选资产备注、登记来源与范围；公开资产标识不能当密钥。
- Agent：身份、版本、部署范围、最近控制心跳、任务标签和已支持能力，明确安装/关联证据。
- SDK 实例：服务、环境、instance_id、版本、SDK 语言、状态原因、事件与接收时间、归属来源；默认当前关系，历史切换展示已解除/迁移。显示 SDK Key 名称或截断 ID，不显示 token。
- SSH：配置/指纹/凭据状态与最近检查，检查成功只是该时刻结果。凭据细节和终端仅管理员。
- 历史：归属变更与现有安装、卸载、移除记录分别展示，操作结果未知保留核对入口。

## 关联 SDK

1. 主机详情“关联 SDK 实例”；仅资产主机无 SSH/Agent 也能打开。
2. 选择实际观察到的服务和实例；候选显示认证 Key 摘要、客户端声明 host.id、最近时间及现有归属。客户端声明只有提示作用。
3. 审阅“将此进程遥测归属于此主机”，明确不验证物理位置、不授予远程管理权限；确认后保存。
4. 已在其他主机的实例进入显式“迁移归属”，不以普通关联抢占；旧数据不回填。
5. 查不到候选显示配置 Key、自监控和稳定 instance_id 的说明；查询故障给重试，不显示“没有 SDK”。

## 批量与破坏性动作

继续首列复选框、每批 50 项和逐台结果。命名统一为“批量部署 Agent / 批量卸载 Agent / 批量移除 Agent 接入 / 批量删除主机 / 批量 SSH 安装检查”。部署成功并完成接入才显示 Agent 在线；未关联 SDK 不阻止部署。

删除主机确认分开列出：平台资产/连接与部署历史清理、终止 SDK 归属数量、业务数据和远端程序保留。卸载 Agent 不删除主机、不解除 SDK。首批不做批量 SDK 绑定，避免多主机多实例的隐式排列映射。

## 语言、无障碍和窄屏

中文“主机”对应 Hosts，“接入状态”对应 Integrations；SDK 使用 Recent heartbeat / Heartbeat overdue，而非强存活保证。状态同时有文字与时间，不能仅靠颜色。SDK 计数为有名字的按钮，支持键盘打开详情；关联确认后焦点返回发起按钮。390px 主机卡片可折行，实例表有局部横向滚动，页面自身不溢出；错误/未知不能只用 tooltip 表示。
