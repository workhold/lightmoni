# SDD 212：助手分类删除

## 背景

0.1.20 已支持自定义分类，但分类建议和分组只能新增，不能删除。用户看到不需要的分类后没有清理入口。

## 目标

1. 新对话分类下方提供“管理分类”入口，可查看并删除当前用户可见的分类建议和使用中的分类。
2. 删除前确认影响：有会话的分类会被批量清空分类，对话本身保留并进入未分类。
3. 固定建议分类可以被隐藏；使用该分类的会话清空后，后续新对话不再自动建议它。
4. 正在运行响应的会话不参与批量清理，接口返回跳过数量，避免并发写会话。
5. 删除仅影响当前登录用户的会话分类；不删除会话、消息或附件。

## 非目标

- 不建立独立分类表或跨用户共享分类目录。
- 不做批量移动到其他分类。
- 不改变后端会话存储结构和分类长度限制。

## 验收

1. 候选分类显示删除图标；点击后出现影响确认。
2. 确认后该分类下的非运行会话分类全部变为未分类。
3. 有运行中会话时接口返回 skipped，UI 提示部分会话保留原分类。
4. 隐藏固定建议后刷新页面，该建议不再出现在候选列表。
5. 新建自定义分类、选择既有分类、清空分类行为不受影响。
