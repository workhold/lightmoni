# 发布设计

1. 从已合入 main 的固定提交 git archive 构建，工作区、运行时凭据与未提交文件不进入镜像。
2. 沿用既有 Dockerfile、构建镜像源和锁文件完整性，分别构建双平台并隔离验证。
3. 沿用已核对发布脚本，追加生产共享机器地址与 Agent 本机复用模块检查。凭据仅经保护的 Docker helper 或权限0600临时测试环境提供。
4. 上传前校验 OCI blob SHA256、已测试 rootfs/config；固定标签不同内容拒绝覆盖，latest 变化时拒绝覆盖。远端回读、独立 CLI 拉取两个平台，核对全部旧标签。
5. 清理本次测试容器/卷/网络/临时凭据，发布 GitHub Release，默认镜像与证据经 PR 合入。
