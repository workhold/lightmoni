# 029 独立展开导航与默认首页

## 目标

左侧分类无需反复重开；用户进入平台先到 AI 助手，并可选择适合自己的默认入口。设置命名为“默认首页”，不使用表示列表排序的“置顶”。同时验证线上主机管理的实际可用范围，修正验证发现的小范围展示问题。

## 需求与验收

1. 左侧各分类可独立展开/收起，打开另一分类或点击其他分类下的页面，不收起已展开项。首次加载仅展开当前页面分类，其余默认收起；整体收起为图标导航后再展开保留本次分类状态。键盘和 aria-expanded/aria-controls 保持有效。
2. 未设置时，访问平台根路径或登录入口默认到 `/assistant`。概览仍可通过导航和固定 `/overview` 地址访问。品牌入口返回用户默认首页。
3. 个人设置的“界面偏好”增加“默认首页”，账户菜单增加直达入口。列表使用当前账号有权访问的导航页面，中英文一致；选择立即保存，不立即离开设置页；可选择 AI 助手恢复默认。
4. 默认首页按账号 ID 保存在当前站点的浏览器存储，不上传后台，不跨账号串用。非法值、无权限页面、丢失/不可读存储回退 AI 助手；写入失败给出明确反馈，不虚报已保存。
5. 从主机、节点、日志、大盘、告警认领/链路、设置等具体链接登录时，保留路径和查询条件。默认首页仅接管根路径、登录入口或未知路径，不覆盖明确深链，不接受外部 URL。
6. 主机能力测试分别记录：线上页面/已有主机的可用情况、本地真实 SSH/PTY、模拟安装路径。不得将模拟安装称为真实安装成功，不为测试重装线上 Agent、修改 SSH 信任或执行业务变更。修正地址复制为显示的主机地址，密码提示区分凭据失效与删除；继续建议用后撤销、避免长期保存。

## 范围边界

不增加主机资源类型、自动执行能力、凭据授权、跨设备偏好 API，不发布新镜像或升级线上平台。本次通过 GitHub PR 交付，线上测试不能代表尚未部署的新前端已经生效。

## 架构影响

不适用。复用现有前端路由和浏览器界面偏好方式，仅调整交互、入口与提示；不改变组件、后台 API、凭据边界、存储系统、数据/控制路径或部署拓扑。浏览器中增加的偏好键不改变既有本地偏好的保管边界。无需重复改写仓库系统设计和 Doca。
