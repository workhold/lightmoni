# 交互契约

- **默认入口**：`/` 和已登录的 `/login` 使用当前账号默认首页；无有效偏好为 `/assistant`。未知路径同样回退，使用 replace 避免重定向堆积历史。
- **概览**：固定路径 `/overview`，与导航的“概览”一致。
- **登录深链**：导航页面本身及其子路由、`/a/:token`、`/traces/:trace_id` 保留 pathname 与 search；`/`、`/login` 和未知路径才使用默认首页。
- **偏好范围**：只接受当前角色可见导航的精确主路径；不接受查询串、片段、外部地址或任意细节页。以账号 ID 命名浏览器存储键；失效值读取时回退，不扩展角色权限。
- **设置反馈**：选择时写入并回读确认后保持在当前设置页，显示成功提示。写入被阻止或静默丢弃时保留原选择；写入后回读失败时只提示“无法确认默认首页已保存”，不宣称原值未改或已经保存。不可读时按统一规则回退 AI 助手。说明“仅对当前账号在此浏览器生效”，默认项为 AI 助手。
- **导航展开**：分类集合彼此独立；路由变化只添加当前分类，不清空其他分类。手动关闭当前分类后，在本路径停留期间保持关闭；切换页面可重新展开所在分类。
- **主机测试**：生产环境不保存新秘密、不修改或删除已有主机、不确认新指纹、不批准安装任务。只读预检/终端仅在已有受信主机与有效凭据允许时进行；缺少条件记录原因，不绕过校验。实际只读命令限定为主机/系统标识，执行后断开终端。
