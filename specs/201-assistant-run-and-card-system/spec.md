# SDD 201：AI 助手会话保活与统一卡片系统

## 背景

AI 助手 turn 仍绑定批准 HTTP 请求；页面切换会中止 SSE，服务器把 turn 标记为 cancelled。工具、代码任务、告警提案、Agent 更新等卡片分别形成不同边框、圆角、状态色和标签样式，视觉上不成体系。

## 目标

1. 管理员确认 turn 后，服务器执行不再绑定 HTTP `AbortSignal`；页面刷新、路由切换或浏览器连接中断都不取消模型和已批准工具执行。
2. 显式停止、12 分钟模型预算和中心关闭仍然终止执行；SSE 断开只切换到持久事件回放。
3. 页面卸载不清空服务器运行；重新进入助手时恢复最近会话，运行中的会话继续轮询并合并持久事件。
4. 建立统一卡片语法：工具执行、代码任务、告警提案、Agent 更新和终端卡使用同一 14px 圆角、边框、浅投影、44px 卡头、状态点和中性状态胶囊。
5. 用户输入保持右对齐、克制的浅色气泡；助手正文保持无卡片流式排版，避免把回答随意装进重卡片。
6. 状态只用运行、成功、失败、取消四类视觉语言，不因工具类型引入随机色卡。

## 非目标

- 不实现跨中心进程或 HA 任务队列；单中心重启仍按现有内存 turn 中止语义处理。
- 不把助手正文变成大卡片，不改变模型协议、工具审批边界或凭据边界。
- 不引入品牌样式复制；仅采用中性、安静、卡片化会话设计原则。
- 不改变 SSE 事件格式或中心存储契约。

## 验收

1. HTTP 请求断开不会中止运行中的模型/工具 turn；显式 cancel API 仍会取消。
2. 卸载助手页面不再主动 abort 活动 turn。
3. 重新进入页面恢复最近会话；运行中的会话按 2 秒轮询持久事件，重复渲染稳定。
4. E2E 验证队列、停止、工具卡片展开、终答、附件、移动端深色布局通过。
5. Web typecheck/build 和 Runtime assistant 回归通过。
