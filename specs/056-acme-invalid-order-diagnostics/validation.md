# 验收记录

本轮包含两项最终行为：管理员查看并下载已保存证书，及恢复失效 ACME 订单时的诊断改进。用户已确认新建订单申请成功；没有对生产域名再次申请、修改 DNS 或声称定位了历史订单的实际原因。

## API 与控制器

Runtime/AI/Web 类型检查通过。平台 API、Store、云证书、可观测性相关测试共 67 项通过（0 失败）。使用真实 Router/SQLite/加密存储和实际生成的 X.509 证书及签名链验证：公开查看不含私钥；四种附件字节和证书/密钥匹配；无链、未签发、错误资源/版本/类型拒绝；成员与跨源请求拒绝；下载 no-store、nosniff、安全文件名；续期切换后旧版本仍可下载；失败续期仍可读取已有材料；普通资源和执行记录继续不含 PEM/私钥。

ACME 夹具覆盖顶层 problem/subproblems、授权挑战原因、缺少原因、辅助读取失败、撤权与版本变化、多域名、完成挑战后的第二次回读失效、后续人工新建订单、步骤终态和脱敏。诊断有界，不存完整 CA 响应，不因诊断读取触发 DNS 写入或自动重新下单。协议依据与边界见 plan.md。

## 界面

沿用现有 Ant Design 抽屉、元数据和标签页。已签发证书在行操作和详情中提供入口；完整链为主下载动作，单证书/中间链/私钥为平行动作。没有额外导航或重复说明；私钥只经附件返回，不回显到 DOM 或 React 查看数据。Drawer 开合、Tabs 切换及按钮 loading 沿用已有组件动效，此局部新增不引入装饰动画。主 Agent 自检，未安排独立评审、不做整站视觉评分。

浏览器使用真实本地 HTTP/SQLite，ACME/DNS 对端为受控夹具，无生产请求。对实际下载文件逐字节核对叶证书+中间链组成完整链，以 X.509 验证签名和私钥匹配；覆盖加载失败重试、下载失败保留、无中间链、详情入口、中英文、明暗主题、390px 窄屏及 200% 缩放等效布局（720 CSS px、2x 像素比例）。连续验收结果见 evidence/ui-1、ui-2、ui-3/ui-report.json；媒体路径由报告指向本机 artifacts/screenshots，媒体不提交 Git。
