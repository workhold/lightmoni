# 交互与接口契约

| 用户动作 | 现有接口 | 等待控件 | 结束状态 |
| --- | --- | --- | --- |
| 打开主机操作 | `GET /machines/:id`，必要时再读取原操作 | 该主机该入口 | 目标身份匹配才打开窗口；失败清理 loading |
| 一键升级 Agent | `POST /machines/:id/agent-updates/start` | 窗口“正在检查并启动”；关闭窗口后主机行继续显示启动中 | 持久操作 ID 进入进度，父页回读后解锁；不确定时仅提供历史核对入口，不自动重试 |
| 继续已有更新 | `GET /machines/:id` 后按新详情的操作 ID 调用 `GET /machines/:id/agent-updates/:operationId` | 主机行“查看/审阅/核对更新” | 校验主机及操作 ID；不调用 `start` |
| 旧计划/回退/核对/恢复 | SDD 045/133 已有 `plan`、`apply`、`cancel`、`reconcile`、`recover` | 正在提交的那个按钮 | 沿用原审批、结果未知及防重放限制 |
| 升级批次 | 现有 `agent-rollouts` 读取与操作接口 | 对应的计划、执行、暂停、继续、取消、刷新或历史按钮 | 其它写操作禁用，完成后读取原批次 |
| 任务、告警及运维手动请求 | 各页面现有接口 | 对应按钮或 Modal 确认按钮 | 成功刷新视图；错误显示并清理等待 |

没有新增或变更 HTTP API。自动轮询仍只读；loading 代表当前用户请求，不能替代持久操作状态。
