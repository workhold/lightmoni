# 实施计划

1. 建立按钮等待状态的交互契约：用户触发的请求对应触发控件、同步防重复、结束清理；后台静默刷新保持安静。
2. 主机列表使用操作与主机 ID 标记入口请求；把现有 Agent 更新摘要的操作 ID 用于直达原记录，避免从隐藏的历史入口绕行。
3. 梳理单机升级窗口的状态层级，把关键目标/影响与技术详情分开，保留一键启动和旧审批、unknown 恢复流程。批次窗口绑定每个请求的独立按钮状态。
4. 修复任务中心、告警响应和运维结果的已知长请求反馈缺口。
5. 用受控延迟的浏览器 fixture 验证 loading、防重复、原操作续接、真实阶段和错误恢复；运行相关既有回归、Web 类型检查及构建，记录证据。

架构影响：不适用；理由见 `spec.md`。无系统设计和 Doca 内容同步。
