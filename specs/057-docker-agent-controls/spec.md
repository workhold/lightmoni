# Agent Docker 即时清单与操作

日期：2026-10-31。分支：`codex/057-docker-agent-controls`。

## 用户故事与验收

### US1（P1）可信的 Docker 清单
主机抽屉区分平台部署和全部 Docker，保留定期采集；采集失败显示安全的具体原因、最近尝试时间和旧清单，不能把失败或未知误报为空清单。Docker 清单查询不得等待应用日志积压。空平台应用但存在外部容器时引导到 Docker 页签。

### US2（P1）立即刷新
点击“立即采集”向该主机已认证 Agent 下发只读任务，展示排队、执行、成功、失败、未知结果；只有新的 Agent 清单到达才显示成功。重复点击复用活动任务，旧 Agent 无能力、离线和任务超时都有明确反馈；后台页面轮询仍只读缓存。正常空闲 Agent 在控制轮询周期加一次 Docker 查询时间内完成，不等待遥测采集周期。

### US3（P2）容器操作
管理员可对该主机最近清单中的容器启动、停止、重启，每次展示容器名称、ID、主机及影响并显式确认。只允许这些固定动作和完整容器 ID；不接受 shell、镜像拉取、删除或凭据。执行器再次验证容器 ID 和当前状态，操作后读取状态和完整清单；未知结果不自动重试。平台容器提示调度器可能恢复期望状态，外部容器操作不将其纳入平台部署。

## 范围与兼容性
沿用 Agent control 凭据、持久任务、租约、审计和结果协议，中心不访问 Docker socket、不回退 SSH、不增加 AI 执行工具。新能力需升级中心及 Agent；旧 Agent 定期心跳兼容且禁用即时操作并提示升级。

## 架构影响
适用：新增 UI→中心→Agent 任务→Docker→结构化回执控制路径和清单来源合并。同步 `docs/system-design.md` 与 [Doca 系统设计基线](https://doca.heyphp.com/#/r/2902a80f-c592-414e-9aed-64fe19f2ed53)，保存和最新版本回读证据记录于 validation.md。
