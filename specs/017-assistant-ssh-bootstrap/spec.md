# AI 助手 SSH 首次接入

## 目标
管理员让 AI 助手为已登记主机安装 LightMoni Agent 时，助手能够真实登录 SSH、检查安装条件并生成可审核的持久化部署计划。主机页面复用相同能力；安装仍由管理员明确确认，激活成功后优先使用 Agent 通道。

## 用户故事与验收
- 管理员选择主机和已保存私钥，执行“SSH 安装检查”，看到连接是否成功、Linux/CPU 架构、依赖、systemd、root 或免交互 sudo、平台 HTTPS 可达性；失败有明确的结构化原因。
- 助手使用已登记主机 ID 和可选凭据 ID 执行相同检查；仅一个有效私钥时自动选用，多个时列出不含秘密的 ID 让用户选择。
- 检查通过后，助手生成有 ID、有效期及审核链接的部署计划；打开链接能看到同一计划并确认，不会重新生成。
- 只有未过期且与当前主机、私钥及架构匹配的检查才能生成计划。确认时再次校验主机快照、凭据和计划有效期，避免审核后切换目标。
- SSH 登录成功但不符合安装条件，必须显示“已连接，安装条件不满足”；不能误报可安装或已安装。
- 普通成员不能检查、查看凭据或创建计划。未知参数、任意 command/host/key 等参数均拒绝。密码、跳板与 SSM 不新增自动登录支持。
- 固定检查不安装软件、不修改主机配置。模型、会话、数据库检查记录和日志不包含私钥、token、主机指纹或原始 SSH 输出。
- 每台主机检查和部署互斥；检查最长 60 秒，支持取消；不影响其他主机。主机操作期间禁止改连接信息、删除主机或撤销正在使用的凭据。

## 范围
提供固定只读 SSH 安装检查、真实部署提案和主机审核入口；不提供网页交互终端或通用远程 shell。首次自动安装支持 Linux systemd amd64/arm64、直接 SSH、无口令私钥及 root/免交互 sudo。平台下载地址必须为 HTTPS。
