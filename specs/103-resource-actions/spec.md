# SDD103 应用删除与资源操作入口

## 需求

修复已卸载应用因历史恢复记录无法删除登记的问题；应用和网站列表提供明显的监控图标，将高频卡片及工具栏操作统一为图标按钮。

## 验收

- 当前实例已卸载、旧实例有经过认证的 Agent 无容器证明时，允许删除登记，保留执行历史和持久化数据。
- 普通停止、残留容器、未完成或未知执行、缺失或不匹配的恢复凭据，以及网站保存/发布引用仍阻止删除。
- 应用和网站均有可直接进入对应监控路由的图表图标；配置、发布/启动、终端、升级、记录、更多、刷新、新建等列表操作使用一致图标。
- 每个纯图标按钮有中英文可访问名称和悬浮/焦点提示；菜单保留文字、危险操作仍经过文字确认。390px 窄屏和桌面无新增横向溢出。
- 通过相关运行时回归、类型检查和连续三轮隔离 UI 流程，再通过 PR 合入 main、发布镜像并在指定线上页面核验。

架构影响不适用：修复既有实例退役/删除契约的状态解释，复用已认证恢复回执与现有监控路由；不新增协议、权限、存储布局、部署拓扑或控制入口。
