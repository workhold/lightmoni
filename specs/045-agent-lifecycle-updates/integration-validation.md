## 最终行为

解决系统设计、Agent 心跳、节点 API、任务中心和主机界面冲突，保留升级/回退流程与主干的主机 ID 绑定、当前 Agent 主机名所有权检查、SSH 网络观测、中心地址发现、多运行时脚本及任务调度能力。维护期间保留任务领取和调度互斥。自动重试在有界扫描前排除维护主机，事务内再次核对，避免维护冲突抛错中断整个 tick，或 200 条维护记录占满候选窗口；暂缓保留仍有效的重试资格，其他主机继续重试和调度。

升级的固定 SSH 调用同时记录主机凭据绑定与集中凭据库的最近使用时间。撤销集中凭据后，待执行维护计划被取消，禁止继续启动远端升级。界面沿用登记主机的默认凭据和集中名称；默认凭据不可用时需重新选择，不静默改用其他凭据。

主机界面的升级入口加入主机请求代次和目标 ID 校验，迟到的详情、深链、轮询响应不会覆盖新选择、显式刷新、暂停或关闭结果；删除主机与权限变化会使旧请求失效。
