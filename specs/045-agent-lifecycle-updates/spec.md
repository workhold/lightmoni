# 045 · Agent 升级与回退闭环

## 目标与驱动

平台更新只改变下载包，不能更新用户主机上的 Agent。本功能让管理员在主机管理审阅并执行单机/批量 Agent 升级，可靠区分相同 version 下的不同构建，保留主机、Agent 身份和遥测队列，并能证明新程序已连接平台。日常任务继续通过非 root Agent 执行；Agent 自身维护沿用已保存的 SSH 通道，不授予 Agent 长期 root 权限。

## 必须满足的行为

1. 平台提供真实可用发行目录：version、source_revision、build_id、state_schema、Linux 架构、包 SHA256。没有包不能声称可更新；审批固定包和维护器摘要，不使用漂移 latest。
2. 升级前通过 SSH 验证主机、现有 Agent ID、root/免交互 sudo、受管 systemd unit、当前发行指纹、磁盘和运行中任务。主机、当前程序或服务运行状态改变时旧计划失效；中心、维护器启动及切换前均核对审批固定的运行状态。15 分钟内明确批准一次，重复请求不能再次切换。
3. 下载票据限定单次维护计划、文件和期限，散列保存，仅通过 SSH stdin 传递；不重新 enrollment，不生成替代 Agent ID，不泄露 SSH/control/data 凭据。
4. root 维护器独立于 SSH 会话运行，持有主机生命周期锁；先下载和验证包、检查暂存配置，再原子切换程序。配置、身份、队列、游标和任务回执不被替换。普通 Agent 继续以原非 root 用户运行。
5. 维护器等待平台确认；平台必须看到同一 Agent 的目标包摘要、build、state_schema 和新 boot_id 的新心跳，并确认控制配置正常后才能 commit。进程 active 不等于成功。
6. 启动失败或超时自动切回之前程序和服务文件。回退只支持相同 state_schema，保留当前数据，不能恢复旧队列快照造成遥测丢失/重复。未知 schema 或非受管安装拒绝自动操作。
7. SSH 断连、平台重启、远端结果不完整均记 unknown，不自动重放破坏性命令。管理员用只读核对读取持久 receipt；核对不能将 waiting_confirmation 自动提交。超时由远端维护器回退后再核对。
8. 成功升级后可审阅回退到保留的上一发行。回退采用同样审批、验证、新启动和确认协议。来源程序/摘要必须与已审阅指纹一致。
9. 批量使用服务端持久 rollout，默认串行，每机独立计划与结果；失败/unknown 自动暂停，继续须明确批准；取消仅取消未启动项，不伪称已回退运行中主机。重启暂停且不自动重复执行。
10. 生命周期计划/运行/unknown 阻止新增和领取冲突任务、部署、卸载、删除、重绑定及并发 SSH 维护。已在运行/unknown 的任务须先结束或核对。
11. 管理员写操作，成员只读；AI 只可查询和准备审阅计划，无 apply/commit/远程任意命令工具。

## 非目标与边界

本次不更新生产或 vchive，不发布镜像，不提供无 SSH root 维护通道的远程自提权升级，不跨 state_schema 迁移，不保证掉电期间立即自动恢复。掉电后持久记录和程序指纹用于核对，不能凭平台超时认定成功。SDK 仍独立直报中心，不经 Agent 转发。

## 验收

校验发行同版本不同构建、摘要篡改拒绝、审批过期/重放、身份与配置保持、控制健康才成功、失败回退、断连/重启 unknown 核对、任务互斥、批量暂停/取消、角色与 AI 边界。真实 Linux/systemd 验证与模拟执行器测试分别记录，不将模拟结果当远端主机验收。

## 主干集成复核（2026-10-31）

- 同步最新主干，保留系统主机名与用户名称分离、SSH 目标代次/公钥固定、Agent 观测归属及界面异步请求防错配能力。
- 保留中心 endpoint 发现、集中连接凭据、主机网络发现和多语言脚本任务能力；维护 fence 叠加现有任务资格/能力判断，不替代主干逻辑。
- 升级、回退及只读核对使用集中凭据时，同时记录主机绑定与凭据库最后使用时间；撤销和有效期校验继续使用统一凭据边界。
- 集成回归只操作隔离 SQLite/HTTP/SSH fixture，不升级生产或 vchive，不重跑以前已记录的真实 systemd 验收作为本轮证据。
