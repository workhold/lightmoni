# SDD 179：Agent 生命周期恢复体验的 0.1.5 发行

## 范围与验收

- 将已合入的 SDD 178（PR #245，助手真实更新卡片与阶段进度、恢复引导、重装权限继承及同机身份收口）作为 0.1.5 发行，统一平台、Agent、SDK、MCP 和构建版本。
- 仅从版本 PR 合入后的 main 在本地构建 linux/amd64 中心镜像；固定标签为 `v0.1.5-20261115-182326-amd64`，镜像内继续携带双架构 Agent 与四种 SDK。
- 版本一致性、构建、镜像内发行包 SHA256、隔离健康、版本、鉴权与 MCP 检查通过后，发布固定标签与 `latest` 并回读相同摘要及 OCI revision。
- 镜像发布后通过 1Panel 升级生产中心；升级前只读核对实际运行标签并备份配置、主密钥和 SQLite，保留数据卷与既有环境。回滚使用升级前实际固定标签，不假设磁盘 Compose 与运行状态一致。
- 线上核对容器健康、实例版本、首页和既有主机/应用可用性。中心镜像更新不自动升级或恢复任何主机 Agent，不自动审批、不执行通用 shell。

## 架构影响

不适用。本发行不新增组件、协议、存储或控制路径；SDD 178 的架构影响已在 PR #245 同步 `docs/system-design.md`。

## 发布约束

不使用 GitHub 流水线，不把源码构建或镜像推送当作生产升级完成，不发布 arm64 中心镜像。验证记录只写实际完成的证据。
