# SDD 190：0.1.8 集成发布与生产更新

## 目标

将已合入 GitHub `main` 的 PR #261、#263、#262 作为同一 0.1.8 发行交付：发布从最终合并提交构建的中心 Docker 镜像，保持既有 Compose 项目、配置和数据卷，更新生产中心，并让 `zz-bj-1` 的受管 Agent 使用包含单次作业快速领取修复的新发行包。

## 范围与验收

1. 三个 PR 均经 GitHub PR 合入 `main`，最终源码修订与镜像 OCI revision 一致；固定标签和 `latest` 在私有仓库回读为同一摘要。
2. 发布前在隔离 Compose 项目验证中心、ClickHouse 健康，首页与 `/healthz`、实例版本、MCP 版本以及内置双架构 Agent 和 SDK 校验和。
3. 生产切换前核对实际运行镜像、Compose 和数据卷，完成受限备份并保留可用的旧固定标签回滚目标；切换后核对中心、ClickHouse、实例版本及关键页面。
4. 通过平台现有维护流程升级受影响主机 Agent，确认精确版本、源码修订、服务与心跳。观察应用核对回执和私有仓库清单；不能仅凭容器存活声称历史未知结果已解决。

## 兼容与架构影响

中心沿用原 Compose 拓扑、卷、主密钥和运行时凭据。中心镜像不会自动升级已安装 Agent；历史 `unknown` 回执保留审计并按原流程核对。发布过程本身不改变组件职责、协议、存储或凭据边界，故本 SDD 无新增架构章节；功能变更的架构说明分别由 PR #261、#263、#262 更新在 `docs/system-design.md`。
