# 网站与运维界面设计

## 用户任务与方向

面向管理员，将网站、托管域名、证书、Docker 应用、托管服务放到同一个运维入口。用户先登记可复用资源，再填写类型化配置，保存后审阅具体资源版本并执行，最后查看真实回执。证书更新后的云 CDN 分发和自定义脚本，是证书的独立目标。

这是存量产品的新流程，沿用既有 React / Ant Design、侧栏、字体、间距与明暗主题变量；没有重新建立视觉系统。页面以当前资源表和“新建”操作为主，概况数字与最近执行保持次要层级，共享凭据、机器池、网关组和 ACME 账号收进“基础设施”抽屉。已检查原 OperationsPage 与现有样式变量；未单独保留改造前的可运行截图。

## 结构与关键状态

- 五个核心页签共享搜索、配置版本、已观察状态与执行记录。保存配置不显示已部署；未签发、未执行、排队、失败、unknown 都有独立呈现。
- 证书页将生命周期与分发目标分为相邻两表。目标行显示期望 / 已应用证书版本、自动任务类型和失败原因；证书到期和已过期突出提示。详情另列网站引用、证书指纹与剩余天数。
- 每个配置使用领域表单。环境变量、端口、挂载文件、静态文件、后端地址均可逐行增删；Compose 保留代码编辑区，并共享托管挂载配置，支持指定 Compose 服务名。
- DNS 抽屉使用实际分页 API 搜索并查看全量缓存，CRUD 后重新读取记录。同步平台记录与 DNS 缓存传播分别说明。
- 脚本目标显式选择 Agent、解释器、正文、超时、环境和自动触发。已有正文与环境不回显；空白保留，环境支持明确清空。三云目标使用对应平台凭据与 CDN 域名。
- 实例详情显示机器、分配资源、现场 CPU / 内存、就绪状态和观察时间；网站另有逐网关版本与失败回执。
- 写操作携带资源 revision。409 等失败保持表单输入；执行前显示资源名称、类型和版本，unknown 引导先检查目标。
- 旧 `/services` 入口转向托管服务页，侧栏保留一个“网站与运维”入口，防止继续从旧页面创建 systemd 应用。

## 设备、主题与动效

1440px 为主要桌面验收视口，390px 为窄屏。窄屏下概况改为两列，表单变单列，表格在自身容器横向滚动，页面无横向溢出。中英文复用字典调用，明暗主题复用全局变量；深色状态标记加了局部对比度修正。

三处基本动效：切换核心页签时表内容淡入并轻移；新增挂载 / 文件 / 端口行时淡入；配置弹窗和详情抽屉使用既有 Ant Design 的开合动效，按钮提供状态过渡和 loading 反馈。开启 reduced-motion 时禁用局部入场动画。

## 验收与证据

交互脚本：

- `web/src/app/ops/verify-ui.mjs`：隔离 HTTP 夹具，覆盖容器端口和托管文件、保存刷新、409 保持输入、三云 CDN、更新脚本、DNS CRUD、服务发现、网站 HTTPS / DNS 关联、英文与 390px。
- `web/src/app/ops/verify-live-ui.mjs`：实际 SQLite 和领域控制器，覆盖真实自签签发、密钥脱敏、配置持久化、Compose YAML 规范化、真实 revision 冲突、脚本环境脱敏、托管服务和三类网站。仅接受 loopback 的 `qa-admin` 后端并清理自己创建的资源。它不部署 Docker、不请求公网 DNS / ACME / 云服务。
- `web/src/app/verify-navigation-homepage.mjs`：保留原默认首页、权限、导航、存储失败覆盖，补充旧服务路径重定向和运维入口合并断言。该脚本读取生产 bundle，需主任务最终构建后执行。

结构化结果分别保存在 `evidence/ui/report.json`、`evidence/ui-live/report.json`。截图通过 Oil UI 的 `shoot.mjs` 输出到仓库忽略的本地媒体目录 `artifacts/screenshots/specs/033-operations-control-plane/evidence/ui/`，包含桌面 / 移动端、200% 和动效记录；网站 / 证书列表截图数据为隔离 HTTP 夹具，不能作为真实外部系统验收。实际 QA 后端的脚本表单截图另存 `artifacts/screenshots/specs/033-operations-control-plane/evidence/ui-live/hook-form/`；桌面使用 Oil 截图工具，移动端选择器回放不稳定，改用既有 Playwright 工具捕获 `hook-script-390.png`。Oil 检查的唯一环境项是现有 favicon.ico 返回 404。

已做减法：移除旧版独立备份 / Cron 面板和重复的服务部署导航，避免把独立全局资源再绑到单个 Agent；表格保留名称、配置目标、实际状态和动作，完整观察 JSON 收到详情折叠区。界面没有整页 JSON 配置表单。

主任务需对最终截图进行独立视觉复核，并连续三次运行交互脚本后汇总结果。子任务不自行给出独立评审评分。真实云平台 / 公网 DNS / ACME 验收另记，不能由 UI 夹具代替。

## 独立视觉复核后的修正

主任务独立复核没有评分，提出三项具体改进，均已落实：资源编辑弹窗改为正文内部滚动，标题、关闭与外置提交 footer 始终留在视口；表格将鉴权错误转成“云账号鉴权失败 / 检查凭据”，完整错误码仍在 title 和详情；未分发目标隐藏双空版本，长版本在表格只显示前 8 位，详情保留全值。新增 8 行端口后检查三个固定控件在视口内，并保存 `evidence/ui/long-form-fixed-controls.png` 到本地媒体目录。真实 QA 证书覆盖 `*.example.test`，测试继续遵守后端 SAN 校验。
