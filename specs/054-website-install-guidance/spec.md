# 网站安装引导与按需集群入口

日期：2026-10-31。分支：`codex/054-website-install-guidance`。

## 用户需求与验收

1. 管理员进入网站页，尚未安装全局 OpenResty 应用时，主体显示“请先安装 OpenResty”及安装按钮，不显示无意义的网站空表、搜索、新建网站或集群筛选。点击跳转应用页并直接打开 OpenResty 安装配置，无需再次找模板。
2. 安装页支持选择部署集群，并通过字段旁链接进入集群管理页创建或调整集群，安装成功后返回网站页并回读资源。保存失败保留安装输入；部署失败按既有真实回执提示，不能声称已运行。已有 OpenResty（包括部署中、失败或停止）继续提供管理和网站列表，不能反复引导创建单例。
3. 侧栏和默认首页候选不再展示集群；集群管理路由保留管理员权限、标题与登录深链接。已有集群/旧运维默认首页迁移到应用管理。
4. 应用及网站列表去除独立集群管理横栏；需要时在列表工具栏保留筛选，集群管理跳转只出现在集群表单字段旁，新建仅在独立集群管理页进行。管理链接在新页打开，保留未保存表单；应用管理与网站的列表、安装/编辑表单均不再内嵌“新建集群”；仅保留管理跳转，并在返回页面焦点时回读集群列表，保留父表单输入。
5. 未安装、加载中、读取失败分别显示；接口失败不能被误报为需要安装。验证中文/英文、390px 和 200% 的安装提示和跳转。

## 架构影响

不适用：仅调整现有 React 页面呈现、前端路由参数与导航入口，复用现有 overview/catalog/install/资源接口及管理员路由。不改变组件业务职责、后端数据或控制路径、存储、部署、协议、凭据或 AI/工具边界，无需改写 `docs/system-design.md` 与 Doca 系统设计基线。
