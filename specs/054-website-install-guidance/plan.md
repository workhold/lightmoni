# 设计

复用 Ant Design Empty、Button、Spin 和既有应用商店抽屉。网站未安装状态以一条解释和“安装 OpenResty”为唯一主动作；加载与错误不显示安装结论。已安装判定来自全局 application/role=openresty，不受列表筛选或运行实例健康影响。

网站按钮跳转 `/applications?install=openresty`，复用 CatalogDrawer，在模板加载后自动选中 OpenResty。关闭清除安装参数；成功回读并返回 `/websites`，失败保留表单与既有错误提示。直接打开深链接且已安装时不再打开安装表单。安装表单通过 preserve watch 读取商店预设的 OpenResty 角色，确保未注册的预设字段也能展示入口域名配置。普通应用商店保留模板列表，抽屉每次打开重置选择，避免上次模板残留。

移除导航组内集群项，保留页面元数据供标题和登录深链接使用；首页选项只取侧栏页面，旧 `/clusters` 与 `/operations` 本地偏好迁移至 `/applications`，旧运维路由也转到应用管理。集群表单旁复用管理链接，新窗口打开 `/clusters`，应用安装、编辑与网站表单不再提供内嵌新建集群；返回原页面焦点时回读数据。集群筛选收进列表工具栏，只在多集群或显式筛选时出现，安装提示期间隐藏。

局部低风险流程调整，沿用现有 Empty 入场/按钮反馈、抽屉开合和表单项入场，不添加新动效。由主 Agent 直接检查实际截图，无独立评审；记录桌面、窄屏、200% 与中英文状态证据。使用本机一次性 SQLite/真实 HTTP QA 服务验证安装跳转、集群管理页创建后返回选择、刷新读回和失败保留输入，运行针对性浏览器验收三轮及 web 类型检查。

架构同步：不适用，理由见规格。
