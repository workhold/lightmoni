# 验收清单

- [x] Mastra 仍是对话和编排主入口，LightMoni Agent 节点保持监控职责
- [x] Pi 在单个 code task 内支持真实多轮读取、修改、检查和修复
- [x] 未配置工作区关闭能力；仅管理员使用且模型不能切换用户工作区
- [x] workspace、路径、符号链接、凭据路径和命令白名单有服务端校验
- [x] 隔离副本在批准前不写回；审批前检测内容变化，父子工作区互斥
- [x] 超时、取消、步骤上限和关闭停止后续执行，不误报成功
- [x] 配置 key 不进入外部结果；源码任务记录加密，持久化失败不公开审批
- [x] 四协议真实 Pi 适配及逐请求计费已验证，缺失 token 保持未知
- [x] 网页真实状态、步骤/检查/diff 和确认应用通过浏览器验证
- [x] 不自动 commit、push、PR、merge 或 deploy；平台代码按独立 PR 交付
- [x] 说明可信工作区、命令默认关闭、无依赖安装和非 OS 沙箱边界

证据和环境限制见 [validation.md](validation.md)。
