# 主机网络地址分类与摘要

## 目标

主机列表优先展示可用于定位主机的网络地址，不再由 Docker/CNI 网桥等地址挤占摘要。入口、网卡与平台连接来源分开表达，不能由 IP 范围推断可达性或全局出口。

## 需求

- 登记的 SSH 地址标明公网范围、内网、共享地址或域名；它只是已配置的 SSH 入口，不代表验证过的公网服务入口，也不解析 DNS 或修改连接目标。
- 普通命名接口上的私有/公网范围地址优先展示，公网范围必须排除文档、基准、保留等特殊地址；未识别接口不能宣称为物理网卡。
- 明确命名的 Docker/CNI/veth/虚拟机网络地址、回环、链路本地与特殊地址折叠至详情，不丢弃原始观测；br0、bond/VLAN 等可能承担主机网络的接口不被一概隐藏。VPN/隧道地址单独展示，不能因其虚拟而遗漏。
- 平台来源按公网范围、内网/共享、本地或特殊地址分类。私有 TCP 对端可能是容器/反向代理，只在详情中显示；公网来源可作为“到平台的公网来源”展示，不能称为主机确定的公网出口。真实出口及 NAT/公网入口无法证明时明确待确认。
- 所有事实保留来源、采样时间与原始接口列表；SSH 检查、主机列表和详情共用分类逻辑，中英文一致。
- 仅调整显示投影，不改变 Agent/SSH 采集、心跳、存储、服务端字段、可信代理边界或主机身份。

## 验收
