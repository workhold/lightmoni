# 主机网络地址分类验收

## 审查结论与变更边界

原主机摘要读取private_ips，该数组按IP范围聚合了所有接口，Docker/CNI网桥可能先于主机地址展示。平台source_ip来自TCP对端或可信转发链，私有对端可能是容器/反向代理，不能称为主机出口。

本轮在Web显示层对既有addresses按IP范围和接口命名分组：有用的普通接口地址优先，VPN单列，明确容器网络、回环、链路本地和特殊地址留在折叠详情。登记SSH地址单独标识范围与用途，不根据网卡或Agent观测改写。

## 架构影响

不适用：没有变更Agent/SSH采集、心跳协议、后端响应字段、SQLite存储、可信代理、身份、凭据或控制路径。本轮落实已有系统设计13.6/13.7关于网卡、登记目标与平台来源的独立事实边界，仓库与Doca架构正文无需改写。

## 限制

- 接口角色依据明确名称推测，仅用于显示；未知接口不声称物理网卡。自定义名称的容器网桥可能仍进入普通地址摘要，详情保留接口和完整地址供核查。
- 范围分类不表示地址可达或存在公网NAT/防火墙映射；DNS目标不自动解析。
- 到平台的来源只表示该连接；即使是公网地址，也可能是代理，不代表主机全部流量的出口。公网/内网出口不能由这些观测证明时保持待确认。
- 没有访问生产、vchive或真实SSH；验收为本地纯函数和拦截所有网络的浏览器fixture，不冒称实机网络拓扑已验证。
