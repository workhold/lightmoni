# 实施计划

1. 先明确地址事实与显示契约，保留现有采集/传输/身份边界。
2. 实现纯前端地址分类投影并补有意义的回归；不依赖后端旧聚合数组选择主机地址。
3. 优化主机摘要、SSH入口标签和可展开网络详情，复用至SSH检查。
4. 构建并完成隔离浏览器验收、主机管理相关回归、差异检查；同步最新main后创建GitHub PR。

基于GitHub main 4ea53b5（已合入PR32）的隔离工作区。禁止为本轮验收访问生产/vchive、执行SSH或改动现有平台服务。

## 架构影响

不适用：本轮是既有 network.addresses/source_ip 与登记SSH地址的界面分类投影，不增加协议字段、存储、采集路径、控制路径、凭据边界或部署拓扑。系统设计现有13.6/13.7已经规定平台来源不等于全局出口；本轮落实其显示语义，无需无意义改写仓库或Doca架构正文。
