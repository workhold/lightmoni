# 设计

资源定义增加可信的派生名称钩子，证书通过已校验域名获得名称；创建和更新存储派生名称，历史资源读取按域名投影，历史快照/材料/引用不改写。domains 数组契约保留，新建长度为 1；历史多域名仅允许保留原集合更新。新建名称由中心决定，不信任浏览器名称。

证书表单用单值域名输入，内部序列化为 domains:[domain]；历史多域名以不可编辑集合展示。复用已有 Ant Design 表格展开行、抽屉、状态标签与表单，主列表域名为主信息，同步任务归属其行下。只在目录同步需要时展示机器/集群范围与管理集群快捷跳转。沿用组件开合、loading 和状态动效；局部修改由主 Agent 自检，不引入装饰动效。

集群目录分发使用独立模块，读取 cluster.machine_ids 和 managed_machines.agent_id，预检全部成员后按机器 queue。每个 run 复用现有加密载荷、job lease、目标配置 revision 与持续授权；幂等键加入机器/Agent。SQLite queue 单次原子，进程中断可能只提交部分机器，下轮依靠逐机器幂等键补齐，不声称跨多个 queue 的事务原子性。

资源定义增加私有载荷验证钩子，解密后、返回前重新核对集群成员与当前机器/Agent 绑定、Agent 未移除和配置启用授权。集群任务保存有界逐机器状态，通过持久 run 查询和回执归约；完整 applied 要求当前所有成员、当前任务 revision、当前证书版本与指纹都通过。旧配置/旧版本/离群机器回执不更新当前聚合。自动轮次不能因旧聚合 applied 跳过成员变更；失败/unknown 不自动重试，显式 retry 只派发失败成员，inspect 按成员读取现场来确认 unknown 的已应用结果。

验证覆盖单域名/泛域名/规范化名称、快捷表单、旧数据不丢；两台真实 Agent 目录同步、部分失败、重试去重、unknown 检查、成员加入/离开/换 Agent、撤权、过期/缺失成员、超过概览历史分页的去重与脱敏。浏览器从证书域名行添加任务、选择集群、编辑/刷新读回、失败保留输入及每机器结果，三轮脚本与截图自检。完成后 PR 合入，复用上一轮发布工具，固定 main 源码双平台构建/隔离验收/推送回读，发布记录经 PR 合入。
