# SDD 176：同机残留身份修正的 0.1.3 发行

## 范围与验收

- 将 SDD 175（PR #238）作为 0.1.3 补丁发行，统一平台、Agent、SDK、MCP 和构建版本。
- 仅从版本 PR 合入后的 main 在本地构建 linux/amd64 中心镜像；固定标签为 `v0.1.3-20261115-164421-amd64`，镜像内继续携带双架构 Agent 与四种 SDK。
- 版本一致性、构建、隔离健康、版本、鉴权、MCP 和发行包 SHA256 通过后，发布固定标签与 `latest` 并回读相同摘要。
- 发布不等于生产部署。中心替换、vchive 状态修正和重新安装均需管理员明确操作，不自动执行。

## 架构影响

不适用；仅发行已合入实现。状态修正的控制路径与凭据语义由 SDD 175 和 `docs/system-design.md` 承载。
