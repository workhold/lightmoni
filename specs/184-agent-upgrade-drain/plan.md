# SDD 184 实施计划

1. 扩展 `prepareMachineMaintenance`，只允许显式的一键升级在已有执行期间取得准备预约；预约仍检查绑定和其它准备预约，默认调用保持原语义。
2. 一键升级先预约，再在有界时间内等待原有 SSH 车道与任务围栏空闲。未知任务立即失败；已运行任务只等待其自行完成。完成后沿用 `idle`、`assertTarget`、SSH probe 和计划写入；任何失败按 token 释放预约。
3. 主机能力投影在 SSH 凭据等静态前提满足时允许一键升级进入等待，即使忙状态来自当前操作；更新/安装/卸载等持久围栏仍禁用。按钮说明等待当前操作结束。
4. 定向测试覆盖自动 inspect 持续调度、运行任务排空、unknown 拒绝、超时/取消释放、其它计划不等待，以及 UI 能力。类型检查、相关回归和构建通过后创建面向 GitHub main 的 PR。
