# SDD 216：助手会话头部编辑与列表降噪

## 背景

会话历史把标题、分类、删除按钮挤在一行；分类占据固定宽度后标题严重截断，宽标题也没有可扩展的浏览方式。进入会话后缺少直接编辑标题的入口，分类编辑位置不符合用户心智。

## 目标

1. 历史行只保留标题、时间/状态和删除操作，最大化标题可读宽度。
2. 标题过长时支持横向滚动查看，不再依赖截断猜测内容。
3. 选中对话后的 Workbench 左上角提供标题和分类的直接编辑入口。
4. 分类修改后历史分组、候选列表和当前会话状态保持一致。
5. 保留侧栏顶部的新对话分类建议和分类管理入口。

## 非目标

- 不改变会话 API、存储结构、分类权限和运行状态语义。
- 不移动整个 Workbench 头部布局或引入会话设置抽屉。

## 验收

1. 历史行不再显示分类选择器，标题区域获得更多宽度。
2. 长标题可以在标题容器内横向滚动。
3. 选中对话后头部显示可编辑标题和分类。
4. 修改标题或分类后列表、头部和分组立即同步。
5. 现有创建、删除、分类管理、运行/取消/附件行为不回归。
