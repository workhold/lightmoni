# 删除阻断的引用详情

用户在删除已卸载 ABC Demo 时只看到“仍有资源引用”，无法知道应该处理哪个资源。保留现有引用和执行保护，拒绝删除时明确列出实际引用资源。

验收：显示资源类型、名称、网站域名，区分已保存配置和仍启用的已发布版本；同一资源去重，但保留所有阻断版本。可从提示进入该资源详情。引用清单持续显示到用户关闭，中文、英文、桌面和窄屏可读。不删除或修改任何引用资源，不公开配置、凭据、脚本或环境变量。

兼容：原 DELETE 请求、HTTP409 和 platform_resource_in_use 错误码保持；旧服务无详情时保留通用提示。

架构影响不适用：既有管理员删除端点补充只读错误摘要，复用现有资源详情入口；组件职责、控制路径、认证、Agent 协议、存储与部署拓扑不变。
