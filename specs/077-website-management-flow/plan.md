# 设计与界面说明

## 方向

这是已有运维工具的流程整理，沿用 LightMoni 导航、Ant Design 组件、蓝色主操作、语义状态色与现有主题变量。网站是页面主对象，入口基础设施为次级设置；优先回答“配置是否发布、解析由谁维护、下一步做什么”。不新增风格卡片或第二套设计系统。

## 结构

1. 从共享通用资源表中抽出网站列表：保留名称/域名，集中呈现配置与发布版本、网站 DNS、明确发布/编辑动作；移动端自然换行而非隐藏主操作。技术性完整观察状态仍在详情末尾。
2. 增加纯只读状态解释函数，依据已有 per-cluster desired_revision/enabled/phase/active/synchronized/instances 与 DNS 资格/回读区分未发布、发布中、部分、已发布、停用、失败、unknown。配置 revision 增加可能来自即时流量策略，因此只客观显示配置/发布版本差异，不宣称所有 revision 差异都需要发布。
3. 网站详情先呈现配置、发布、DNS 的短状态和明确动作，再展示逐域名/集群流量与原入口回执；未发布的 DNS 原因明确为先发布。最近成功的 DNS 回读只称最近回读，不等同当前配置已同步或公网传播。
4. 集群入口抽屉按集群组织，提供只改域名和托管的简短表单。编辑时冻结资源快照和 revision；后台刷新不重置输入。表单失败就地显示，冲突保留输入；高级部署编辑继续调用原应用编辑器。
5. 发布动作直接打开原确认流程，网站动作不再额外要求从通用操作选择器中选“部署”；仍显示目标资源、保存版本与集群，最终由确认按钮发送原 actions 请求。

## 动效与验收

- 主发布按钮使用短按压与请求 loading 反馈；业务状态不等待动画。
- 入口编辑展开和确认弹窗沿用组件动画，来源/退出方向一致，取消恢复到原集群位置。
- 网站列表首次进入沿用短促淡入；后台轮询不重播。减少动态效果时移除新增动画与位移。

使用隔离真实 SQLite/API 验证入口字段更新、刷新读回和乐观锁失败保留；对真实后端无法自动生成的现场健康/发布/DNS状态使用明确标记的浏览器响应夹具，不假称实际 Agent 或权威 DNS 同步。相关脚本由主 Agent 连续运行三次，覆盖旧上游字段回归。桌面/390px/200%/主题与动效截图或三帧查看后交隔离视觉评审。按 skill 要求只运行相关类型检查和针对性验证，不运行生产构建或全量测试。
