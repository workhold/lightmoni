# SDD 177：维护车道可观测与 keep_current 出口的 0.1.4 发行

## 范围与验收

- 将已合入的 SDD 175（PR #238，同机残留身份修正）与 SDD 176（PR #241，busy 车道可观测、keep_current 核对出口、围栏 409 细分、恢复投影补全）作为 0.1.4 发行，统一平台、Agent、SDK、MCP 和构建版本。
- 仅从版本 PR 合入后的 main 在本地构建 linux/amd64 中心镜像；固定标签为 `v0.1.4-20261115-165712-amd64`，镜像内继续携带双架构 Agent 与四种 SDK。
- 版本一致性、构建、镜像内发行包 SHA256、隔离健康、版本、鉴权与 MCP 检查通过后，发布固定标签与 `latest` 并回读相同摘要。
- 发布后按既有流程完成生产中心替换（先备份）、线上验证；生产从 `v0.1.1-20261115-100500-amd64` 直接切换至 0.1.4，回滚目标为该 v0.1.1 固定标签。
- zsw-hk8c8g 残留操作锁清理与其 Agent 升级在生产切换后经平台 SSH 执行；不自动清除 unknown、不做通用 shell。

## 架构影响

SDD 176 的 API 面（busy 查询/释放、reconcile resolution）与组件职责（busy 车道可观测）属架构变更，已在 PR #241 同步 `docs/system-design.md`；本发行不另行变更架构。
