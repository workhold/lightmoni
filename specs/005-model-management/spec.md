# Feature Specification: 模型管理与用量计费

Created: 2026-10-17 · Status: Implemented and verified

## 用户目标

设置中的“大模型接入”改为“模型管理”，保留模型配置，在下方展示模型计费信息和 token 消耗统计。管理员配置输入、输出单价，按供应商报告的用量估算费用。

## 验收场景

1. 管理员打开 `/admin?tab=models`，看到“模型管理”、现有模型连接配置、每百万 token 输入/输出单价与币种。单价独立保存，不触碰密钥或连接配置。
2. 助手生成、工具后续生成、历史整理、显式连接测试产生的用量进入持久账本；同一事件重放不重复计数，失败或取消前已报告的消耗保留。
3. 7/30/90 天统计包括输入、输出、总 token，逐日、按模型及来源汇总；多币种分开统计。日期按用户选择的有效时区解释。
4. 缺失 token 或单价显示未知/未计价，不能冒充零；明确设置为零的单价表示免费。费用是估算值，不是供应商账单。
5. 每轮助手和连接测试使用开始时的连接和单价快照；同轮工具后续调用沿用该快照。修改价格不重算历史；旧会话无法确定模型或价格时显示未知，不套用当前模型价格。
6. 账本独立于最多 200 个会话的列表和事件保留上限；升级时从所有仍可读取的历史会话幂等回填。无法恢复已被清理的历史用量。
7. 仅管理员可以读写计费及统计接口；响应不包含密钥、用户提示词或生成正文。配置、计费、统计各自显示加载/失败状态。
8. 桌面及移动端展示可读，空统计清晰；原有模型发现、手工输入、连接测试与配置流程继续工作。

## 边界

主流四种协议均支持；不猜测市场价格，不调用供应商账单 API，不引入任意 URL 拼写纠错。缓存、推理 token 与供应商折扣可能使实际账单不同。只统计能从运行时或已有历史取得的用量，失败且未报告的调用不凭空估算。

## 优化修复验收（2026-10-17）

1. 同连接仅修改执行限制后保存，不覆盖未保存单价；重新加载单价或更换连接需要保留草稿或提供明确的覆盖确认，冲突后连接与计费显示同一身份。
2. 刷新统计保留分组和有效分页，加载及失败时保留已有结果；每日默认最近日期优先，今天标记未结束，明确最后刷新时间。
3. 自动模式已经唯一确定协议时可直接测试；仍有歧义时要求选择。测试沿用用户思考深度，但协议适配不得静默扩张固定的测试总输出预算；输出预算不足要与连接失败区分。
4. 每个实际发起的模型请求有稳定 ID，记录 pending/succeeded/failed/cancelled，完成、失败和取消均可统计，未知 Token 不变成零；同一请求的开始和终态合并一次，已有终态金额不可因重放改价。服务重启将遗留 pending 标为中断失败，保留原时间、费率及已知用量，不长期显示进行中。
5. 账本保存当时输入/输出单价及分项费用；输入或输出仅一侧可计价时保留已知部分，标明部分计价，不冒充完整总费用；旧记录单价/状态未知。
6. 四种 SDK、Go 并发检查、管理页与助手的隔离浏览器验收覆盖上述回归，构建并重启本地服务。
