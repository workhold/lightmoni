# Implementation plan

1. 为 SQLite/Memory 增加独立用量账本、稳定事件 ID、全量历史回填及按时区聚合。
2. 按规范连接身份（Base URL + 协议 + 模型）存单价，提供管理员 API 和旧身份冲突保护。
3. 正常助手和连接测试在真实 usage 事件时写账本，运行时完成但缺失 usage 时仍记录未知；调用时保存价格快照。
4. 改名管理入口，增加独立单价表单、统计摘要、每日及模型/来源明细。
5. 完成 runtime、Go race、前端构建、隔离浏览器验收，先构建静态资源再构建服务并重启。

费用 = 输入 token × 输入单价 / 1,000,000 + 输出 token × 输出单价 / 1,000,000；无法完整计算则不写完整费用。币种分别聚合，时间范围左闭右开。
