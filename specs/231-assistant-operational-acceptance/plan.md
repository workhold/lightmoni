# 实施设计

1. 使用生产中心与在用模型验证回复、只读查询、大盘、告警审阅和合成历史压缩。对测试主机记录操作前的服务版本与健康，制造可控异常，完成原生预检、审批和恢复，再通过进程、心跳、应用状态及执行回执验收。
2. 在现有告警提案服务中接入新建规则。新建规则使用告警域验证和写入，生成带固定目标和有效期的预览。审批重查意图、权限、定义和绑定，事务内只应用一次。工具声明列出静默的实际范围和时间字段。
3. 为已复现的 Agent 作业过期扫描及特权作业派发和过期扫描建立仅覆盖活动队列的 SQLite 索引。保留既有查询、锁、状态和过期条件。

架构影响见系统设计末尾的“AI 助手运维验收与告警创建”。新告警提案沿用统一能力层和 Web 内原生审批，增加告警域创建路径。部分索引附加到既有 SQLite 表，历史任务和状态机沿用原有契约。
