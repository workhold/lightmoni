# Feature Specification: 主机容器管理与镜像清理

**Feature Branch**: `codex/109-host-container-management`
**Created**: 2026-11-08
**Status**: 实现完成；后端、契约与真实Docker验收通过，浏览器全流程验收受工具权限限制待完成
**Input**: 主机容器部分支持增删改容器信息，参考1Panel；支持删除容器、清理无用镜像。

## User Scenarios & Testing

### User Story 1 - 删除容器与日常管理 (Priority: P1)

管理员从主机全部容器列表查看详情、启动、停止、重启或删除目标，不需要手工登录终端。

**Why this priority**: 用户明确补充删除容器，现有列表只有查看能力。
**Independent Test**: 对可丢弃测试容器执行启停和删除，重新读取确认状态及实际删除结果。
**Acceptance Scenarios**:
1. **Given** 目标已停止，**When** 确认容器名称并删除，**Then** 仅该容器消失，默认保留卷和镜像，操作结果可回读。
2. **Given** 目标仍在运行，**When** 未选择强制删除，**Then** 拒绝删除并解释原因；选择强制删除后确认才执行。
3. **Given** 容器有匿名卷，**When** 用户明确选择同时删除匿名卷，**Then** 确认面板列明影响；不删除命名卷和绑定目录。
4. **Given** 平台应用或Compose创建的容器，**When** 管理或删除，**Then** 展示归属与可能被编排重新创建的提示，不隐式卸载应用。

### User Story 2 - 清理无用镜像 (Priority: P1)

管理员查看主机镜像占用，预览并选择未被任何容器引用的镜像后清理。

**Why this priority**: 回收磁盘空间时必须看清具体对象，避免误删保留镜像。
**Independent Test**: 准备运行容器、停止容器所引用镜像和一个未引用镜像，只清理最后一个。
**Acceptance Scenarios**:
1. **Given** 同机有运行和停止容器，**When** 扫描无用镜像，**Then** 排除二者所引用镜像，列出候选名称、ID、大小及回收估计。
2. **Given** 已确认若干候选，**When** 执行前某镜像被引用，**Then** 跳过该项并报告，不扩大到新出现的候选；不删除容器、卷、网络、缓存。
3. **Given** 预览过期或候选元信息变化，**When** 提交清理，**Then** 要求重新预览；不会重复提交结果未知的操作。

### User Story 3 - 创建和修改容器 (Priority: P2)

管理员从本机已有镜像创建容器，设置名称、启动命令、端口、命名卷、资源限制及重启策略；可修改已有容器名称和运行期支持的配置。

**Why this priority**: 补齐用户要求的增改，同时避免把不可原地修改的配置伪装成已保存。
**Independent Test**: 创建一个无特权容器，改名与修改限制/重启策略，刷新后读回。
**Acceptance Scenarios**:
1. **Given** 本机已有镜像，**When** 选择镜像并填写有效配置后确认，**Then** 创建容器且回读配置；默认先创建，是否启动需明确选择。
2. **Given** 容器详情，**When** 改名或修改资源/重启策略，**Then** 仅修改已审阅字段，回读一致才报成功。
3. **Given** 详情含镜像、端口和挂载，**When** 查看，**Then** 显示这些信息，并明确变更它们需要创建新容器，不自动删除重建。

### Edge Cases

- 离线、旧管理组件、未授权、目标身份变化、过期观测、并发任务时禁用或拒绝写操作。
- 连接丢失、超时或部分完成时保留结果未知及执行围栏，用户只能回读核对，不能自动重试。
- 长名称、多端口、空清单、清单超限、窄屏及中英文均可操作；输入失败保留配置。
- 原始检查信息中的环境变量、标签、凭据与守护进程错误不进入响应及事件日志。

## Requirements

### Functional Requirements

- **FR-001**: 所有容器和镜像动作绑定当前主机及精确对象；只有人工管理员会话可发起。
- **FR-002**: 创建、改名、修改、启停、重启、删除和清理必须展示精确影响并单独确认，保留发起人、请求标识与终态回执。
- **FR-003**: 删除默认保留卷与镜像，强制删除和删除匿名卷分别选择；命名卷和绑定目录不由该动作删除。
- **FR-004**: 清理必须排除所有容器引用，最多只删除本次预览明确选择的镜像，不使用全局清理。
- **FR-005**: 创建仅使用本机已存在的精确镜像，提供基础配置，不开放特权、宿主网络或自定义守护进程入口。
- **FR-006**: 已有容器支持独立改名及更新CPU、内存、重启策略；镜像、端口、挂载保持可见，不隐式重建。
- **FR-007**: 写前核对对象版本；成功必须有实际状态/配置/不存在回读；不以请求已受理代替成功。
- **FR-008**: 旧组件继续显示清单，新增管理操作解释升级需求；普通监控Agent不获得写权限。

### Key Entities

- 容器：主机、完整ID、名称、状态、镜像、资源限制、重启策略、端口、挂载及可验证版本。
- 镜像预览：精确ID、名称、占用、引用、扫描时间和候选版本。
- 管理任务：主机、发起人、精确动作、幂等请求ID、执行状态和核验回执。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 测试中的创建、改名、资源修改、启停及删除100%经回读与目标一致。
- **SC-002**: 清理验证中运行与停止容器引用镜像均保留，只有已选且未被引用候选被移除。
- **SC-003**: 相同请求重复提交最多执行一次；权限失败、版本变化和结果未知均不触发自动二次写入。
- **SC-004**: 中文和英文390/1440宽度及200%阅读场景均可完成主要流程，失败后保留用户输入。

## Assumptions

- 参考1Panel的容器列表、详情、创建和磁盘清理流程，不复制其源码或全部功能。
- 沿用已有完整管理模式与受管主机运维授权；新增能力需要更新管理组件，默认不替用户提升权限。
- 本轮不包括镜像仓库管理、拉取/构建镜像、容器日志终端、批量容器删除、编排重建和全盘垃圾清理。
- 功能开发和本地可丢弃资源验收已授权；不删除生产容器或镜像。
