# Specification: 顶部账户与界面偏好

日期：2026-10-19。分支：`feat/header-preferences-i18n`。

## 用户需求

用户名称和登录身份从左下角移到右上角，并提供界面颜色管理和中英文切换。各页面保持统一的账户入口，窄屏也能访问。

## 验收要求

- FR-001 登录后在全局顶部右侧展示头像、昵称（为空回退用户名）和管理员/成员身份。账户菜单可打开个人设置、退出登录；左下角不再重复展示账户。用户保存个人资料后顶部立即同步。
- FR-002 顶部提供界面配色入口，支持深色、浅色、跟随系统及预设强调色；个人设置保留同一偏好入口。现有深浅色偏好兼容，偏好保存在当前浏览器，不更改其他用户或平台全局配置。
- FR-003 顶部提供简体中文和 English 切换；同步文档 lang、导航、账户、个人设置及组件库语言。语言本地持久化，切换不导航、不刷新、不丢失当前输入或登录状态。
- FR-004 用户已确认覆盖全站界面：前端固定界面文案逐页接入显式翻译，包括管理/接入、大盘/图表、日志、告警、节点和 AI 助手；保留业务名称、用户输入、服务日志、代码、SQL、凭据、模型输出和接口字段的原始内容。
- FR-005 新布局兼容展开/收起导航、独立图表页、AI 助手和 390px 窄屏，无页面横向溢出；名称过长时省略但完整名称可访问。退出失败展示错误且保留登录状态。
- FR-006 所有变更按功能分支 PR 交付，不自动合并。当前分支基于待审核 PR #17，保留该功能并明确依赖关系。

## 完成标准

先提交规格、设计、契约和任务；完成构建、生产页面交互与视觉验证，记录真实覆盖和外部数据翻译边界，更新本地运行版本后创建待审核 PR。
