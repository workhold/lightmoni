# Acceptance

1. 网站页先看到用户网站主表；点击次要“OpenResty 管理”，创建南北两个集群、一套多集群OpenResty，设置south/north入口域名；编辑增加/移除已停止集群，创建第二套OpenResty必须失败。
2. 创建双集群服务；托管网站选择一次服务及端口，验证两个实际集群。手动网站配置两个不同代理，保存刷新不丢失。
3. 启用默认权重1:1，添加厂商返回的两省线路；成功回执后核对CNAME与line/weight。
4. 南集群入口失败或失联/过期时只撤下南方默认和省线路，北方默认保留；恢复成功回执后重新加入。关闭策略同样撤下。
5. 更新权重而不发布网站草稿，确认DNS更新且应用的网站修订不变。无支持线路/套餐、外部修改、未知写入、撤权均不误报成功。
6. 运行针对性node:test、runtime/web typecheck及UI三轮，记录非公网DNS验证边界；同步Doca与仓库设计并回读。
