# UI design

沿用现有Ant Design与运维页面变量，不另建视觉方向。网站页主区优先显示用户网站、域名及实际集群；OpenResty只保留“OpenResty 管理”次要按钮，部署集群、入口域名和编辑/安装操作收进抽屉；应用现有编辑入口保留并改善商店配置字段。网站编辑先选绑定模式：托管服务选择一次服务及端口、展示自动集群；手动选择集群与后端。公共域名/证书/路径不重复。实际集群表展示开关、权重及默认承接，线路详情折叠且从托管zone目录选择。域名错误和云错误可见，失败保留输入。
动效复用现有Modal/Drawer开合、Button加载与Switch状态反馈；网站列表沿用页面出场，遵守prefers-reduced-motion。桌面、390px和200%检查表格内部滚动与固定表单动作。基线/最终截图及评审归档在本SDD evidence，图片通过qa-artifacts存放本地artifacts目录。

独立评审修订：桌面缩到390px时自动收起现有导航，回到桌面恢复已保存偏好；窄屏必须看到标题、主操作及业务对象。版本冲突改为可操作的人类提示，保留输入并说明复制修改后取消重开最新配置。共用线路说明移至区域顶部只出现一次。全页截图先滚动归零，避免固定顶栏被拍到错误位置。

按用户最新反馈：移除主体OpenResty表格及安装提示，主表不被基础设施详情下推；OpenResty 管理抽屉保留全部功能。验收必须先见用户网站，打开OpenResty 管理后才见部署域名。此处只调整信息层级，已有数据/控制/凭据边界不变；同步基线的UI描述。
