# SDD 210：助手分类自定义与 Workbench 可见性增强

## 背景

0.1.18 的分类输入使用 `Select tags + maxCount=1`，视觉上更像固定选项；用户输入自定义分类的心智成本过高。同时 Workbench 第一阶段主要新增右侧 Inspector，对没有工具产物的普通对话视觉变化不明显。

## 目标

1. 新建对话和修改历史对话时都可以输入任意自定义分类，常用分类仅作为建议。
2. 分类输入采用显式 AutoComplete 输入框：输入后回车或失焦提交；不再依赖“标签 token”交互。
3. Inspector 无产物时显示安全快捷入口，避免普通对话右侧看起来空白。
4. 任务头部状态更明显；历史会话行显示最后更新时间与分类。
5. 不改变后端 API、权限或分类长度限制。

## 非目标

- 不做自动语义分类。
- 不增加新工具、后台任务或模型协议。
- 不允许批量修改分类或跨用户共享分类。

## 验收

1. 新建分类“客户系统”可以保存并出现在分组中。
2. 历史会话可移动到既有或自定义分类。
3. 清空分类后回到未分类。
4. 空 Inspector 显示安全快捷入口。
5. 桌面、窄屏和暗色布局通过浏览器验证。
