# 验收记录

日期：2026-10-29。以用户最终要求“先登记主机、平台部署，不做独立身份兼容”为准；替代此前的独立脚本节点及自动发现方案。

## 最终行为

平台主机是唯一资产，平台生成不可变 ID，名称由用户维护。登记填写名称、SSH 目标地址、端口和用户名；指纹及凭据可稍后补充。Agent 安装身份与主机资产 ID 分开，Agent 是该主机的管理通道。

接入链路只有“登记主机 → 限期 SSH 凭据与可信指纹 → SSH 预检 → 审阅确认 → 平台部署”。中心内部签发 enrollment 时预绑定真实主机及旧身份快照，兑换和激活持续核验，激活事务用 CAS 关联；注册或心跳只更新观测 hostname 和时间，不创建资产，不改变归属，不按 IP/hostname/客户端 host_id 推断主机。

独立脚本安装页面、独立 token 生成及手工关联入口已删除；原独立签发请求返回 409，原手工关联请求返回 410。主机新建/更新接口仅接受直接 SSH，省略连接方式时新建默认直接 SSH；新凭据仅接受明确指定的私钥或密码，旧手动脚本记录不能继续执行操作。没有主机预约的旧 token/身份、Agent 共享 SDK Key 及配置中的旧 `key` 字段均拒绝。不自动迁移身份，不自动删除实际数据库数据。原无主机预约的 Agent 需通过登记主机后的新安装流程重新部署，不能把旧配置直接作为有效接入身份。

控制面、数据面、安装下载、运维可选目标及任务入队均检查主机预约/绑定与独立凭据。安装离线预检仅允许 `configure/check --pending-enrollment`，不能运行 Agent 或创建身份；激活后保存 control/data 凭据并通过严格校验，才启动服务。Agent 内嵌公开 SDK 只负责遥测，远程配置由 Agent 控制面取得。

管理员列表只由登记主机生成，Agent 仅补充通道和任务；成员只读投影使用真实主机 ID/名称，不读取 SSH 元数据。主机名称及 SSH 配置可编辑，ID 不变。移除/卸载 Agent 保留主机；有效身份所在主机不能直接删除。同一主机在旧身份已终止、任务无未决结果、SSH 新预检确认无安装后可安全重装，保留主机 ID 和历史；旧身份卸载回执不影响新身份状态。

SDK 独立直报行为保持，不增加 SDK 主机环境变量，不强制安装 Agent，不要求 SDK 改经 Agent 上报。
