# SDD 104：操作、状态与日志体验统一

## 请求与范围
1. 网站监控拆为「访问大盘」「访问日志」两个页签；图表与日志独立阅读。
2. 主机列表、连接凭据及运维资源的列表/工具栏动作采用图标，悬停和键盘聚焦均提供说明；保留对象名链接、表单提交和危险确认中的文字。
3. 参考 1Panel 的紧凑运维面板：状态先行、结果摘要、按需读取详情，避免原始 JSON 和技术 ID 主导页面。

## 验收
- 网站页签写入 URL，刷新、前进后退保持选择，切换保留时间范围。大盘显示原时间窗真实数据，不编造汇总；图例使用集群名称，未知集群保留原 ID。
- 日志支持当前返回记录的关键字/状态码筛选；表格保留时间、域名、方法、路径、状态码、耗时，原文在单条详情中查看和复制，不撑开行高。筛选范围明确为已加载记录。
- 所有新图标按钮有可访问名称、Tooltip、可见焦点；禁用理由和原确认、权限、unknown 约束继续生效。
- 运维执行结果采用抽屉：最新状态、资源/动作/时间和错误原因先行；原始回执折叠。提交后台请求使用「已提交」反馈，不能声称已执行成功。
- 操作日志的时间、级别、事件、状态和详情入口分列，原文按需展开；采集状态使用紧凑分组，异常保留原因和最近成功时间。
- 浅/深色、1366px 桌面、390px 窄屏和200%阅读无页面横向溢出；表格允许区域内横向滚动。隔离 fixture 覆盖成功、失败、unknown、保存失败保留输入和刷新读回，关键流程连续三轮。
