# 设计与实现

沿用 SDD 087 的紧凑浅色面板、Ant Design 图标与 lm 色值，不另建主题。用户来列表判断状态、进入操作，来详情定位失败原因；首屏主角是状态与内容。

- 网站：标题与轻工具栏，采集状态条，白色页签工作区；访问大盘只放两张真实时序图，访问日志是可筛选的紧凑表格和单条详情抽屉。
- 操作：复用 IconAction，保持按钮事件、禁用和危险确认原样，统一32px命中区。复杂菜单仍保留动作文字，确认和保存保留清晰动词。
- 结果：一个结果状态摘要，紧凑元数据与可复制执行 ID，异常说明不折叠，原始技术回执折叠查看。操作日志也采用表格与单条详情，避免行内多层信息。
- 动效：沿用150–180ms列表入场、页签切换和抽屉展开/按钮反馈；尊重 prefers-reduced-motion，不增加进度猜测。
- 减法：删除重复的「请求流量与访问日志」副标题与行内原始JSON；保留名称、时间、失败原因、权限限制。
- 验证：复用 loopback fixture 和项目 Playwright，先截图基线；实现后主 Agent 连续三轮关键交互与定向类型检查，桌面/窄屏/深色/放大实际看图；隔离视觉评审一轮。

参考：https://1panel.pro/docs/v1/user_manual/logs/ （操作、访问、系统日志按用途组织）；https://docs.fit2cloud.com/1panel/user_manual/appstore/installed （既有 SDD 087 参考）。仅借鉴结构，不复制品牌或源码。
