# UI 兼容契约

- 既有 website-telemetry 查询与15秒轮询、from/to 参数保持不变；tab=overview|logs 是前端 URL 状态，默认 overview；其他查询参数保留。
- 不将已加载最多一页日志当作全时间窗统计；筛选仅作用于本次返回的 rows，不改变接口或权限。
- 日志字段优先读取结构化值（含0），无字段再解析 body。不可信 body 始终作为文本显示。
- 图标仍调用原事件，不绕过确认或改变 disable/权限判断；对象名称与菜单文字保留。
- 回执根据同一份最新 Run 渲染状态、详情和 unknown 警告，避免陈旧状态与新结果矛盾；UI 不修改后台状态、不自动重试。
- API 路由、请求与响应、凭据、数据模型均保持；不新增日志导出或复制秘密接口。

- 前端通过既有 /ops/overview 回读集群名称用于图例；若名称读取失败，回退显示原集群 ID，不影响监控查询。
- 列表、操作日志、运维结果及任务结果共用状态颜色含义；原始执行快照/代码折叠可查，敏感输出仍须原有显式读取与权限核对。
