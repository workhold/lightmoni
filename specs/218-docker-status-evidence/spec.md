# SDD 218：Docker 历史安装只读恢复证据

## 背景

历史 Docker 安装记录进入 unknown 后，若远端操作目录或状态文件缺失，只读核对会继续返回 unknown，导致终端、执行权限和 AI 主机操作被永久围栏。

## 目标

只读核对必须区分三种远端证据：正常状态文件、操作目录缺失、状态文件缺失。前两者都不代表正在执行，可安全置为 failed 并解除安装围栏；有效 running 状态仍保持围栏。

## 非目标

不重放安装、不删除远端证据、不自动安装 Docker。

## 验收

只读命令对缺失目录和缺失状态文件输出结构化 failed 证据；测试覆盖不会重新执行安装。
