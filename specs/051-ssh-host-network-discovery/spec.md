# SSH 安装检查阶段的主机网络发现

## 目标

登记主机后，平台在安装 Agent 前即可通过用户主动执行的 SSH 安装检查发现主机名、网卡及内网 IPv4/IPv6。Agent 接入后继续更新同一主机的网络信息。登记使用平台生成 ID 和用户名称；首次 SSH 连接地址仍需用户填写，不能从私钥、浏览器所在电脑或机器名称凭空推导。

## 范围与要求

1. 登记、编辑、列表及详情统一称“SSH 连接地址”，支持平台能够访问的 IP 或域名；不自动用发现 IP 改写连接地址、端口、用户名、资产名称或主机绑定。
2. 复用一次已经完成身份和凭据验证的 SSH 预检会话，执行平台固定只读命令。核心安装检查与可选网卡发现分别解析；缺少 ip 工具、坏数据、超量输出或网卡发现失败，不将安装条件通过改成失败，不泄露原始命令输出或凭据。
3. 采集主机名及有界网卡地址，复用已有 IP 规范化/分类和最多 64 条限制。发现状态、来源与时间可见；只有成功的快照更新资产，失败不得擦除已有数据。
4. 复用 machine_network_observations 存储和主机 network 接口，区分 SSH 预检与 Agent 上报。SSH 发现仅在目标地址/端口/用户名/主机身份仍与预检一致时写入；目标变更使旧 SSH 快照失效。Agent 来源始终受当前合法身份绑定约束，重装不能显示上一 Agent 的快照。
5. 网卡快照与平台观测来源各自保留来源边界。SSH 不写 source_ip，网卡公网范围不代表公网可达，Agent 到平台的来源 IP 仅代表这条连接。页面统一称“平台观测来源 IP”，不伪造公网入口、NAT 映射或全局出口。
6. SSH 检查结果显示发现信息，主机列表/详情刷新后保留；安装条件不满足时仍可查看成功采集的网络。未发现时明确提示可执行 SSH 安装检查或等待 Agent 上报，不暗示必须先安装 Agent。
7. 保留既有默认凭据选择、主机密钥校验、一次性密码消费、审批安装和卸载流程。发现不额外建立 SSH 会话、不安装依赖、不执行用户脚本或 Agent 安装。

## 验收

- 无 Agent 主机通过只读 SSH 发现多网卡、内网 IPv4/IPv6，并在接口、检查弹窗、列表与详情中展示来源和时间；重启/刷新后可读。
- 缺工具、非法/超量发现数据与空快照语义明确；核心预检严格验证，发现失败不影响核心 ready，不覆盖已有快照。
- 主机目标变更、主机密钥不匹配、取消、凭据失效及 Agent 重装的身份边界保持；Agent 上报可继续更新当前主机，来源 IP 不能由 SSH 或请求正文伪造。
- 中文/英文、390px 窄屏与现有中央凭据/登记/SSH 流程回归通过。不连接生产平台或 vchive，不把本地隔离验收称为真实主机安装。
- 同一 PR 更新仓库系统设计和 Doca 对应章节/原生图块并回读，记录真实同步结果。
