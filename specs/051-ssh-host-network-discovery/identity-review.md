# 主机身份周边逻辑复核

## 已确认并修复

1. **用户名称误作 SSH 目标身份。** 原更新接口把 `name` 变化计入 `ssh_target_generation`，导致仅重命名就隐藏原 SSH 主机名/IP、删除有效预检。现将显示名称从 SSH 修订值和主机公钥 compare-and-set 中移除；真正修改 SSH 目标仍使旧结果失效。包含旧名称的安装计划取消，执行前独立核对名称快照，卸载保留既有编辑互斥及名称快照核对。
2. **替换 Agent 继承旧系统主机名。** 原 `observed_hostname` 缓存没有身份归属，换 Agent 后到首个心跳前会误显示前一个 Agent 的主机名。现激活时原子清除缓存；读接口只从当前绑定且未移除的 Agent 获取该字段，不改变独立 SSH 网络快照。
3. **跨主机异步响应覆盖当前选择。** 原详情请求不核对请求代次，较早点击 A 的结果可覆盖后点击 B 的终端、凭据或部署弹窗。现按操作和目标跟踪请求，关闭、删除、权限变化、页面卸载及目标变化使旧请求失效；刷新与操作结果也受独立版本约束，防止部署完成后旧刷新退回待审批状态。

界面明确区分“主机名称（用户自定义）”“系统主机名”“SSH 连接地址”和登录用户名；IPv6 连接含端口时用方括号表示。

## 复核后保留的边界

- 主机 ID 由平台生成且不可修改。同名、相同系统主机名、相同 IP 或 SSH 公钥不会自动合并两条主机记录。
- 发现不自动填充或覆盖用户名称、SSH 地址、端口、登录用户；首次连接地址仍须由用户提供。
- 平台观测来源 IP 只描述 Agent 到平台的连接。SSH 不写来源 IP，不推断公网入站地址、NAT 映射或其他流量出口。
- 网络快照按 SSH 代次/公钥或 Agent owner 与时间验证；Agent 重装不继承旧 Agent 网络，失败发现保留已有成功记录。
- 任务派发、凭据保存策略、安装与卸载的管理员审批边界保持；没有把 UI 隔离测试称作真实主机操作。
