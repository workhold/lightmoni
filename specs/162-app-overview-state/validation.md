## 兼容影响

`GET /api/v1/ops/overview` 的字段、权限、过滤、排序和上限保持；每个请求复用一次资源读取。Web 的 `unverified` 仅为显示态，旧 API 客户端、Agent 协议、持久记录和数据库无需迁移。显式刷新仍会替换在途请求，自动刷新会等待当前读取结束。已停用集群的旧状态不污染启用集群的发布态；若已无启用发布集群但仍有活动遗留实例，保守显示待核实直至停稳。已退休历史不触发本轮新增的应用动作门禁，未退休且已移除的实例若仍关联未核对执行则继续阻止写操作；登记删除仍受既有 `store.remove` 对未核对历史运行的独立保护。核对抽屉复用既有按 ID 运行记录 GET，不改变 100 条历史列表上限。后端 `applied_revision` 对空实例集合可能被 `every()` 误判；本轮以目标和就绪数量阻止前端误报，后端计算另行处理。
