# SDD 208：AI 助手历史删除与分类

## 背景

AI 助手已有持久会话、搜索和运行状态，但用户无法删除历史，也无法把对话归入“监控 / Agent / 运维 / 研究”等工作类别。随着会话增多，列表只能顺序展示，难以定位和治理。

## 目标

1. 会话持久化新增管理员可读的 `category`；旧会话缺省为未分类。
2. 创建会话可选择分类；已保存会话可移动到既有分类或输入新分类。
3. 历史侧栏按分类分组，并继续支持标题与分类搜索。
4. 用户可删除自己的空闲会话；运行中会话必须先取消。删除同时清理会话事件、消息与该会话附件记录。
5. 删除采用显式确认；选中的会话删除后回到新对话态，不把旧事件留在视图或缓存中。

## 非目标

- 不允许删除运行中响应；避免删除后后台继续写回。
- 不做自动语义分类；由用户选择或输入。
- 不开放跨用户访问、批量删除或审计恢复。
- 不改变模型上下文裁剪、摘要和附件加密协议。

## 验收

1. `GET /assistant/sessions` 返回 `category`，旧会话为空字符串。
2. `PATCH /assistant/sessions/:id` 可修改标题或分类；运行中返回 409。
3. `DELETE /assistant/sessions/:id` 仅允许所有者且空闲；删除后 GET 返回 404，附件 KV 记录一并清除。
4. 浏览器验证展示分组、搜索、移动分类、删除临时会话、附件发送和暗色窄屏布局，无页面错误。
