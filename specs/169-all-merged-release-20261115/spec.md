# 全量合入后的发行与生产验收（SDD169）

日期：2026-11-15。用户授权将当前待合入功能全部经 GitHub PR 合入、发布 Docker、部署并做线上测试。

## 范围

- 核对并合入 #218（服务主体固定只读能力）与 #219（服务任务提案续行），以及应用中心测试修正 #226；各功能的规格、架构和测试证据分别保留在其 SDD 中。
- 从所有功能合入后固定的 `origin/main` 提交构建 Linux amd64/arm64 中心镜像，发布新固定标签；隔离验收后再更新 `latest`，保留旧固定标签。
- 通过独立 PR 更新根 Compose 的中心镜像引用与本 SDD 证据；GitHub Release 指向镜像对应的源码提交。
- 在现有 1Panel Compose 项目中备份并仅升级中心服务，随后做线上只读健康、应用中心、AI/MCP 与授权边界检查。Agent 只在确认为可安全升级时按既有流程升级，未知执行仍保持围栏。

## 验收

1. 功能 PR 合入且最终合并树的相关检查通过；#218/#219 的架构同步均在各自 SDD/PR 中有 Doca 最新版本回读证据。
2. 固定标签与 `latest` 的双平台镜像索引、OCI revision、内置 Agent/SDK 包身份一致；隔离容器健康、页面与鉴权检查通过。
3. 发行配置 PR 合入，GitHub Release 绑定同一源码提交；生产备份与回滚版本可核验，仅中心重建且原数据卷、ClickHouse 保持原状。
4. 线上页面/API 的只读验收通过；不为测试创建生产应用生命周期动作、任务提案或新的服务主体调用。

## 架构影响

本发行本身不适用：仅打包已合入的实现、更新既有镜像引用并在既有部署拓扑中升级；组件职责、控制和数据路径、凭据边界、存储及协议的变更由 #218/#219 的 SDD167/168、仓库设计文档和 Doca 同步承载。本发行不编辑设计文档或 Doca。
