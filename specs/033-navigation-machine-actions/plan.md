# 设计

主机列表以显式待删除对象记录目标，使用独立确认窗口呈现名称、地址及删除影响。忙状态在请求开始前同步防重；异常显示在列表区域，并保留稳定的失败目标，便于查看详情处理约束。删除与部署取消的错误状态分离，避免把无关错误串到删除区域。

成功后仅关闭被删主机对应的详情、凭据、预检、安装/卸载及终端状态，再刷新列表。原有服务端授权和互斥不变；不增加自动撤销凭据或自动卸载。

导航优先验证已有 SidebarNavigation 行为。线上旧资源诊断单独记录，不为了部署差异重复实现导航。

验证使用生产构建和隔离浏览器 API 夹具，不请求线上变更接口。沿用现有导航、SSH、凭据、卸载回归脚本并增加列表删除目标/取消/拒绝/成功检查。
