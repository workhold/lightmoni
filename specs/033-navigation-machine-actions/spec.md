# 分类导航与主机列表删除入口

## 目标

保持左侧按功能分类、各分类独立展开的导航体验；管理员可在主机列表直接删除指定主机记录，无需进入详情寻找入口。

## 需求与验收

1. 分类导航保留工作台、监控分析、运维工具、数据与接入和系统设置。展开一个分类不收起其他分类，路由切换和侧栏整体收放保持已展开的分类。
2. 每行操作区提供“删除主机”，点击后显示绑定该行名称、地址的二次确认。说明仅清理平台记录及关联凭据/检查/安装卸载历史，不卸载远端 Agent、不停止业务。
3. 取消确认不发送删除请求。提交期间阻止重复请求，待删除目标必须绑定稳定的主机 ID，不能使用当前详情主机作为隐式目标。
4. 后端仍校验有效连接凭据、未结束部署/卸载与运行操作。失败不移除行，列表显示目标及具体原因，并允许查看该主机详情处理阻塞后重试。
5. 成功刷新主机列表，清理属于该主机的旧详情或对话框；不能影响其他主机。详情不再重复展示删除入口。
6. 提供中英文与窄屏可用性验证；不删除线上 vchive 记录，不修改远端 Agent。
