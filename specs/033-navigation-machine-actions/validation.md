# 验收记录（2026-10-28）

## 最终行为

管理员在主机列表每行直接点击“删除主机”，确认窗口显示名称、地址、主机编号和删除影响。取消或 Escape 不发送 DELETE；提交后按钮禁用且同步阻止重复请求。后端拒绝时保留该行，在列表上显示准确目标和拒绝原因，并可进入该主机详情处理。详情不再有重复删除按钮，取消部署计划的错误仍显示在详情。

成功删除立即移除目标行，关闭仅属于该主机的相关窗口；其他主机详情保留。列表刷新失败、删除前列表请求晚返回或同主机详情晚返回，均不会恢复已删行或重新打开旧详情。
