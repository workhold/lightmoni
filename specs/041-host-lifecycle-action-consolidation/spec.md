# 041 主机列表生命周期操作收敛

## 驱动目标

主机列表已支持勾选一台或多台主机，移除 Agent 身份和删除主机应复用工具栏统一入口，减少行尾重复按钮。用户无需在单项与批量两套相同操作间选择。

## 需求与契约

1. 删除列表行内“移除节点”和“删除主机”按钮及各自专用弹窗/状态/请求处理代码，详情中不增加重复入口。
2. 保留复选框和现有批量工具栏。勾选一台也通过同一入口执行；未选择时操作禁用。保留安装/卸载审阅、移除身份与删除主机的影响说明、明确确认和逐项结果。
3. 移除节点仍仅撤销 Agent 身份并保留主机，不等同卸载远端 Agent；删除主机仍服从既有身份、凭据与未结束任务限制。只合并 UI 入口，不改变 API、权限或生命周期语义。
4. 行内保留登录终端、详情、编辑、凭据、SSH 检查、部署/卸载等上下文操作，以及节点详情、任务标签和卸载指引。
5. 保留成功后的主机/Agent 状态刷新、失败目标与原因、成员只读限制和移动端可用性。
6. 工具栏三种生命周期动作简写为“卸载 Agent”“移除节点”“删除主机”，英文同步省略 Bulk/Batch 前缀；对应弹窗、确认与原因文案保持一致，操作范围继续由已选择数量及目标列表表达。

## 设计与任务

统一使用现有 MachineBatchDialog 与 batchSuccess；选择一项与多项使用同一套请求、复核及结果展示。删掉 MachinesPage 中仅由旧单项按钮触发的移除/删除实现，保留被批量成功回调使用的归档缓存、forgetMachine、删除保护等逻辑。

架构与 Doca 同步不适用：仅前端入口去重，组件职责、控制路径、凭据边界、API、存储及部署拓扑不变。当前 UI 设计文档记录入口变化；通过 GitHub PR16 更新，不自动合并。
