# 实施计划

1. 为主机摘要增加现有安装/卸载记录的安全只读投影，明确 active 优先和稳定排序；保持既有权限过滤。
2. 共享阶段模型和进度组件，严格只有 succeeded 到100%，unknown/失败停留在已知阶段。
3. 单台安装、卸载和批量每行接入原记录只读轮询，主机列表显示各自主机进度。
4. 验证多主机隔离、阶段变化、结果未知、刷新失败/恢复、关闭清理、中英文和窄屏；运行相关回归、类型检查与构建。
5. 用户提出可部署验证后，从固定功能提交构建 linux/amd64 与 linux/arm64 候选镜像；镜像仓库拒绝大层时，将等价运行时文件拆分到多个镜像层，保持最终 rootfs 不变。
6. 推送固定候选标签，回读镜像索引和各平台版本标记并做本地镜像冒烟；不覆盖 `latest`，不更新生产部署。
