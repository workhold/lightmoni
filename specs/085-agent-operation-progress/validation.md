# SDD085 验收记录

验收日期：2026-11-02。所有浏览器与 API 测试使用本地 fixture 和隔离数据库；没有访问生产环境、建立 SSH 会话或操作真实主机。

## 行为

- 主机列表中每台主机独立显示最近安装或卸载状态；未结束操作优先于较新的终态历史。单台安装、卸载弹窗与批量目标行复用同一状态组件。
- 安装百分比按服务端持久化阶段映射；卸载运行显示停止服务并移除程序阶段。只有服务端 `succeeded` 到达 100%。`unknown`、`failed`、`cancelled` 保留未完成状态；unknown 停止活动效果并提示只读核对。
- 操作摘要只读取进度字段，不返回计划、凭据或 SSH 输出；错误文本沿用生命周期接口的脱敏处理，保留管理员权限边界。
- 轮询固定为已知主机 ID 与操作 ID 的只读 GET，不创建、apply 或 reconcile。每次 GET 最长等待 10 秒；超时保留最后进度、显示刷新提示并继续只读重试。关闭弹窗或卸载组件时会取消在途请求。
