# SDD085：每台主机的 Agent 安装与卸载进度

安装和卸载 Agent 时，每台主机分别显示进度条、当前阶段和实际状态。单台弹窗、批量目标行与主机列表复用相同展示，不只显示一个全局 loading。删除平台主机记录、移除节点身份与远端卸载保持区分。

- 基于现有持久部署/卸载记录与 execution_stage 投影阶段进度；没有字节或子步骤证据时显示正在执行的阶段和活动进度条，不用计时伪造百分比。只有服务端 succeeded 才显示100%。
- 明确待审阅、提交中、执行中、完成、失败、已取消和 unknown；unknown 停止动画并提示只读核对，不自动重试安装或卸载。
- 安装下发后可显示“下载并安装 Agent”，不声称已完成下载或服务启动；卸载 running 统一显示“停止服务并移除程序”，不伪造子步骤完成。
- 主机列表从已有记录的安全摘要展示最近操作，优先当前未结束操作；活动时加快只读刷新。弹窗和批量对已知记录ID只读轮询，刷新页面仍能恢复服务端阶段。
- 每个结果绑定主机与操作ID，忽略迟到或失配响应；卸载、关闭弹窗或权限变化清理轮询，不引入新的执行入口、审批或重放。
- 中英文、暗色和窄屏可读；进度条具备可访问名称，状态与阶段有文字。

架构影响：不适用。仅对已有持久化状态做只读摘要与前端展示/轮询，不改变存储模型、SSH或Agent协议、控制路径、凭据边界、审批和部署拓扑；不为展示进度新增执行事件或服务。按 AGENTS.md 无需无意义改写系统设计和 Doca。
