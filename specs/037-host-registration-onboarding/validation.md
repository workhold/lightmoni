## 实际行为

登记流程为同一窗口的“连接信息 → 凭据与保存时长”。主机创建成功后保存其 ID；凭据失败可重试，不重复创建主机。管理员可暂不保存凭据；保存完成后可进入 SSH 检查或生成安装计划。登记本身不远程安装，执行仍需要审阅确认。主页面、首个页签和导航统一为“主机”，隐藏脚本接入按钮，保留旧协议和路由兼容。

私钥和密码支持临时、按期限托管。新界面密码默认临时复用 15 分钟，私钥默认 1 小时；临时均最多 1 小时，Agent 激活后清除。托管需主动确认，默认密码 1 天、私钥 90 天，最长 365 天，到期或撤销清除，激活不会提前清除。旧 API 省略 retention 的密码仍为一次性；检查/终端结束后清除，不能用于安装。可复用密码可用于固定 SSH 身份核验、安装和卸载，安装令牌仅走独立 exec stdin。

主机摘要提供 `LIGHTMONI_MACHINE_ID` / `LIGHTMONI_MACHINE_NAME`，详情支持安全引用和复制。Node.js、Python、Go、Rust SDK 从进程启动环境补齐 `lightmoni.machine.id/name`，显式 resource 优先，缺失或非法环境不破坏原有上报。固定安装将相同公开元信息写入暂存 Agent 配置并校验，Agent 自用公共 SDK 附加这些属性，不改变 agent_id / host_id 或控制权限。用户需在业务启动环境配置后重启；未修改已有 unit/container 或全局环境。SDD 036 的显式归属关系与状态聚合仍未实现。
