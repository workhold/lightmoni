日期：2026-10-29。用户修订已实现并完成本地验收；Doca 在线架构同步仍受服务端错误阻断，尚未满足全部合入条件。

## 最终行为

登记在同一窗口完成“连接信息 → 凭据与保存时长”。主机创建后保留中心生成的不可变 `id`，`name` 由用户填写并可修改，同名资产用 ID 区分。POST/PUT 显式指定或修改 ID 会被拒绝；改名不重建主机。详情清晰展示用户名称与平台生成的 ID，ID 只能查看/复制。凭据保存失败可重试，不重复登记。

已按用户修订撤回原先的主机环境方案：不生成 `sdk_environment`，不提供环境配置展示或复制，不扩展 SDK 读取，不传安装元信息、不在 Agent 配置或 SDK 遥测中注入资产字段。SDK、Agent 配置及安装器对应文件与 `0988f2c` 基线对比一致，相关新增测试已删除。SDK 完整归属和心跳汇总仍属 SDD 036 后续设计。

私钥和密码支持临时及按期限托管。新界面密码默认临时复用 15 分钟，私钥默认 1 小时；临时最多 1 小时，Agent 激活后清除。托管需主动确认，默认密码 1 天、私钥 90 天，最长 365 天，到期或撤销清除。旧 API 未传 retention 的密码仍为一次性，用于检查/终端后清除，不能安装；可复用密码支持固定身份核验、安装和卸载，密码与 enrollment stdin 分离。

主页面、导航和首个页签统一为“主机”，隐藏脚本接入按钮，保留旧协议及路由。默认从已登记主机预检、生成计划并审阅确认后安装宿主机 Agent，登记本身不执行远端写入。
