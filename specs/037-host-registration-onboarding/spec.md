# SDD 037：登记主机、凭据有效期与 SDK 主机变量

状态：代码实现与本地验收完成；Doca 在线架构同步受服务端 500 阻断，尚未满足合入验收。日期：2026-10-29。本增量落实用户对 SDD 036 的三项修订，不表示 036 的完整 SDK 归属/心跳汇总已实现。

1. 登记主机后在同一接入流程选择 SSH 私钥或密码的保留策略和有效期；临时策略到期或 Agent 激活提前清除，按期限托管策略保留至到期/撤销，必须主动确认。默认建议短期保存，不默认长期托管。旧密码请求省略 retention 仍按 one_time 处理。
2. 登记生成不可变主机 ID，名称取用户填写的主机名；向管理员展示 `LIGHTMONI_MACHINE_ID` / `LIGHTMONI_MACHINE_NAME` 的可复制环境配置。SDK 在进程环境读取并附加 `lightmoni.machine.id/name`；显式 resource 优先，不覆盖 service/instance 或 Agent host_id。变量是公开归属声明，不是密钥或控制授权，也不替代 036 的确认关系。
3. 主列表移除“脚本接入节点”按钮，默认从已登记主机执行 SSH 检查和 Agent 安装计划。旧脚本路由及 enrollment 协议保留兼容；登记本身不执行远端写入，用户审阅确认计划后才安装。私钥与可复用的限时密码都可用于固定安装/卸载；一次性密码仅用于原有检查/终端。

验收：自选时长及边界、过期/撤销/激活清除、密码检查后仍可安装（非一次性）、秘密不回显；SDK 四语言变量读取/显式覆盖/无变量兼容，浏览器无进程变量依赖；登记→凭据→安装引导、中英文与窄屏、隐藏按钮但旧路由可用；主机元信息随固定安装进入 Agent 配置，不改已有身份。

不在本次范围：完整 SDK 主机关联数据库和状态聚合、自动修改已运行业务服务环境、自动扫描现有容器/集群、未确认即执行安装、线上平台或 vchive 操作。
