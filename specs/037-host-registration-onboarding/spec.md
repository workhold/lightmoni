# SDD 037：登记主机、凭据有效期与平台主机标识

状态：用户修订已实现并通过本地验收；Doca 在线架构同步受服务端 500 阻断，尚未满足合入验收。日期：2026-10-29。本增量落实用户对 SDD 036 的三项修订，不表示 036 的完整 SDK 归属/心跳汇总已实现。

1. 登记主机后在同一接入流程选择 SSH 私钥或密码的保留策略和有效期；临时策略到期或 Agent 激活提前清除，按期限托管策略保留至到期/撤销，必须主动确认。默认建议短期保存，不默认长期托管。旧密码请求省略 retention 仍按 one_time 处理。
2. 平台通过主机 `id` 和 `name` 标识资产：`id` 由平台自动生成并保持不变，`name` 由用户填写、可修改。名称不作为唯一标识，改名不能改变主机 ID、已有凭据及 Agent 关联。本轮不创建主机环境变量，不提供环境配置展示，不扩展 SDK 读取，也不将资产字段额外写入 Agent 配置或 SDK 遥测。
3. 主列表移除“脚本接入节点”按钮，默认从已登记主机执行 SSH 检查和 Agent 安装计划。旧脚本路由及 enrollment 协议保留兼容；登记本身不执行远端写入，用户审阅确认计划后才安装。私钥与可复用的限时密码都可用于固定安装/卸载；一次性密码仅用于原有检查/终端。

验收：自选时长及边界、过期/撤销/激活清除、密码检查后仍可安装（非一次性）、秘密不回显；平台生成稳定 ID，用户配置及修改名称，同名主机通过 ID 区分，SDK 与安装器不新增环境/元信息契约；登记→凭据→安装引导、中英文与窄屏、隐藏按钮但旧路由可用；保留原有 Agent 身份与资产关联。

不在本次范围：SDK 主机变量及读取、完整 SDK 主机关联数据库和状态聚合、自动修改已运行业务服务环境、自动扫描现有容器/集群、未确认即执行安装、线上平台或 vchive 操作。
