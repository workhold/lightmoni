# SDD 123：中心主动运维改用 SSH

状态：实现与验收中。2026-11-12。

## 目标

管理员在中心发起的主机操作使用已登记 SSH 账户与凭据直接连接目标机器，减少等待 Agent 领取作业的时间。Agent 继续负责主机采集、独立上报、心跳、配置与定时任务；业务 SDK 保持直报中心。

## 用户场景与验收

1. 管理员登记主机的 SSH 密码或私钥后，页面不要求设置保存时长；新凭据加密保存且没有固定过期时间，直至管理员撤销或解绑。关闭页面、中心重启、Agent 离线后仍可用。已有已清除的秘密不能恢复，须重新录入。
2. 管理员审阅中心发起的应用部署、网站、证书、备份、容器与主机维护计划后，中心通过 SSH 对同一主机执行受控命令；Agent 离线不应单独阻止这类操作。定时任务仍由 Agent 按计划执行。
3. SSH 不可达、凭据撤销、主机指纹变化、主机目标或账户变更时，操作明确失败或保持未知待核对；不回退 Agent 派发，不自动重放已有副作用。
4. 用户在计划、进度与历史中看到执行通道、目标账户、结构化阶段和最终回执；秘密、完整 SSH 输出与上游密钥不回显。

## 功能要求

- FR-001：机器管理页面新建 SSH 凭据只采用无固定期限保存，不展示过期秒数；服务端默认永久，原 API 显式有限期策略保持兼容。密码和私钥继续加密存储，服务端响应不包含秘密。
- FR-002：已有尚有效且未撤销的有限期限凭据转为永久存储，保留原 ID、绑定和审计；已过期或清除的秘密不得复活。管理员可以撤销或按主机解绑。
- FR-003：中心主动操作复用主机资产、默认 SSH 账户、有效凭据绑定和可信主机密钥。领域计划继续冻结资源版本、批准者和目标；SSH 派发时再次验证机器及凭据绑定，运行期间绑定变化使连接中止。
- FR-004：中心发起的远端操作以固定命令和精确作业 ID 通过 SSH 唤起受管发行包。远端单次进程使用原签名执行器接口或 Agent 作业接口领取既有批准计划并提交有限回执；常驻 Agent 不领取中心主动作业。模型不能直接执行任意 SSH 命令，人工终端仍是独立入口。
- FR-005：远端副作用与回执分离，连接中断或超时进入 unknown；只读核对和人工结束保留原审计，不能自动再次执行。
- FR-006：采集、遥测上报、心跳和定时任务继续使用 Agent 的出站通道及自身凭据；中心 SSH 凭据不下发给 Agent。SSH 单次进程沿用原签名执行器/Agent HTTPS 接口获取冻结载荷、制品和密钥并提交回执，目标仍需能访问中心。
- FR-007：旧版常驻 Agent/执行器不再领取新的中心主动作业；已领取或 unknown 的任务按原租约与核对机制处理，不双派发、不重放。目标主机须先升级至含 `managed-once`、`task-once`、`jobs-once` 的发行包。

## 边界与假设

适用“管理员或中心当前主动发起的机器操作”，包括维护和各受管领域。用户配置的周期任务继续由 Agent 执行。SSH 可达性是中心执行的前提；目标没有 SSH 或有效登录账户时页面给出可修复原因。永久存储不表示凭据永远有效：撤销、远端密码/密钥变更和主机身份变化仍使连接失败。

## 成功标准

- 新建凭据后列表与主机详情均显示永久，重启后仍能用于 SSH；创建请求没有期限字段。
- 受管操作共享同一个 SSH 派发入口，覆盖成功、不可达、撤销、指纹变化和未知结果；成功操作不依赖常驻 Agent 在线，但依赖主机到中心的授权/回执连接。
- 自动化检查确认没有秘密进入响应、日志、命令行或模型上下文，且旧未知作业不会重放。
