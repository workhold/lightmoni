# SDD123 验收记录

## 已交付行为

- 机器管理和连接凭据页面不再要求保存期限。新建 SSH 密码及私钥加密后永久保存，直到管理员撤销或解绑。旧 API 显式有限期仍可用。一次性启动迁移仅延长尚未过期、未撤销且秘密未清除的旧凭据及绑定，不复活失效秘密。
- 中心扫描已批准的普通作业、受管执行器作业和手动脚本任务，以主机默认 SSH 绑定和可信主机密钥连接，一台主机同时只启动一个带精确作业 ID 的固定单次命令。应用、网站、证书、Compose、备份、容器、服务部署和平台巡检沿用原签名计划、授权、制品、密钥和回执契约。常驻 Agent/执行器不再无 ID 领取中心主动操作；Agent 继续采集、上报、心跳及运行定时任务。
- SSH 连接建立前的失败使尚未领取的作业明确失败；已领取作业沿原租约及 unknown 栅栏核对，不自动重放。凭据撤销或绑定变化中断连接，指纹变化给出独立原因。手动与定时任务使用独立恢复标记，Agent 更新检查两者。

## 发布兼容

中心镜像更新不会自动更新目标主机上的已安装程序。已有主机需要通过现有 SSH 更新入口升至包含 `managed-once`、`jobs-once`、`task-once` 的发行包，才可执行新的主动操作。远端单次进程仍需通过 HTTPS 访问中心领取签名计划并提交回执；目标主机无法访问中心时不会产生成功回执。定时任务不要求中心持有 SSH 凭据。
