# SDD 087：参考 1Panel 优化运维界面

状态：实施中。分支：codex/087-panel-ui。用户要求参考 1Panel 优化一版现有 UI。

## 用户任务与范围

日常运维人员需要快速找到主机、应用、网站和证书，判断实际状态，再进入配置或查看执行记录。以现有 LightMoni 为基础，统一共享外壳、应用与网站列表、配置分区；其他管理页面通过共享样式保持一致。

## 验收

1. 采用参考 1Panel 的紧凑管理面板方向：稳定侧栏、轻量顶栏、浅灰画布、白色工作区、蓝色主操作。保留 LightMoni 品牌、既有导航分组与权限可见性。
2. 显式保存的深浅色/强调色/导航偏好继续有效，深色同样可读；新用户默认浅色。无外部字体、图标或新增前端依赖。
3. 应用卡片明确展示服务名、部署模式、状态、集群/主机与实际端口。常用入口优先，维护和破坏性操作归入更多菜单，保留原确认、禁用和未知结果约束。
4. 资源计数与筛选后的条目保持一致；无匹配结果不能误报成尚未安装。证书同步任务默认收起并显示数量，支持按需展开。网站列表对齐网站/后端、发布版本、DNS/TLS 和操作，减少重复解释；公网验证与 DNS 厂商回读不可混称。手动 URL/服务与托管服务仍按既有规则显示及保存。
5. 网站长表单有清晰分区与可跳转目录，所有字段保持挂载、名称和验证契约不变；跳转不提交、不清空输入。
6. 1366px/1728px 桌面、窄屏和放大阅读无正文溢出，长镜像 digest、域名与中文名称可以阅读或查看完整值，键盘焦点可见。减少动态效果时遵循系统设置。
7. 使用真实组件和隔离本机 API fixture 验证导航、筛选、菜单、编辑、保存成功/失败及读回；不通过生产写操作做 UI 回归。保留前后截图、独立视觉评审与验收记录。

## 架构影响

不适用：仅调整前端呈现、信息层级和既有事件入口，不改变 API、权限、凭据、协议、存储、调度或部署拓扑。docs/system-design.md 与 Doca 无需改写；PR 必须说明此理由。
