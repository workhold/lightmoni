# 设计与实施

## 方向卡

品类是需要长时间使用的服务器运维面板，首屏主角为实际资源及其运行/发布状态，主动作是进入配置。参考 1Panel 官方应用列表的紧凑双列卡片、浅色导航、工具栏和低噪声操作行；采用一套明确方向，不复制品牌、截图资产或增加另一套主题开关。

- 视觉：沿用系统字体与 Ant Design 图标；14px 正文，标题22px、分组12px，8px间距基线，6–8px圆角。共享 lm 色值与 Ant Design token 同源对齐，浅深两色均核验。
- 外壳：侧栏/顶栏与内容区有稳定边界，选中项清楚，页面标题不在内层工作区重复。
- 应用：身份和状态在同一行，服务名/部署方式可见，镜像单独一行，主机端口和常用操作分层；更多菜单承担维护操作。
- 网站：桌面按列对齐，窄屏转为纵向条目；服务来源明确，成功状态的长解释退到 tooltip，失败/未知提示保留。
- 表单：使用实际可点击分区目录跳转，字段一直挂载，保留表单值和错误定位，避免切页导致数据丢失。
- 动效：复用资源列表短入场、导航收放、菜单/弹层反馈；只做约150–180ms轻量变化，减少动态效果下关闭；证据以实际状态与浏览器走查为准。

## 顺序

先建立隔离 API fixture 和当前截图，完成共享样式与两类资源列表，再加配置目录，验证后进行一轮无历史上下文的视觉评审并修正。最后记录兼容影响、验证证据，通过 GitHub 功能分支 PR 交付。
