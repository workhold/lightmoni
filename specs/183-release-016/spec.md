# SDD 183：导航与镜像管理体验的 0.1.6 发行

## 范围与验收

- 将已合入的 SDD 180（PR #251，Runtime 测试语义与待审批零进度）、SDD 181（PR #252，集群导航与主机归属）和 SDD 182（PR #253，统一镜像与仓库页面）作为 0.1.6 发行，统一平台、Agent、SDK、MCP 和构建版本。
- 仅从版本 PR 合入后的 main 在本地构建 linux/amd64 中心镜像；固定标签为 `v0.1.6-20261116-060123-amd64`，镜像内继续携带双架构 Agent 与四种 SDK。
- 版本一致性、构建、镜像内发行包 SHA256、隔离健康、版本、鉴权与 MCP 检查通过后，发布固定标签与 `latest` 并回读相同摘要及 OCI revision。
- 发布后通过 1Panel 备份配置、主密钥和 SQLite 一致性快照并升级生产中心，避免重复执行全量遥测卷停服务压缩。回滚使用升级前实际固定标签，保留既有数据卷和环境。
- 线上核对容器健康、实例版本、首页、集群导航、统一镜像页面及既有主机/应用状态。中心镜像更新不自动升级或恢复任何主机 Agent。

## 架构影响

不适用。本发行不新增组件、协议、存储或控制路径；各功能 PR 已分别更新系统设计。

## 发布约束

不使用 GitHub 流水线，不把源码构建或镜像推送当作生产升级完成，不发布 arm64 中心镜像。验证记录只写实际完成的证据。
