# 行为契约

- 回退不得改变当前 Agent 运行模式和权限代次；候选必须具备该模式所需且经过验证的组件。模式缺失提示用户先审阅切换至合适模式后重新生成计划，禁止内部自动提权、降级或重试。
- 缺失或变化的目标组件在切换服务之前被拒绝；当前程序和服务继续运行，失败收尾释放本次锁。
- 中文状态与执行记录导航不更改服务端请求或目标授权范围。
- 未知结果不自动重放写操作，不抹去现场失败。
- 压缩包上限 256 MiB、展开 TAR 上限 768 MiB；索引上限 16 MiB、单段扩展元数据上限 64 KiB。私有临时 TAR 以独占 0600 文件创建，完整预校验后以至多 64 KiB 分块落盘，并在可捕获退出时清理。保留路径、链接、文件类型和磁盘余量校验。
- 大文件 SHA-256 和指纹组成不变；每次读取使用 64 KiB 缓冲区，不将完整 Node 二进制或压缩包同时驻留内存。
- `worker-claim.json` 在事务失败收尾之外独占创建并持久同步，成功取得执行权后才能进入 `preparing`。标记保留于操作审计目录，竞争失败者及中断后的重复进程不得进入失败收尾；部分标记写入失败也保持围栏，等待人工核对。
- `preparing` 的 SIGTERM/SIGINT 协作取消发生在服务切换之前；不可捕获退出不经过 `finally`，不得因此声称已经解锁、清理或回退。
