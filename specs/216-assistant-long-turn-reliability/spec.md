# SDD 216：助手长任务可靠性与运行反馈

## 背景

AI 助手 turn 执行存在硬性 2 分钟总超时（`runtime/src/assistant/index.ts` 的
`AbortSignal.timeout(options.turnTimeout ?? 120000)`，装配处从未覆盖），超过 2 分钟的
多步工具任务一律失败；SSE 在长工具执行期间零字节输出，容易被中间代理掐断；前端流中断
后直接报错，不会自动恢复，尽管服务端 turn 仍在运行且事件持续持久化。同时运行反馈缺少
已用时间与当前工具指示，工具结果只有原始 JSON，长任务过程中用户无法判断进展。

## 目标

1. turn 超时从"绝对超时"改为"空闲超时 + 总上限"：
   - 空闲超时（默认沿用现有 120 秒）：只在无任何模型输出、工具活动时计时；
   - 总上限（新选项 `maxTurnDuration`，默认 30 分钟）：到点必中断兜底；
   - 中断文案区分空闲超时与总上限两种原因。
2. SSE 心跳：turn 运行期间每 15 秒写 `: ping` 注释帧（工具执行期间同样发出，并视为活动）。
3. 前端断线自动恢复：流中断且非用户取消时，按 2 秒间隔轮询会话事件合并，直至该 turn
   出现终态；轮询连续失败或超过客户端上限才报错；恢复期间显示恢复提示而非错误。
4. 运行反馈：会话运行中显示运行条（当前工具、已用时间、步数、停止）；工具活动摘要
   显示已用时间与逐工具状态；每个工具可计算各自耗时。
5. 工具卡片通用摘要化：默认显示关键结果徽标（行数、条目数、耗时等），原始 JSON 折叠保留。
6. 清理 `assistant.css` 中两处整段重复的样式块。

## 非目标

- 不改变工具权限、审批流程、凭据边界与上下文压缩逻辑。
- 不把 `maxTurnDuration` 做成管理后台配置项（仅模块选项）。
- 不为每类工具定制专属结果卡片（保持通用徽标 + 折叠 JSON）。
- 不改变会话/事件的存储格式与 API 形状（新增字段仅在前端视图层）。

## 验收

1. 静默执行 3 分钟的工具调用不会被中断，SSE 每 15 秒出现 `: ping` 帧。
2. 空闲超过 120 秒的 turn 被中断，错误文案为空闲超时；总运行超过 `maxTurnDuration`
   被中断，文案区分。
3. 前端在 SSE 中断后自动轮询恢复：不出现错误提示，终态事件到达后正常结束。
4. 运行中的会话显示运行条与已用时间；工具活动行显示逐工具状态与耗时。
5. `run_query` 等工具卡片默认显示结果徽标，原始 JSON 折叠可展开。
6. `assistant.css` 无整段重复样式块；`npm run typecheck` 与相关测试通过。
