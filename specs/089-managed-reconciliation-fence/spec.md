# SDD 089：受管未知结果的主机互斥一致性

状态：实施中。SDD088线上核对后，privileged_jobs/task_runs已有人工核对，agent_jobs仍为unknown。主机执行和生命周期守卫只看agent_jobs状态，导致新的检查被machine_execution_locked取消，后端观测不能恢复，健康调度撤下受管DNS。

验收：同一受管作业已有完整人工核对时，所有主机繁忙判断使用同一规则不再阻塞；两个作业表和原运维回执仍保留unknown及原错误码，不重放任务。普通未知任务、未核对、身份不匹配、不同能力或不完整核对仍阻塞；活动任务/普通排队任务规则不放宽。验证新受管检查可以执行、生命周期守卫一致、域名和实际HTTPS恢复。

架构变更：主机互斥从单表状态判断变为核对同一特权执行身份与审计的共享谓词。同步docs/system-design.md与Doca基线目标章节，保留原生图块及无关内容并回读；无API、凭据、协议、数据库结构或部署拓扑变化。
