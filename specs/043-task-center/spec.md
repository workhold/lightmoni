# SDD 043：任务中心与主机标签

## 驱动目标

平台统一定义、派发、执行和查看任务。指标采集、服务拨测、目录日志是平台提供的内置任务类型；用户可以调整参数、停用、复制任务，或创建脚本任务。主机标签属于平台主机 ID，不依赖 Agent 是否已安装，卸载和重新接入不丢失。

## 需求与验收

1. 主机列表的“监控任务”列改为“主机标签”，移除匹配任务计数，详情展示该主机生效的任务。未安装 Agent 的主机也可编辑标签。
2. 主机工作台提供“主机 / 任务中心 / 主机标签”，中文和英文同步；任务中心覆盖任务定义、内置模板、目标选择、派发与执行记录。
3. 新安装的平台默认启用指标采集和服务拨测，默认任务应用到所有已登记主机。指标采集在 Agent 接入后运行；拨测未配置地址时显示“待配置”，不得虚构探测地址或执行成功。已有用户配置和停用选择不能在重启时被覆盖。
4. 内置模板与用户任务分离。用户可以调整任务参数、停用、复制为自定义任务；原始平台模板保持不变。主机可覆盖任务的启用和内置采集参数。
5. 任务目标支持所有主机、主机标签或明确主机 ID；标签为任一匹配，直接主机与标签为并集，目标为空不广播。新主机能自动获得目标匹配的默认任务。
6. 自定义脚本支持 Node.js 与 POSIX shell，支持立即执行和固定间隔定时执行；内置采集使用持续配置。脚本源代码、运行参数及目标在每次派发时生成不可变快照。
7. 中心持久化执行记录，Agent 使用独立 control 凭据领取属于自身且仍绑定该主机的执行。租约与领取凭证绑定；丢失租约/重启后的不确定执行不能自动重放。周期任务不重叠，不追赶历史遗漏周期。
8. 执行状态包含 queued/running/succeeded/failed/cancelled/unknown；支持查询输出、超时、取消和显式重试。重试建立新记录，不能改写原始记录。Agent 离线时不伪造成功。对于未重试的 unknown，管理员可以在人工核对后填写原因并明确确认结束；保留 unknown 历史与确认审计，解除生命周期/调度阻塞，不重新执行，也不宣称平台已证明远端停止。
9. 脚本有长度、运行时、并发、超时和输出限制；使用独立工作目录及最小环境，不向脚本注入 Agent control/data 凭据。脚本具有 Agent 进程权限，本次不宣称容器沙箱。
10. AI 助手通过平台工具查询任务与结果；修改、派发、取消使用已有的用户审阅/批准通道，不绕过审批执行生成的脚本。
11. 管理员可修改/执行，普通成员只读。主机删除、Agent 移除/重新绑定不能让旧身份继续领取任务；存在活动任务时生命周期操作必须拒绝或明确终止。

## 架构影响

适用：标签归属、任务控制协议、执行状态存储和 AI 工具边界改变。必须同步 docs/system-design.md 与 Doca 系统设计基线，并回读验证原生图块、相关章节和无关内容保留。
