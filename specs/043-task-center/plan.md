# 实现设计

- 在现有 NodeStore/任务 API 上扩展任务定义；保留内置指标、日志、拨测的原生处理器，不把持续采集改成重复启动的脚本。
- 新建主机标签关系并将已有已绑定 Agent 的标签迁移到主机。任务编译根据主机 ID、标签和单机覆盖生成配置，重装 Agent 读取同一主机配置。
- 平台模板只读，默认任务一次性初始化；脚本定义与持续采集共用目标解析。脚本执行独立于部署 agent_jobs，避免混用部署健康校验状态机。
- 独立 task_runs 持久化不可变快照、主机/Agent 绑定、租约、输出和结果；中心定时扫描间隔任务，Agent 通过出站 control 请求领取、续租/查询取消、提交结果。
- unknown 保持不可改写历史；显式重试创建新记录，管理员人工核对后的 resolve 保存确认人、时间和原因并解除阻塞。resolve 只能经界面人工确认，AI 不提供直接确认工具，晚回执不能覆盖人工决议。
- 前端以任务中心展示内置/自定义任务、派发与记录，主机页面直接管理主机标签。
- 验证：数据库迁移、重启不重置、主机重装继承、无 Agent 标签、默认拨测待配置、权限、目标隔离、重复领取、租约丢失、超时/输出限制、定时不重叠、取消/重试和浏览器闭环。
