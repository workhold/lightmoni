# SDD 186：历史未知任务下的 Agent 强制维护

## 背景

已结束但结果为 `unknown` 的主机任务可能长期阻止 Agent 升级或卸载。管理员需要在远端无活动执行时继续维护，且不能把旧任务伪装为成功或清除审计。

## 行为

- 升级和标准/恢复卸载可选择“忽略历史未知任务”，必须填写原因。常规流程保持不变。
- 平台先列出并固定本次忽略的任务中心、Agent 作业及提权作业 ID，执行只读 SSH 探测；远端生命周期锁、操作锁、身份或权限异常仍拒绝。
- 只允许忽略已进入 `unknown` 的固定记录。运行中、已派发、执行结果尚未过期、其他维护流程、后续新增的未知记录仍阻止维护。
- 审批计划展示并保存忽略列表、原因、操作者和远端证据。执行前再次核对记录及远端状态；旧记录保持原状态，供原页面单独核对。
- 升级成功仍须新 Agent 心跳和发行身份验证；卸载成功仍须远端移除证明及当前主机凭据归属检查。

## 验收

- 一个历史未知提权 `inspect` 阻塞正常升级/卸载，但可生成有理由的强制计划并完成现有审批路径。
- 新的或仍活动的任务、变动的任务状态、远端锁或身份漂移使强制计划失效。
- 忽略范围不能扩散到别的主机、别的 Agent 或后续任务；旧结果及日志不被改写。
- 非管理员不能使用；管理员必须通过交互会话明确审阅计划。
