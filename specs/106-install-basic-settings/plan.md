# 设计

- 安装位置选择紧接访问域名之后、目标集群/机器之前；自动选择提示只说明集群与机器，避免在填写自定义端口时仍声称端口自动选择。
- 必需应用参数之后、折叠的高级设置之前展示端口映射及监听范围。复用 ApplicationPortFields、原表单字段和既有样式，不引入新分组组件或动效。
- 保留 Form.List 的稳定字段标识和高级资源字段 portal，避免影响多集群资源归属。
- 使用隔离 loopback fixture 留取基线与修改后截图；主 Agent 自检改动处及相邻内容，连续三轮核验字段可见性、切换、收起后保留输入和提交错误。类型检查仅针对 web。
- 本次为局部低风险修改，不启动独立视觉评审，不添加装饰或重复说明。
