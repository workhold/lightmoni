# SDD 106：安装位置与端口映射常规展示

## 请求与范围

应用商店安装表单中的「安装位置」和「端口映射」不再放在高级设置内。沿用现有安装表单样式、自动选择默认值和提交行为。

## 验收

- 高级设置默认收起时，安装位置选择始终可见；选择自选部署位置后，直接展示既有集群与机器/实例字段。
- 普通应用的全部端口映射及监听范围在常规区域可见、可编辑，保留 0 自动分配、固定端口约束与用户输入。
- OpenResty 保留固定宿主机 80/443 提示，不生成可编辑端口字段。
- 服务标识、部署模式、可选参数、资源限制和添加集群部署继续放在高级设置；展开/收起不会重置安装位置或端口。
- 中文/英文、桌面/390px 窄屏和 200% 阅读检查；提交失败保留输入，既有请求格式保持兼容。

## 架构影响

不适用：仅调整现有前端字段的展示位置和自动位置提示，不改变组件职责、数据或控制路径、API、权限、凭据边界、存储、协议或部署拓扑。仓库 docs/system-design.md 与 Doca 系统设计基线无需改写。
