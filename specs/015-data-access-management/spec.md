# Specification: 数据接入与凭据管理整理

日期：2026-10-19。分支：`feat/data-access-management`。

## 用户需求

数据接入只保留 SDK 接入与执行节点接入。上报密钥和 Agent 身份在统一入口管理，保留不同凭据的用途、权限和生命周期；数据表管理独立展示，图表模板使用已有监控大盘入口。

## 验收要求

- FR-001 数据接入只有 SDK、执行节点两个页签；页面不依赖模板、密钥列表或数据表目录请求成功才能接入。
- FR-002 管理后台新增「接入凭据」，分为「SDK 上报密钥」「Agent 接入令牌」「节点凭据」。SDK 密钥保留创建、权限编辑、启停和上报记录；明确旧 Agent 仍可能使用既有密钥。
- FR-003 Agent 接入令牌显示签发、过期、待激活、已接入、已撤销状态，提供撤销未完成接入的令牌；生成仍进入执行节点接入流程，明文只在创建时显示。撤销待激活令牌同时阻止后续激活。
- FR-004 节点凭据只显示身份、control/data 用途、有效期、最近使用和撤销状态。沿用现有按节点及用途撤销接口，操作明确说明影响该用途全部未撤销凭据；不显示、下载或重新生成明文凭据。
- FR-005 新增「数据管理」页面，成员可看目录、服务、表类型和保留时长，管理员可改单表保留时长及日志采样/停报规则。全局 SDK 停报规则保留原入口。
- FR-006 旧 `/data?tab=keys|tables|templates` 分别跳转到接入凭据、数据管理和监控大盘；更新 SDK、任务、保留设置等内部链接。成员不能访问管理员凭据管理。
- FR-007 不改 SDK/Agent 上报协议、现有密钥权限、数据库数据或模板 API；SDK 密钥和节点 control/data 凭据不互换，不恢复 Go/Rust 发布。
- FR-008 所有新增管理 API 需要管理员身份；列表只返回明确允许的元数据，不含令牌、token hash、bootstrap、私钥或安装 nonce。过期状态按当前时间准确展示，GET 不修改状态。

## 完成标准

先提交规格、设计、契约和任务，再实现；验证权限、令牌撤销后无法兑换/激活、列表无秘密、旧链接跳转、关键管理操作及桌面/窄屏页面。通过 PR 交付，刷新本地运行版本供用户查看，不自动合并。
