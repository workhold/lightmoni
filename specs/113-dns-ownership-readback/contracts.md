# 兼容契约

无新增公共 API 字段、厂商请求或数据库迁移。

| 记录类型 | 目标值比较规则 |
| --- | --- |
| CNAME | ASCII 转小写且统一末尾带点；有点、无点回读均等价 |
| TXT 及其他类型 | 保持原有逐字比较 |

name/type/line 仍是现有身份字段。CNAME 指向其他域名不等价；TTL、已声明权重、授权和 unknown 检查不变。现有归属 ID 与原始值保留；厂商回读值仍按原样发布。外部等价记录可满足解析，但不登记平台归属或进行写入。

发行契约：固定源提交、双架构镜像和下载包 SHA256 可追溯。生产仅更新中心，原数据卷、主密钥、环境和权限边界保持；不手工改归属日志或绕过外部修改保护。敏感备份只保留生产主机的 0700 目录/0600 文件，仓库只记录脱敏摘要。
