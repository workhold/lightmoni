# SDD 174：Agent 中断恢复修复的 0.1.2 发行

## 范围

- 将已合入的 SDD 173（PR #234）作为 0.1.2 补丁发行，统一平台、Agent、随镜像 SDK、MCP 与构建版本。
- 仅从合入后的 `origin/main` 在本地构建 Linux amd64 中心镜像；镜像内继续携带 amd64/arm64 Agent 和四种 SDK 包。
- 固定标签为 `v0.1.2-20261115-152221-amd64`，根 Compose 使用同一标签；隔离验收后更新 `latest`，旧固定标签保留。

## 验收与边界

1. 版本一致性、类型检查、生产构建和相关回归通过；镜像 OCI revision 等于实际构建源码合并提交。
2. 镜像健康、页面、版本、鉴权和内置发行包 SHA256 在隔离环境验证后，才能推送固定标签与 `latest`。
3. 发布镜像不等于生产部署。替换中心容器需单独确认；vchive 的只读核对与恢复仍按原生围栏和管理员审批执行。

## 架构影响

不适用。仅递增版本并打包已合入实现，不改变组件职责、数据/控制路径、凭据边界、存储、协议或部署拓扑；SDD 173 已承载对应架构文档变更。
