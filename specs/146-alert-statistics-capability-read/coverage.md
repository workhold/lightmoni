## 明确不进入普通 MCP 的能力

- SDK/Agent 高频上报、心跳、任务领取等专用协议。
- 用户/令牌/OAuth/模型/SSH/Registry/供应商秘密和权限自管理。
- 任意 SQL 写入、任意 Shell/SSH、交互式终端、未经审阅的远程执行。
- 未证明持久恢复与授权复验的长任务或高风险直接执行。

## 后续 Goal 不得误报

Slice 3 需要完成各领域提案闭环；Slice 4 需要跨领域索引、OpenAPI 和普通程序 Bearer；Slice 5 需要服务主体与受控自动化。真实 Codex/Claude OAuth 矩阵、生产/主机验证和 PR 合入状态必须分别提供证据。
