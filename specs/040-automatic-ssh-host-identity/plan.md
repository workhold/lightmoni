# 设计与任务

## HLD

中心主机资产管理 SSH 端点与自动观测的服务端身份。登录凭据继续独立加密管理。SSH 连接器在首次握手自动固定当前端点身份，以后自动比对；UI 不参与主机密钥批准。Agent 控制通道与 SDK 独立直报保持原架构。

## LLD 与契约

- `host_key_fingerprint`、`host_key_public_key`、`host_key_observed_at` 只读，保留现有已固定指纹并在匹配时补全公钥。公钥格式为 OpenSSH `<算法> <base64>`。
- 持久化验证器在发送登录秘密/执行命令前核对当前主机端点、已固定key、凭据和活动操作，再以事务/CAS 固定首次key，拒绝竞争或过时结果。终端与固定命令共用验证器。
- 无指纹时能力按直接SSH、有效凭据及互斥状态计算，不产生 `host_fingerprint_required` 门禁。计划在预检后捕获含已记录指纹的revision，apply仍固定该revision。
- 影响目标的编辑在事务中递增 ssh_target_generation 并删除旧checks/取消待审批计划，避免A→B→A复活。地址或端口编辑额外清空公钥/指纹/时间；同一端点更换用户名保留服务器身份。认证完成与exec前重新校验授权/目标，阻止握手后变更窗口；命令已开始后按真实回执收敛。
- 未新增无条件跳过host verifier、手工覆盖信任或任意SSH工具。自动首次记录是TOFU，无带外首次身份核验；后续发现身份变化时停止并返回结构化错误。
