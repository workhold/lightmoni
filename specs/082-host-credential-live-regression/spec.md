# SDD082：主机与连接凭据线上回归

用户已部署正式镜像，要求结合 vchive 开发机回测主机和连接凭据的全部相关能力。以线上实际版本和现场状态为准，不复用历史通过记录冒充当前验收。

## 范围

- 主机 ID/用户名称与系统主机名、SSH 地址、内外网地址、标签、查询和编辑。
- 集中密码/私钥凭据的新增、期限、重命名、绑定、默认选择、使用记录、解绑、撤销、过期门禁和秘密不可读。
- 通过平台执行 SSH 检查、交互终端和 Agent 安装计划、升级、回退、卸载、恢复与重新接入；用 SSH 独立核对现场。
- 只使用 vchive 和明确标记的临时测试记录；其他主机及其凭据只读，不修改业务服务、数据、主机账号密码或真实 unknown 现场。
- 独立 root 执行器先核对当前状态；新增整机授权与实际高权限测试另行明确范围，不因登记用户为 root 自动开启。

2026-11-02 用户明确授权临时完整回测：安装独立 root 执行器并批准提权脚本、容器管理和受管运维，仅执行身份/版本检查、专用测试容器和 LightMoni 自身检查；结束后卸载执行器并撤销权限。测试不包含其他业务服务的部署、备份或破坏性故障注入。

## 验收

保留去秘密的基线、测试矩阵、操作 ID、平台回执和独立现场核对。成功、预期拒绝、实现缺陷、环境阻塞和未执行分开记录。新增临时凭据按短期保存并在测试后撤销；清理仅限本轮测试对象。发现问题先补规格和最小修复，再执行对应回归，不直接修改生产程序绕过平台。

## 架构影响

初始为不适用：核对现有契约并进行回归。若后续修复改变职责、协议、凭据边界或部署拓扑，须在同一 PR 更新仓库设计与 Doca 并回读；不把测试记录当作架构已同步。
