# 226 · 旧 Agent 身份的 Docker 安装栅栏收敛

## 背景

`vchive` 的 Docker 安装记录创建于旧 Agent 身份；主机后来重新安装 Agent，当前 Agent ID 已变化。0.1.33 的只读核对因为“目标已变化”拒绝 SSH，但异常处理又把该 409 写回 unknown，导致历史旧身份记录持续阻塞当前 Agent。

## 需求

1. 服务启动时，若运行中或 unknown 的 Docker 安装记录绑定的是旧 Agent ID，而主机当前 Agent ID 已变化，必须安全收敛为 `failed/docker_install_target_changed`。
2. 只读核对前再次检查主机身份和固定目标修订；已变化时直接返回失败收据，不发起 SSH，也不写回 unknown。
3. 执行期间目标变化时同样收敛为失败，不能保留 unknown 栅栏。
4. 不重放旧安装、不删除远端证据、不自动创建新安装；用户仍需显式创建新的审阅计划。
5. 保留旧记录作为审计证据，失败记录不再阻塞主机任务和 Agent 生命周期。

## 非目标

不处理状态文件内容损坏的细分诊断；不改变 Docker 安装命令或凭据边界。
