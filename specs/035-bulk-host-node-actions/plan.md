# 设计

MachinesPage 负责复选框、选择有效性和操作栏；独立批量窗口固定目标快照，读取最新详情、选择凭据，按动作管理准备、审阅、执行、取消与逐项结果。复用现有固定 API，默认串行，无共享全局秘密。

安装/卸载分两阶段：准备时按主机预检并创建计划，审阅阶段显示每项计划；明确确认后逐台 apply。失败响应通过读取同一计划历史判断失败/成功/unknown，读取失败时标注待核对，不自动重复 apply。用户取消未执行计划时逐项请求已有 cancel，失败保留该项及历史入口。

批量窗口内部使用同步 pending ref 防重和 stop ref；停止不 abort 已启动的远端写入。所有结果各自显示；统一刷新后依据返回状态更新列表。纯前端编排不保证关闭页面后继续调度。
