# 主机与节点批量操作

## 目标

列表首列提供管理员复选框和全选，统一操作栏支持批量 SSH 安装检查、宿主机 Agent 部署、Agent 卸载、节点移除与主机记录删除。成功安装并完成 enrollment 的主机才成为节点；SDK 仍可独立上报。

## 行为与验收

1. 选择支持当前过滤结果跨分页；过滤或刷新使目标消失时自动剔除，普通成员没有选择或批量写入入口。批次最多 50 个目标；打开窗口后固定本次目标，后续选择变化不能改变确认对象。
2. 窗口逐项显示目标、类型、SSH/Agent 条件、凭据选择与不可执行原因，不假设所有记录都适用同一操作。独立 Agent 可移除，但缺少主机连接时不能自动 SSH、安装或卸载。
3. 批量 SSH 检查使用现有固定只读预检。可选有效私钥或一次性密码；密码使用后消耗的行为提前说明。多条有效凭据必须明确选择，不静默任选。
4. 安装和卸载先按主机执行预检并生成现有持久化计划，逐台展示计划、目标身份、影响及有效期；用户统一确认后只执行已审阅计划。安装默认独立 systemd 服务，各主机架构取本次预检结果，不统一强行指定架构。已有关联或安装不能覆盖。
5. 卸载停止 Agent、移除标准受管程序并保留配置/缓存，撤销节点凭据；节点移除仅在中心归档撤销身份；删除主机仅清理平台主机记录。操作名称、确认说明不能混用。
6. 默认逐台执行，结果分为待处理、处理中、成功、失败、不适用和结果未知。单台失败不影响其他目标，不声称批量原子成功；不自动重试安装、卸载、删除或移除。SSH 中断后按已有记录核对，避免重复远端变更。
7. 执行期间同步防重、禁止更换目标/凭据/版本或关闭确认窗。“停止后续”只停止尚未开始的目标，等待当前请求完成；准备后未执行的安装/卸载计划可取消，不能遗留不可见待审计划。刷新或关闭页面后以各主机现有持久化历史为准。
8. 保留现有单项能力、列表删除确认、旧链接和成员权限；中英文、390px、部分失败、重复点击、混合选择、计划到期和取消须验收。
9. 本地演示复用隔离 18080 平台，不操作线上平台或 vchive。没有真实 SSH 条件的演示主机须显示不可执行原因。

## 架构影响

不适用。仅新增浏览器内的选择、逐台请求编排和统一确认展示，调用既有单主机预检/计划/确认/取消、节点移除和主机删除 API；不新增批量后端、持久化任务、认证、协议、任意命令或部署拓扑。服务器仍逐请求执行现有授权、身份、凭据、计划和互斥守卫，因此无需改写仓库/Doca 架构基线。若实现范围改变则重新评估。
