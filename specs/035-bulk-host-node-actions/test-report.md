# 批量主机与节点界面验收

## 结果

基于生产 Web 构建运行隔离浏览器验收，**24 组验收点全部通过**；未捕获浏览器异常，未出现未预期的 HTTP 请求。原始结果见 [bulk-host-node-ui-report.json](bulk-host-node-ui-report.json)。

```sh
node web/src/app/verify-bulk-host-node-actions.mjs
```

脚本先复制 `runtime/public`，再使用 Playwright 加载该副本。所有静态资源和 API 均被拦截，API 响应来自元数据夹具；没有访问线上平台、vchive、SSH、模型或真实凭据，没有执行远端部署、卸载或删除。

## 验收范围

- 列表首列复选框、跨分页保留选择、清除、任务标签过滤剔除、刷新后剔除不存在的目标、跨分页最多 50 项。
- 普通成员无复选框和批量入口，不请求主机或连接凭据；主机历史深链打开准确目标，过期深链明确显示 404。
- 主机与独立节点混合选择逐项展示不适用原因；多条凭据必须显式选择，一次性密码提前说明消耗且不能用于安装计划。
- SSH 检查 HTTP 200 但 `ready=false` 仍判失败，后续主机继续；停止凭据准备时等待当前详情返回，不继续请求后续主机或 SSH。
- amd64、arm64 分别使用各自预检架构生成持久化计划；审阅目标、步骤、有效期后统一确认执行；过期计划不可执行。
- 创建计划响应丢失时，按同一检查和凭据从历史恢复；不再次创建。取消失败时保留未执行计划和窗口，确认取消后才关闭。
- 安装单项失败继续后续目标；同步双击不重复发送 apply；停止后续等待当前主机完成，仅取消未执行的后续计划。
- 卸载通信中断读取原计划并显示未知与历史核对入口，不重复 apply。
- 节点移除单独确认撤销身份，跳过仅主机记录且不远程卸载；主机删除单独确认清理平台记录，逐项保留失败结果且不撤销节点身份。
- 中文、英文 390px 界面和批量窗口无横向页面溢出；实际截图已人工查看，长内容可滚动。

## 验证边界

本次验证浏览器的选择、计划审阅与逐台请求编排。服务器逐请求授权、实际 SSH、Agent 安装和卸载沿用既有单项能力；本报告不将 API 夹具结果视为真实主机操作成功。
