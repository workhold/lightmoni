# SDK 接入设计

## 现状与范围
DataPage 混合五个入口，SDKSetup 不选择密钥，中心所有 OTLP 请求必须带密钥。改为 SDK 样例、SDK 密钥、豁免表三个 Tab。保留现有深色工作台、AntD 表单/弹窗、代码高亮和上报地址组件。分支 codex/sdk-onboarding，主干为 origin/main。

## 数据与后端
Auth 初始化新增 sdk_exempt_tables(name PRIMARY KEY,description,active,created_at)，默认空；管理员 CRUD，登录用户读取。表名复用 validTable/systemTable 校验，不自动建业务数据表。Auth.validateKey 增加显式 allowExempt 可选参数，仅 OTLP 与 SDK 配置拉取使用；仅 Authorization 头完全缺失时允许返回匿名身份，allowed_tables 为实时启用豁免名单，id 为空。旧下载与节点控制入口仍要求密钥。错误/空 Bearer 不降级。
Ingest 每次在幂等命中前校验名单；无密钥批次加独立命名空间，写入 key_id 为空，自监控记录也只落目标豁免表，不路由系统表。旧带密钥请求、幂等数据保持兼容。匿名 SDK 配置仅可读豁免表策略，SDK 停报规则沿用现有协议。

## 界面与状态
样例配置置于代码前：语言、服务、表、地址、认证模式。默认密钥模式与直连中心，必须明确选择有效密钥；无密钥模式展示启用豁免表及用途推荐。空密钥下拉只有创建按钮；非空下拉在底部固定新建按钮；弹窗仅填名称，后台按当前合法表创建最小授权密钥。完整值仅留组件内存；旧密钥环境变量使用指名占位。筛选权限并修正失效选择，加载失败禁用生成。
推荐应用日志/业务指标/前端事件，以随机 16 位十六进制后缀命名；推荐本身无副作用，保存后才启用，自动选中新豁免表。豁免列表支持说明、开关、删除，不删除遥测数据。
执行节点安装改到 /agents/install，旧 /data?tab=agent 重定向并保留 group；单表管理独立组件移至 /admin?tab=tables，旧表链接重定向。模板由原有大盘编辑器继续提供。

## 视觉与交互验收
主动作是复制当前样例；配置区保持紧凑、代码在下方；删除重复语言和冗长说明。AntD 弹窗/下拉动效提供主操作反馈，认证切换内容短淡入，首屏配置区一次淡入；支持 prefers-reduced-motion。分别保留空下拉、新建选中、无密钥推荐、名单、390px 与 200% 证据。原样式不另建主题。独立视觉评审不涉及后台授权判断。

## 检查
有意义的契约测试覆盖匿名鉴权、失效/错误凭证、系统表、幂等隔离、权限、重启持久化；四语言生成测试检查变量、安全转义和无密钥清除；真实 ClickHouse/API/浏览器隔离验收。运行相关类型与单元检查。UI 验收连续三次；完成后按会话已授权的本地运行目标更新一套实例，保留数据，未获授权不合并。

## 实际样例联调补充
Python 3.9 实测发现既有传输在已完整读取且连接已关闭时，仍对旧 socket 调用 settimeout，误报 Bad file descriptor 并重试到截止时间。为使本功能提供的 Python 样例可运行，检查保留取消/截止时间校验，仅对仍打开的 socket 更新超时；补充真实 Connection: close/chunked 回归，不改变上报/重试契约。
