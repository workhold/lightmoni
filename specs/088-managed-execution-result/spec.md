# SDD 088：受管作业结果核对入口

状态：实施中。作为SDD087的线上验收补充。

线上中心升级期间，一条inspect作业因502保留unknown并持有主机互斥。已只读核对目标日志：unknown、无活动作业、执行unit不存在、无managed操作锁，业务容器仍运行。但操作记录没有复用现有的人工核对界面，管理员无法在产品内处理该受管作业。

验收：管理员从应用安装记录或操作执行详情查看对应主机作业；仅接受同一job ID、主机和operations.managed.v1能力的结果。普通旧作业404时不显示错误控件，其他错误可重读。人工核对沿用现有原因、确认、身份校验、审计与未知状态保留，不重试或改成成功，不自动读取敏感输出。非管理员不读取/显示入口。卡片将互斥错误显示为可读说明，错误码在详细记录及tooltip保留。

架构不适用：复用已存在的特权作业GET/cancel/reconcile API与同一结果组件；权限、主机互斥、凭据、数据结构、状态语义和执行路径保持现有契约。新增的是现有运维记录的呈现入口，不扩大授权或新增执行能力，无需修改系统设计或Doca。
