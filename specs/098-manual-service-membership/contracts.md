# 中心配置与观测契约

| 条件 | 手动模式 | 托管模式 |
| --- | --- | --- |
| 从未就绪 | 不发布成员 | 不发布成员 |
| 已就绪后失联/不健康/意外停止 | 中心成员和解析保留，原机器可执行时按中心配置恢复 | 向中心反馈，宽限后按副本目标和最低预算迁移/补齐 |
| 对账确认实际不一致 | 当前中心配置自动 apply/stop/remove，固定原机器 | 当前中心配置自动修复，运行服务复用预算和调度 |
| 原成员被旧健康逻辑撤下 | 有历史成功且仍获授权时恢复 | 不自动重加已撤旧成员 |
| 人工修改中心目标 | 按新目标收敛 | 按新目标收敛 |
| 未知执行或身份变更 | 核对/阻塞，不绕过 | 核对/阻塞，不绕过 |

availability=retained 表示中心成员保留、实际状态等待恢复；不计为真实健康。机器状态不能修改应用 spec/revision、中心 desired state 或手动发布成员。

网站失败回执可含 published={state:succeeded,revision,enabled}，只保留简短成功证据，当前错误不隐藏。DNS 取中心授权配置与成功版本交集，不发布未验证的新域名。HTTP API、执行权限、Agent 协议不变。
