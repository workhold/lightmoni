# SDD 204：Agent 中断恢复核对卡片

## 背景

Agent 升级进入结果未知时，主机管理弹窗同时展示状态、计划、执行影响、恢复影响、凭据和多个告警。用户难以找到“核对—确认—恢复”的下一步，也容易误把长说明当作需要立即处理的错误。

## 目标

1. 为 `unknown` 更新提供单独恢复核对卡片，主视图只保留主机、当前/目标发行、最后阶段、SSH 凭据和两个顺序动作。
2. 明确“只读核对”是第一步；“审阅后恢复”默认关闭，必须勾选简短确认且读取到当前恢复修订后才可用。
3. 上次恢复未确认时禁止再次恢复，并只用一行关键事实提示锁定原因。
4. 恢复影响、操作 ID、恢复修订和完整日志折叠为次要信息；不隐藏安全边界。
5. 保持现有只读 reconcile、恢复修订复验、凭据校验和禁止重放协议不变。

## 非目标

- 不自动恢复、不自动重试维护。
- 不修改恢复 API、远端维护器或审批模型。
- 不把恢复入口暴露给非管理员。

## 验收

1. 默认卡片先引导只读核对；恢复按钮关闭。
2. 勾选确认且凭据和恢复修订有效后，恢复按钮才开启。
3. `recovery_requires_verification` 存在时恢复持续关闭并提示先核对。
4. 中英文和窄屏布局可读，不出现横向溢出。
