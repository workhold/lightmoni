## 最终行为

管理员从应用菜单或系统备份页下载本发行包的固定 Python 工具，核对 SHA256 后在数据所在主机执行。应用归档覆盖同机全部平台实例的持久挂载、运行配置与可选精确镜像；标准部署归档覆盖中心 state/master.key/SQLite 与 ClickHouse，并强制包含镜像。归档流式写入，不受旧单目录256MiB内存缓冲上限影响。

确认停机后核对配置、数据消费者和整个 Docker 事件窗口；部分停机失败或受控取消时只恢复原运行且身份未变的容器。源/输出重叠在任何停止前拒绝。干净停机、归档全部校验成功和排他发布共同决定成功，不能由文件存在代替。

恢复先验证全部字节、路径、链接和精确镜像身份，再获得 daemon 项目排他锁；每次只创建带随机操作标识的新卷，核对无消费者/空内容，并逐文件回读内容、uid/gid/mode/链接。生成 Compose 而不自动启动。美元符正确转义，保留安全限制和停止参数。镜像归档拒绝可变仓库标签，兼容经典 config ID、内容寻址 manifest 及 OCI index，并沿内容摘要验证到实际配置。

S3 采用受保护运行时凭据、SigV4、条件PUT及完整GET校验；结果未知不自动重写。systemd 仅生成文件，是管理员另行安装的本机root持续授权；脚本、配置、凭据及祖先受root保护，Python隔离启动、凭据三项白名单、清洗Docker环境、文件锁防重叠。平台已有备份计划则封存真实authorizer和不可丢失的来源，在派发/领取/开始前重验授权；两种权限模型分别记录。
