# SDD 090：UI交付验收与Registry后端隔离收口

状态：实施中。UI、受管核对入口及双层互斥修复已经发布。最终复查发现Registry当前配置新增172.21.0.16:20001/20002，原主机规则仅保护20000；公网20002的/v2/实际返回200与registry/2.0，属于未按内网绑定意图隔离的后端。

验收：通过既有签名root脚本作业，将现有防火墙脚本的受管后端集合扩展为20000、20001、20002。仍只匹配172.21.0.16、TCP和ORIGINAL方向，受信172.21.0.0/20保持访问，HTTPS入口正常；不停止Docker或防火墙依赖单元。脚本校验目标IP、root所有权、原文件摘要，原子替换并保留原配置备份。公网不能直连这些后端，私网/v2/与HTTPS鉴权仍通过。

同一PR保存SDD087–089最终线上证据，确认UI、真实Demo按钮、新检查、DNS/HTTPS、私有镜像摘要；不把暂态排队当作失败或自动部署尚未批准的新应用配置。仅部署资产与证据，不修改中心/Agent运行时代码，镜像保持20261103-1bfd49c。

架构变更：实际部署的Registry私网后端端口集合与防火墙匹配范围变化，同步仓库第86章及Doca对应原生段落并回读；既有节点/连线、权限、协议、凭据及执行路径保持不变。
