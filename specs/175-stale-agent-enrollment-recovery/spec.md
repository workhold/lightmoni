# SDD 175：远端卸载后的同机残留 Agent 身份修正

## 背景

vchive 的程序、服务与工作进程均已移除，但中心保留同一主机多次安装产生的六条 active enrollment。现有状态修正只接受当前 Agent ID，遇到其他历史 ID 直接拒绝，导致无法结束原 unknown 更新并重新安装。系统设计已要求撤销同机旧身份与待激活预约，实现与该语义不一致。

## 需求与验收

1. 只有固定只读 SSH 证据确认 Agent 程序、服务、helper 和工作进程均不存在，路径/身份/锁安全时，才能创建状态修正计划。
2. 同一主机上其他历史 Agent ID 的 active enrollment 必须进入计划 identities，不再仅因历史 ID 拒绝。其他 Agent 的有效 executor 或跨主机工作仍失败关闭。
3. 审批前继续复验目标 revision、凭据版本、远端观测和完整影响快照；任何新增/变化都使原计划失效。
4. 成功修正时取消同机所有已列入快照的有效 enrollment，同时撤销当前 Agent 凭据并保留配置、缓存与业务数据；其他主机的 enrollment 不变。
5. 不直接写生产数据库、不自动安装、不自动执行状态修正；仍由原页面输入主机名称并明确审批。

## 非目标

不扩大运行时权限，不恢复或伪造未知任务成功，不删除远端文件，不改变现有 SSH/Agent/MCP 凭据边界。
