# Validation Guide

1. runtime/web/TypeScript SDK类型检查，相关Node及各SDK测试。
2. 真实签名执行回归：同主机顺序入队、完整核对与未核对unknown。
3. 托管区域与多机器集群安装入口不填域名，确认稳定生成与DNS原因；网站只CNAME。
4. HTTP模板只填域名与必要参数，检查自动位置/端口/证书/网站；失败重试不增加资源。
5. 仓库只5000，单仓库推送拉取与数据保留。
6. SDK空配置读环境与显式覆盖；公共响应无秘密。
7. 本地UI默认/失败/窄屏，连续三次交互检查；证据放evidence。
8. 更新仓库与Doca设计，按最新seq回读文本和原生图节点/连线。
