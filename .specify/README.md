# Spec Kit tooling

Shared Spec Kit scripts and templates under this directory, and the Spec Kit skills under `.agents/skills`, were installed from [github/spec-kit](https://github.com/github/spec-kit) version1.0.4. The upstream MIT notice is preserved in [LICENSE](LICENSE).

The project constitution and feature specifications are maintained for LightMoni. Machine-local feature pointers and extension overrides remain excluded by `.gitignore`.
