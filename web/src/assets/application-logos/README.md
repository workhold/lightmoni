# Application logo sources

These 31 local assets identify the applications in the built-in catalog. They are bundled by the frontend; loading a logo does not contact the brand, an icon CDN, or any other third party. Each image has a different SHA-256. The registry entry uses the Docker emblem, and the SonarQube entry uses the SonarQube Server emblem.

`sources.json` records each exact repository revision, source path, SHA-256, collection license, upstream brand-license metadata when supplied, and any change. Simple Icons paths are unchanged; their upstream brand color is set on the root SVG. The other images are retained byte-for-byte. No image was synthesized from initials or generated by AI.

Internal gradients, masks, filters and fragment references are retained where they form part of the original artwork. Custom user uploads follow the application's separate raster-upload contract and do not use these trusted SVG sources.
