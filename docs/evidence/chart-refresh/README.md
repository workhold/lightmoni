# 大盘自动刷新闪屏修正（2026-10-11）

自动轮询原先会给全部面板同时显示加载提示，并先用新的时间范围重绘旧数据，再用查询结果重绘一次。查询耗时、空告警列表与图例状态的重复赋值还会触发额外绘制；G2 异步绘制期间直接操作同一画布，可能短暂显示未完成的画面。

本次修正：

- 后台查询保留上次结果，只在首次加载时显示查询提示。查询结果、执行时间范围和时间桶元数据一起提交。
- 图表结果比较排除请求耗时等元数据；不变的告警、变量选项和隐藏曲线保留原引用。回调稳定化和 React memo 减少无关绘制。
- 所有数据与尺寸更新经过同一异步绘制队列，正在绘制时合并等待中的更新，只使用最后一次配置。
- 重绘期间用上次完成的画布覆盖当前画布，成功完成后再切换。缓冲区保留原始像素分辨率与面板背景；失败和重试期间不以未完成画面覆盖缓冲区，不影响鼠标交互。

## 验证

`npm --prefix web run typecheck`、生产构建及 Linux arm64 服务构建通过。前端回归共 44 条全部通过，其中 6 条新增测试覆盖画布保留、慢绘制与连续更新合并、失败后重试、卸载、结果签名及图例引用稳定性。测试使用可控的慢绘制和模拟画布，不能代替真实浏览器录屏。

真实大盘在更新服务后仍返回完整查询结果：CPU 趋势、内存和 CPU 当前值各 599 行，业务请求量 81 行。读取到用户大盘版本为 17；本轮没有写入大盘定义。详见 [API 验证](api-results.json)。

已更新 `http://localhost:18380` 的本地 Docker 服务。健康检查通过，首页与全部 20 个 JS/CSS 文件均与最新构建字节一致，详见 [部署验证](deployment.json)。浏览器需要刷新页面以加载这次代码。

自动浏览器读取被浏览器安全策略拒绝，本轮没有尝试其他浏览器通道绕过限制。未取得现场录屏，不能声明真实页面闪屏已完成视觉验收。
