# UI 与交互设计说明

使用 [oil-ui](https://github.com/oil-oil/oil-ui) 的产品任务、视觉层级、动效与真实证据流程；本文记录设计决定，实际界面与复查证据分别存档。

产品品类是日常排障工具。大盘首屏主角是趋势和异常，日志首屏主角是可检索记录与当前位置。参考 Grafana 的面板编辑流程、Kibana Discover 的查询与上下文流程，保留熟悉的信息密度。监控大盘按用户最新选择采用深色工作区，其他模块沿用明亮工作区；细分隔线与单一蓝色操作强调维持一致。

布局：稳定左侧导航、顶栏全局时间/刷新、中心任务工作区；大盘网格和日志三栏为两个不同布局。日志左栏字段可折叠、中栏过滤/时间图/虚拟列表、右侧详情抽屉。大盘编辑时目录与SQL在左、预览在中、图表映射在右。助手可作为可收起侧面板，展开不能遮挡当前保存/运行入口。

React + TypeScript + Ant Design 共享组件按产品主题封装。禁止原生select、window.alert/confirm/prompt；Select/Combobox支持键盘、搜索、多选，Modal支持焦点锁定、Escape与恢复焦点，输入使用受控Input和行内错误。原生日期弹窗也不用，采用React日期/时间组件。删除/禁用Key/发送测试/保存AI草稿都使用同一确认流程，展示具体对象及结果；失败保留输入。

AntV G2统一图表渲染与交互，支持tooltip、图例选择、拖选时间、缩放后真实SQL重查。表格保持原整数文本，Canvas没有键盘读数时提供可访问数据表与操作入口。时间、SQL编辑器、请求状态、主题、图标和空状态只维护一套。

三处基础动效：运行/保存按钮立即显示处理中并交出结果；日志行与详情抽屉做短促同向过渡；首次进入大盘内容按阅读顺序轻显现。高频刷新不重播入场、不滚动整个页面、不让数字动画伪造中间读数。减少动态效果时状态直接到位。最终保存录屏或起中末三帧；静态截图不能证明动效。

验收视口1280×800、1440×900和窄屏；100%/200%缩放检查中文、长service/表名、长日志及按键。保存/刷新/重启重新读取，大盘与日志按核心对标矩阵走真实数据。初版完成后独立视觉评审，截图/录屏与剩余差距记录到任务目录；当前没有真实视觉评分。

## 2026-10-10 交互改造

用户指出普通后台式的功能入口不能满足 Grafana / Kibana 操作预期。本轮以 [Grafana 面板编辑器](https://grafana.com/docs/grafana/latest/visualizations/panels-visualizations/panel-editor-overview/) 和 [Elastic Discover](https://www.elastic.co/docs/explore-analyze/discover) 的主要工作流为参考，保留现有配色，把任务空间与操作可发现性作为改造重点。

大盘明确查看、编辑、未保存、保存与取消还原；拖动把手与缩放角在编辑态可见。面板改为完整工作台：大预览、独立查询页签、实际结果的字段选择及十类图表图库；窄视口将配置移至独立抽屉。SQL 使用明确的 ClickHouse 颜色主题、表字段/函数/时间宏补全与查找，不把每次输入当成一次查询。

日志页压缩查询与时间图，字段表达式生成可编辑过滤条件；时间桶可选择，字段 Top 值独立查询完整时间范围，按 service、level 和属性点击筛选，再进入原始日志与链路。聚合与原始日志切换使用同一结果区，避免切换后只有空白。聚合中注明范围与截断边界，不将已载入列表的样本频率当成完整分布。

实际截图在本机 [交互证据](../artifacts/screenshots/docs/evidence/interactions/)，文字报告见 [独立审阅](evidence/interaction-review)。复查报告不打分，记录每个缺陷及处理；动效仅在取得起、中、止或录屏后标为通过。共享外壳支持收起导航，顶栏及页面间距收紧；减少动态效果时保留极短完成事件，避免保存弹窗停留在离场状态。

## Grafana 大盘操作对齐（2026-10-10）

新建大盘进入编辑画布；添加可视化只选择图表类型，再进入预览、连续 SQL 查询、字段与显示设置；不预先选择表或查询起点。新图表按首个真实查询结果适配字段，饼图优先使用类别、服务字段。标题菜单提供单独查看、直接编辑和数据检查；全屏查看可直接进入编辑，应用后返回大盘草稿，统一保存。布局继续使用 Leafer 手势，拖动标题与右下角缩放，取消编辑恢复快照。

保存始终包含面板、查询、布局、名称、描述与变量定义；已有大盘默认保留服务器上的默认时间、刷新和变量选择。用户可在保存弹窗勾选当前时间范围与刷新间隔，及当前变量默认值。新大盘初次保存默认采用当前选择。保存失败保留草稿和输入。

动效沿用运行、保存按钮的即时状态反馈、AntD 弹层与抽屉切换、页面首次轻量出场；高频数据刷新不重新播放页面出场。减少动画规则沿用应用设置。没有完整录屏或三帧之前不声明三处动效完成验收。

本轮使用真实 Docker API 和本机 Agent 数据。连续三轮鼠标拖拽、键盘缩放、图表类型切换、保存、刷新回读和默认时间恢复结果在 [three-rounds.json](evidence/grafana-dashboard/three-rounds.json)。桌面、751px、390px 及新建、查看、编辑、时间、保存状态截图位于 [大盘证据目录](evidence/grafana-dashboard)。独立评审结果另存同目录。

## 深色主题与显示设置（2026-10-11）

按用户最新要求移除新增的 As table 菜单和查看切换。原有表格可视化、原始数据检查和导出仍有各自入口。大盘、全屏图表、编辑器、SQL 编辑器、添加可视化、时间选择器和保存弹窗采用统一深色，页面背景 #111217、面板 #181b1f、蓝色操作强调 #5794f2；坐标轴使用清晰灰色文字和细网格。

使用 Grafana 官方 @grafana/data 格式化器，覆盖 25 类、273 种单位，以及自定义前后缀和 SI 格式。使用标准单位标识 percentunit（0–1）和 percent（0–100），不保留旧单位别名。轴、图例、提示和数值面板共用格式化；原始检查器保留精确数据。

图例默认显示 Last*、Avg、Max，可选择列表、统计表格或隐藏，支持 20 种计算。数值面板按每条序列计算，平均值和最大值在真实业务数据上分别验证为 155.85 次、166/167 次。默认折线不绘制数据点，多序列使用不同颜色；按名称稳定排序，刷新不会因 SQL 同桶行顺序变化而随机换色。可在图例或显示设置覆盖单条颜色和名称，保存后重新打开仍回显。

折线、面积、柱图和直方图统一使用自动 Y 轴范围。默认包含 0，正值峰值位于绘图区约 85% 高度；显示设置中的“Y 轴范围”也可选择“贴合数据”，在最低点和最高点两侧各留约 15% 空间。`left_zero/right_zero` 为 false 时启用贴合数据；左右轴独立，手动 `left_min/left_max/right_min/right_max` 优先于自动范围，清空后恢复自动。堆叠范围按同一位置的正负总值计算，显示中的阈值和告警标记纳入对应轴范围；对数轴在对数空间留白。常量和全零数据也具有有效展示范围。

390px 窄屏编辑器将显示设置移入独立抽屉，图表类型和 SQL 运行入口可直接访问；添加图表弹窗内部滚动，底部创建入口固定可见，十种图表均可选择。验证和截图索引见 [本轮验收记录](evidence/grafana-dashboard/README.md)。


## 全站主题、直接编辑与告警（2026-10-11）

全站默认深色；“设置 → 外观”可选择深色/浅色，当前浏览器持久保存。主题同时覆盖导航、概览、数据接入、节点助手、日志、SQL、告警、AI、弹层及 Monaco。时间控制和刷新位于大盘标题右侧，与“添加可视化”同一组；没有保存成功横幅或拖拽说明条。

桌面大盘直接拖拽标题、缩放右下角。定义发生变化后才出现保存/放弃操作。后端在事务中保存每次版本快照；409 显示当前版本，用户可保留草稿、另存或覆盖明确显示的版本。覆盖也受 revision 约束，确认期间再次修改仍返回冲突。窄屏纵向展示面板，保留桌面布局；图表编辑可照常打开。

编辑器的 SQL 查询按行连续展示，有独立名称、启用、复制/删除与参数；来源表由 SQL 自身决定。图例统计可放在下方或右侧，右侧宽度可配置；小面板自动转为下方，长名称省略并保留完整提示。刷新复用 G2 实例与固定面板尺寸，加载提示以浮层显示，不推动页面。

面板设置的告警页直接选择当前图表的查询或某条曲线，设置高于/低于阈值或多久没有打点，并直接绑定告警组；不提供关联已有规则的选择器。可添加多个独立条件，默认判断最新点，另可选择窗口平均值、最大值、最小值。阈值使用真实查询原始单位，水位线跟随曲线所在轴，没有打点只显示真实触发和恢复时间标记。保存告警先验证实际查询再启用，失败保留输入；尚未保存的条件会阻止应用面板。告警保存后立即生效，图表关联及显示选项随大盘保存；应用图表查询或字段映射修改时同步更新这些图表告警。图表选定告警组覆盖表默认组；共享通知目标继续去重。事件按所选范围查询后限量 500，并明确提示截断。“设置 → 告警配置”及告警中心集中管理全部规则。SQL/日志规则共用类型化参数与后端判断流程。独立 Trace 页面与专用查询路由暂时移除；日志页增加 Trace ID 字面筛选，详情动作保持来源表和绝对时间。

当时按统一的新接口开发：单位无旧别名，告警 kind 必填，版本表没有历史结构迁移分支。节点任务配置现已按下文“执行节点与任务标签”升级为独立资源；旧 `/agent-groups` 保留安装与已部署节点的兼容。

真实 Docker/Agent 验收、三轮交互和刷新稳定性证据见 [本轮记录](evidence/workbench-next/README.md)。静态页面有独立评审；完整动效录屏仍未独立验收，不据此承诺动效全项通过。

最后按用户截图简化新增图表：只选择可视化类型；不预先选择表或查询起点。查询编辑行无 table 下拉，FROM 决定各自来源，允许同一图表的多条 SQL 访问不同表。空白 SQL 等待用户运行，有明确校验与预览空态。

## 自动刷新闪屏修正（2026-10-11）

后台轮询不再给已有结果显示加载浮层，数据与已执行时间范围一起更新。查询耗时等元数据不触发图表重绘；不变的告警、图例和变量选项复用引用。数据和尺寸变化通过同一绘制队列，慢绘制期间只保留最新待更新配置。重绘时显示上次完成的画布，成功完成后切换；失败后重试继续保留完整旧画面。缓冲区匹配实际背景及像素分辨率，不占布局空间、不拦截鼠标。

类型检查、构建和 44 条前端回归通过，真实大盘查询与部署资源一致性验证通过。自动浏览器检查被安全策略拦截，尚无此次修正的现场动画验收。证据与限制见 [刷新验证记录](evidence/chart-refresh/README.md)。

### 菜单、排序与编辑链接补充（2026-10-16）

## 模型管理与用量（2026-10-17）

`/admin?tab=models` 保持原路由，入口名称为“模型管理”。模型连接卡下方提供管理员单价表单，币种 CNY/USD，输入、输出单价单位为每百万 token；留空未知，0 表示免费。单价绑定服务地址、协议和模型，不修改密钥；连接变化后刷新单价，旧身份保存返回冲突提示。

## 主机、Agent 通道与任务标签（2026-10-29 修订）

软件称 LightMoni Agent，是已登记主机上的管理通道，内部采集模块称采集器。网页 AI 助手保留独立名称。主机管理统一提供主机、任务管理、任务标签；主机资产是列表的唯一来源，不再展示独立脚本节点或提供手工关联入口。用户填写名称，平台生成不可变主机 ID；可在同一资产上编辑名称及 SSH 目标。任务标签过滤作用于主机关联的 Agent 及任务，当前监控任务为指标采集、服务拨测、目录日志三种。

主机列表展示 Agent 在线状态、标签、匹配任务、配置同步状态和心跳，展开查看身份、队列、最近采集错误及有效配置。管理员可多选或清空标签；成员只能读取主机 ID/名称及允许的 Agent 信息，不读取 SSH 地址和凭据。任务按类型提供表单并独立启停，空目标明确说明不会下发；冲突或保存失败保留输入与原有效配置。标签显示 Agent/任务引用数量，可跳转过滤，默认及在用标签禁止删除。

管理员从登记主机的 SSH 预检与部署计划选择初始任务标签，接入后可绑定多个。enrollment、control/data 凭据与业务 SDK Key 隔离，不提供旧共享 Key 控制面兼容。凭据保留期限、逐主机批量结果、计划审阅与取消均有明确反馈；移除/卸载 Agent 保留主机资产，删除有效身份所在主机需先处理 Agent。SDK 默认独立直报，不依赖 Agent，不新增主机 ID/名称环境变量。

当前规格与验收见 [038 主机登记部署](../specs/038-registered-host-agent-onboarding/spec.md) 和 [验收记录](../specs/038-registered-host-agent-onboarding/validation.md)。[006 执行节点](../specs/006-execution-nodes/spec.md) 与 [其验收记录](../specs/006-execution-nodes/validation.md) 保留历史语境，接入身份与主机展示以 038 为准。

## 主机登记与登录凭据保存（2026-10-29，SDD 039）

“登记主机”使用单屏表单，立即展示主机名称、地址、SSH 端口、登录用户名、登录方式、密码或 SSH 私钥输入、保存时长；默认密码登录、保存 6 小时。登录方式与保存时长分别选择，切换密码/私钥时清除原秘密。主机公钥与指纹不再提供输入或确认，首次 SSH 握手自动记录，详情只读可查看和复制；指纹、主机 ID 和名称是资产元数据，不随登录秘密到期而删除。

保存时长提供有限期限、自定义和“永久保存”。有限保存默认 6 小时，最长 365 天，到期或撤销清除；永久没有固定过期时间，选择后须明确确认，不额外展示保存期限提示块。有限和永久凭据均加密存储，不回显，Agent 激活不会提前清除；详情及凭据选择中，永久凭据显示“永久，直到撤销”，不能按空时间显示成已过期。原有临时/一次性凭据可显示其实际策略与状态，不成为登记默认。

主操作在同一表单完成主机登记与凭据保存，另有明确的“仅登记，稍后配置凭据”入口。凭据保存失败时保留已创建主机 ID、原输入及错误供就地重试，不重复创建主机、不开始 SSH；关闭后重开清理秘密。既有主机的“添加凭据”复用相同登录方式与保存时长字段。保存不会执行远端操作；终端、预检及安装/卸载各自保留原有校验与审阅。中文、英文和 390px 窄屏使用相同信息层级。当前契约见 [SDD 039](../specs/039-host-registration-credential-retention/spec.md)，真实验证另行记录。

## 自动 SSH 主机身份（SDD 040）

登记和编辑不含主机公钥或指纹输入，也不展示连接凭据安全提示横幅。主机详情展示只读公钥、SHA256 指纹和记录时间；尚未连接时说明“首次 SSH 连接后自动记录”。首次连接不要求用户确认；已有记录在后续连接自动比对，发现变化时显示连接已停止。默认 6h 和永久凭据确认保持。见 [SDD 040](../specs/040-automatic-ssh-host-identity/spec.md)。
