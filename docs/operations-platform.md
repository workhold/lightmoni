# 网站与运维平台

当前设计与实现：SDD 033，2026-10-29。入口为“网站与运维”，包含网站、域名解析、证书、应用、服务托管；共享基础设施中维护云凭据、ACME 账号、机器池和网关组。全部管理操作要求管理员。

## 建议配置顺序

1. 在主机管理中安装/登记 Linux Agent，节点具备 Docker Engine 与 Compose plugin。中心不需要 Docker socket。
2. 登记云凭据；登记阿里 DNS/DNSPod 上实际托管的域名并同步记录。腾讯云凭据的 provider 为 tencent，DNS 产品为 DNSPod。
3. 创建单容器或 Compose 应用，配置镜像、端口、网络和挂载，选择机器后显式部署。
4. 创建机器池，指定节点可达地址、CPU/内存容量及托管端口区间。创建服务，选择应用、机器池、容器端口、资源与副本，显式部署。
5. 创建 OpenResty 网关组；创建静态/反代/托管服务网站，选择网关组和域名。HTTPS 引用证书，自动解析引用 DNS 区域；显式发布后同步全组。

保存应用、服务、网关和网站配置不等于现场已应用。发布会冻结已授权配置版本；服务同时冻结应用版本，后续保存新配置需再次发布。证书目标 enabled 和自动续期是明确的持续授权，保存启用后在授权范围内自动执行。停用/降权授权者后停止派发新动作。

## 应用、挂载和网络

单容器和 Compose 共享版本、实例、执行和观察模型；Compose 一个项目部署在一台机器上，多机副本由托管服务调度。配置文件由平台版本化分发并默认只读；初始化文件只在目录首次创建时写入；数据目录与 Docker volume 保留业务数据，不随停止、删除容器或配置回退删除。

本地数据不会自动复制到其他机器。多副本应使用无状态应用或自行配置的共享/外部存储。托管服务使用机器可达 IP + 平台分配的发布端口；目标机器之间需要既有可达网络。资源预留以机器池设置及节点可用信息为基础，实际端口仍由 Agent 现场检查。

OpenResty 是系统应用，采用 Linux host 网络，组内各节点共享网站声明。host 网络直接占用宿主端口，不提供容器端口映射；已有 80/443 冲突会拒绝部署。各网站共享本网关进程；不同网关组不能同时占用同一机器的相同监听端口。

## DNS

支持阿里云 DNS、DNSPod 的分页查询、增删改查、启停、线路和 TTL 等能力。可以在授权范围内人工管理现有记录；网站与 ACME 自动化仅操作保存了平台归属和 Record ID 的记录，不覆盖其他业务记录。API 接受与 DNS 传播分开显示；平台端索引延迟时不应重复点击新增。

托管域名可设置管理 scope。登记 DNS 区域不会修改注册商 NS，实际权威解析须已指向相应平台；服务商账号可访问不等于公网解析已生效。

## 证书签发与更新

证书是全局资源，支持 ACME DNS-01、上传证书链/私钥、自签。ACME 账号密钥、订单、挑战所有权和证书材料加密保存；挑战只清理本订单拥有的 TXT。上传证书检查公私钥、SAN 与有效期；上传方式只提供到期提醒，不自动替用户获得新证书。

自签/ACME 可启用自动续期。续期窗口根据有效期和 renew_before_days 计算，不假定固定90天；失败显示具体结果，人工 issue/renew 可以新建尝试。首版未实现 ARI 与完整自动退避重试。证书状态包含指纹、有效期、剩余天数、到期提醒、当前不可变版本及每目标结果。

三类分发目标：

| 类型 | 配置与行为 |
| --- | --- |
| 机器目录 | Agent、绝对目录、证书/私钥文件名、权限及可选所有者/组；在受管版本目录写入并校验后切换 current，目标文件为受管链接。拒绝覆盖未归属文件；私钥禁止所有用户可读。 |
| 云服务 | 阿里云、腾讯云、火山引擎的 CDN HTTPS 域名；固定云端点签名请求，上传/部署/回读，保留云证书ID映射，逐域记录成功/失败/待验证。其他云产品通过后续适配器或脚本接入。 |
| 更新脚本 | 选择 Agent、解释器、脚本、显式环境、超时和 enabled。每个目标修订+证书版本形成一次逻辑执行，结果分别记录。 |

腾讯云先上传 SSL 证书，再精确更新 CDN 配置；火山使用证书中心上传与 CDN 部署，需要账号已具备相应跨服务授权；阿里 CDN 支持直接 PEM 部署。目标是否真正配置成功以云回读为准，HTTP 200 不等于生效；真实边缘传播仍需独立访问核对。

## 更新脚本

管理员配置的脚本在指定 Agent 上运行，具有该 Agent 的本机权限，适用于平台尚未覆盖的外部集成；没有沙箱隔离承诺。脚本正文和环境加密保存，不自动发送 AI；普通摘要不返回环境秘密，编辑留空保留原值。

平台提供环境元数据：

- LIGHTMONI_CERTIFICATE_PATH：本次证书链文件。
- LIGHTMONI_PRIVATE_KEY_PATH：本次私钥文件。
- LIGHTMONI_CERTIFICATE_ID：证书资源ID。
- LIGHTMONI_CERTIFICATE_VERSION：本次不可变证书版本。

脚本以明确解释器和文件参数执行，不把内容拼进 Docker 命令。只继承最小环境与管理员显式字段，有限时和输出上限；stdout/stderr 不进入公开回执或 AI。配置 enabled 表示对当前目标、正文、环境和期限的持续授权；编辑后按新修订重新记录授权。

inspect 可核对目录指纹或脚本成功标记。unknown 不会自动重放，retry 拒绝尚未核实的 unknown。节点持久 unknown 写锁仍需管理员确认旧进程/daemon及现场状态后按原运维恢复流程处理，检查目标不会自动清除此锁。

## 状态、服务发现和发布

管理资源保存期望版本，实例保存观察版本和时间；只有新鲜、运行中且就绪的实例进入服务发现。Agent 离线会使状态陈旧并摘除端点，不代表原容器已停止，不会据此释放端口或静默迁移本地数据。停止/移除经实际回执确认后才释放预留。

网关按完整版本包检查配置、切换、重载并验证 HTTP/TLS；失败恢复上版。服务没有健康端点时网关返回503。网站全部目标网关达到当前发布版本后才执行受管 DNS 更新；DNS多地址不承诺即时故障切换，缓存仍受TTL影响。

查看逐目标失败、unknown、版本和执行记录，不用配置已保存替代现场成功。所有实测及未验收范围见 [SDD 033 验证记录](../specs/033-operations-control-plane/validation.md)。
