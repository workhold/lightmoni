# SDD 216：助手长任务可靠性与运行反馈

## Context

AI 助手（`web/src/features/assistant/` + `runtime/src/assistant/`）当前无法可靠执行长任务，且有明确的代码级根因：

1. **硬性 2 分钟总超时**：`runtime/src/assistant/index.ts:1069` 用 `AbortSignal.timeout(options.turnTimeout ?? 120000)`，从未被覆盖 —— 超过 2 分钟的 turn 一律失败（"assistant turn reached its time limit"）。
2. **SSE 无心跳**：长时间工具执行期间响应零字节，代理/浏览器空闲超时会掐断流。
3. **断线不恢复**：前端 `client.ts` 流中断即抛错"连接已中断"；但服务端 turn 继续运行且事件每 250ms 持久化，完全可以自动恢复。
4. **运行反馈弱**：无已用时间、无当前工具指示、工具结果只有原始 JSON。
5. **CSS 重复**：`assistant.css` 中 "Concise Agent update card"（~193-223 与 ~225-255）和 history 块（~75-92 与 ~257-274）两处整段重复。

按 AGENTS.md 走 SDD：先建 `specs/216-assistant-long-turn-reliability/`（spec/plan/contracts/tasks），实现后记录验收证据。

用户已确认：超时策略用「空闲超时 + 总上限」；工具展示做到「通用摘要化 + 运行反馈」。

## 后端（runtime）

**`runtime/src/assistant/index.ts`**

- **超时改造**（~1068-1070）：把绝对超时替换为可重置的空闲定时器 + 绝对总上限：
  - 空闲超时（默认沿用 `options.turnTimeout ?? 120000`）：每次 `emit()` 真实事件、或工具正在执行时重置；
  - 总上限（新 option `maxTurnDuration`，默认 30 分钟）：到点必中断，兜底；
  - 中断文案区分 `assistant turn idle timeout` / `assistant turn reached its maximum duration`；options 类型（~71 行）加 `maxTurnDuration?: number`。
- **工具执行看门狗**（~1222-1233 的 execute 回调）：工具执行期间每 15s 向 SSE 写 `: ping\n\n` 注释帧（前端解析器只认 `data:` 行，天然忽略）并重置空闲 deadline；turn 结束 `finally` 清理定时器（用 `unref` 防止挂进程）。
- **事件间心跳**：非工具执行期间同样保持 15s 静默心跳（模型流式输出时自然有 delta，无需额外处理）。

**测试**：扩展 `runtime/test/assistant-conversation.test.ts`（当前仅 43 行）或新增用例：静默长工具在空闲窗口内不中断；空闲超时中断；总上限中断；心跳帧写出。

## 前端（web/src/features/assistant/）

**`types.ts` / `timeline.ts`**：`ToolTrace` 加 `startedAt`/`endedAt`（取事件 timestamp）；`TurnView` 加 `startedAt`/`endedAt`，供耗时计算。

**`client.ts`**：流中断错误改为可识别类型（如 `TurnStreamError { code: 'disconnected' }`，保留现有中文文案）；新增 `fetchSession(sessionId, signal)`（GET `/assistant/sessions/:id`）供恢复轮询。

**`AssistantPage.tsx`**
- `runTurn`（~374-396）：流错误且非用户主动取消时进入**恢复模式**——每 2s 轮询 session 合并事件（`mergeEvents`），直到该 turn 出现终态事件或会话离开 running；连续 ~3 次轮询失败或超过客户端侧 30 分钟上限才报错（未 accepted 时沿用现有回队逻辑）。恢复期间 UI 显示"连接中断，正在恢复…"。
- **运行头部**：会话运行中在 feed 顶部显示一条 sticky 运行条（`lm-assistant-runbar`）：当前工具名 + 已用 mm:ss（每秒 tick）+ 步数 + 停止按钮（复用现有 `cancel()`）。
- `ToolActivity`（~210-219）：摘要行加"已用时间"；运行中自动展开逐工具行（状态点 + 名称 + 各自耗时），完成后保持现有 attention/failed 展开逻辑。

**`AssistantPage.tsx` ToolProgress 通用摘要化**（~192-200）
- 新增 `toolSummary(name, input, result, t)` 纯函数：按工具名映射关键徽标（`run_query` → 行数/查询数/耗时/截断；`describe_table` → 列数；`list_*` → 条目数；错误 → 短错误文案）。
- 卡片默认只显示徽标行；「调用参数/执行结果」原始 JSON 折叠进现有 Collapse（保留排查能力），`run_query` 的 SQL、SSH 预检终端块等现有特化展示保留。
- **`WorkbenchInspector.tsx`** activity 卡片加 turn 耗时。

**`assistant.css`**
- 先 diff 确认后删除两处整段重复块，各保留一份；
- 新增运行条、逐工具行、徽标行、恢复提示样式，沿用现有 `--as-card-*` 卡片变量语法。
